## 手順2　Amazon KDP の登録（約40分）
1. https://kdp.amazon.co.jp を開き、ふだんのAmazonアカウントでログイン
2. 規約に同意
3. 「アカウント情報」で次を入力
   - 著者／出版社の情報（**出版社名は「スライム国」**で可）
   - 支払い受け取り用の銀行口座
   - 税務情報（画面の質問に答えるだけ。日本に住む個人として回答）
4. 「アカウント情報が完了しました」と出ればOK

## 手順3　Kindle本3冊のアップロード（1冊15分×3）
巻ごとのコピー用ファイルを開いておき、枠の中の値を1つずつコピーして貼ります。

- 第1巻：`docs/kdp_copy_vol1.md`
- 第2巻：`docs/kdp_copy_vol2.md`
- 第3巻：`docs/kdp_copy_vol3.md`

1. 本棚 →「＋電子書籍または有料マンガを作成」

### 3-1　詳細のページ
上から順に入れます（値はコピー用ファイルの「1. 詳細のページ」）。
1. 言語：日本語
2. 本のタイトル → その下の**フリガナ**、**ローマ字**
3. サブタイトル → その下の**フリガナ**、**ローマ字**
4. シリーズ：第1巻で新しいシリーズを作る（シリーズ名・**フリガナ**・**ローマ字**・巻番号）。第2巻・第3巻は、作ったシリーズを選んで巻番号を入れる
5. 著者：スライム国（フリガナ・ローマ字の欄があればコピー用ファイルの値）
6. 内容紹介
7. 出版に関する権利：「私は著作権を所有しており…」の方
8. 主な対象読者：**露骨な性的表現「いいえ」**を選ぶ（これを選ぶと、カテゴリーが選べるようになる）
9. カテゴリー：次の2つを選ぶ（2026-10-20 に実際に選べたもの）
   - ビジネス・経済 › 業務改善
   - ビジネス・経済 › スキル › コミュニケーション
10. キーワード：7つの枠に1つずつ
11. 「保存して続行」

### 3-2　コンテンツのページ
画面の上から、この順に出てきます。
1. **読む方向**：左から右（横書き）
2. **原稿**：`manuscript.epub` をアップロード。スマホなら、コピー用ファイルの「原稿のダウンロード用リンク」を開いて保存し、そのファイルを選ぶ
   - リンクの形：`https://github.com/suraiu/-/raw/main/products/kindle/<巻のフォルダ>/manuscript.epub`（巻のフォルダは `vol1_email`・`vol2_minutes`・`vol3_notices`）
3. **DRM**：「いいえ」（DRMをかけない）でよい。※出版したあとは変えられない
4. **表紙**：「表紙ファイルをアップロード」を選び、`cover.png` をアップロード（リンクはコピー用ファイルにあります）
5. **AI生成コンテンツ**：**「はい」**。文章・画像ともAI生成と回答。使ったツールを書く欄があれば「Claude（Anthropic）」。翻訳は「いいえ」
6. **プレビュー**：プレビューアーで数ページ見て、崩れていないか確認
7. **ISBN／出版社**：ISBNは空欄のまま（Kindle本には不要）。出版社の欄は「スライム国」（コピー用ファイルにあります）
8. **アクセシビリティ**：「画像にアクセスできますか？」は、いちばん下の「**情報を提供する画像のすべてに代替テキストや詳細な説明が含まれています。**」を選ぶ（本の中のミニキャラには説明文「ぷるの」を付けてあります）
9. 「保存して続行」

### 3-3　価格設定のページ
- **KDPセレクトに登録：チェックを入れる**
- ロイヤリティ：**70%**
- 価格：**300円**（70%を選べない価格だと画面に出たら、そのスクリーンショットを送ってください）
- 「Kindle本を出版」。審査は通常72時間以内。3冊とも同じ手順です。

## 手順4　Threads と Bluesky の準備（約30分）

### 4-1 Bluesky（簡単・約10分）
1. https://bsky.app でアカウント作成。表示名「スライムの知識」
2. 設定 →「プライバシーとセキュリティ」→「アプリパスワード」→ 新規作成（名前は `slime-bot` など）
3. 出てきたパスワードを**手順4-3で登録**（チャットには貼らない）

### 4-2 Threads（少し手間・約20分）
1. Threads アカウントを作成（Instagramアカウントが必要。名前「スライムの知識」）
2. https://developers.facebook.com でアプリを作成し、ユースケースで「Threads API にアクセス」を選ぶ
3. 権限 `threads_basic` と `threads_content_publish` を有効にする
4. アプリの設定で自分の Threads アカウントをテスター登録し、Threads側で招待を承認
5. 「長期アクセストークン」と「Threads ユーザーID」を取得
   ※ここが一番わかりにくい所です。詰まったら画面のスクリーンショットを送ってください。

### 4-3 環境の設定画面に登録
Claudeのセッション画面のタイトルバー → クラウド環境メニュー →「Edit」

**① 環境変数（Network secrets）に4つ登録**
名前は1つずつ枠からコピーしてください。中身（値）はチャットに貼らず、設定画面にだけ入れます。

1つ目の名前（中身：Blueskyのハンドル。例 slimenochishiki.bsky.social）
```
BLUESKY_HANDLE
```
2つ目の名前（中身：4-1のアプリパスワード）
```
BLUESKY_APP_PASSWORD
```
3つ目の名前（中身：4-2の長期アクセストークン）
```
THREADS_ACCESS_TOKEN
```
4つ目の名前（中身：4-2のThreadsユーザーID。数字）
```
THREADS_USER_ID
```

**② Network access の Allowed domains に2つ追加**
```
graph.threads.net
```
```
bsky.social
```

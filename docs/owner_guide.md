## 手順2　Amazon KDP の登録（約40分）
1. https://kdp.amazon.co.jp を開き、ふだんのAmazonアカウントでログイン
2. 規約に同意
3. 「アカウント情報」で次を入力
   - 著者／出版社の情報（**出版社名は「スライム国」**で可）
   - 支払い受け取り用の銀行口座
   - 税務情報（画面の質問に答えるだけ。日本に住む個人として回答）
4. 「アカウント情報が完了しました」と出ればOK

## 手順3　Kindle本3冊のアップロード（1冊15分×3）
各巻の `kdp_listing.md` を開いておき、書いてある文をコピペします。

1. 本棚 →「＋電子書籍または有料マンガを作成」
2. **詳細**ページ：言語（日本語）、タイトル、サブタイトル、シリーズ、著者（スライム国）、内容紹介、キーワード7つ、カテゴリ　→ kdp_listing.md からコピペ
3. **コンテンツ**ページ
   - 原稿：`manuscript.docx` をアップロード
   - 表紙：「アップロード」を選び `cover.png` をアップロード
   - **AI生成コンテンツの質問：「はい」**。文章・画像ともAI生成と回答（kdp_listing.md の申告内容のとおり）
   - プレビューアーで数ページ見て、崩れていないか確認
4. **価格設定**ページ
   - **KDPセレクトに登録：チェックを入れる**
   - ロイヤリティ：**70%**
   - 価格：**300円**
5. 「Kindle本を出版」
   - 審査は通常72時間以内。3冊とも同じ手順です。

## 手順4　Threads と Bluesky の準備（約30分）

### 4-1 Bluesky（簡単・約10分）
1. https://bsky.app でアカウント作成。表示名「スライムの知識」
2. 設定 →「プライバシーとセキュリティ」→「アプリパスワード」→ 新規作成（名前は `slime-bot` など）
3. 出てきたパスワードを**手順4-3で登録**（チャットには貼らない）

### 4-2 Threads（少し手間・約20分）
1. Threads アカウントを作成（Instagramアカウントが必要。名前「スライムの知識」）
2. https://developers.facebook.com でアプリを作成し、ユースケースで「Threads API にアクセス」を選ぶ
3. 権限 `threads_basic` と `threads_content_publish` を有効にする
4. アプリの設定で自分の Threads アカウントをテスター登録し、Threads側で招待を承認
5. 「長期アクセストークン」と「Threads ユーザーID」を取得
   ※ここが一番わかりにくい所です。詰まったら画面のスクリーンショットを送ってください。

### 4-3 環境の設定画面に登録
Claudeのセッション画面のタイトルバー → クラウド環境メニュー →「Edit」

**① 環境変数（Network secrets）に4つ登録**
| 名前 | 中身 |
|---|---|
| `BLUESKY_HANDLE` | Blueskyのハンドル（例：slimenochishiki.bsky.social） |
| `BLUESKY_APP_PASSWORD` | 4-1のアプリパスワード |
| `THREADS_ACCESS_TOKEN` | 4-2の長期アクセストークン |
| `THREADS_USER_ID` | 4-2のユーザーID |

**② Network access の Allowed domains に2つ追加**
- `graph.threads.net`
- `bsky.social`

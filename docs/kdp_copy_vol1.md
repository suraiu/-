### 内容紹介
```
お礼のメールを書こうとして「いつもお世話になっております」で手が止まる。お詫びのメールを、どこまで謝ればいいのか迷って30分たってしまう――。そんな「メールが苦手」を、AIに手伝ってもらうための本です。

対話型のAIに「メールを書いて」とだけ頼むと、だれにでも送れる、だれにも響かない文章が出てきがちです。でも「だれに」「何があって」「何を入れて」「どのくらいの長さで」を伝えるだけで、そのまま使える文章に近づきます。

この本では、仕事のメールでよくある場面ごとに、コピペして使える「AIへの頼み方」を56個まとめました。［　］の部分を書きかえて、AIにはりつけるだけで使えます。

【収録している場面】
・お礼（打ち合わせ、紹介、お祝い など）
・お詫び（返信遅れ、訂正、納期遅れ など）
・日程調整（候補日の提示、変更のお願い、オンライン会議の案内 など）
・催促・リマインド（やわらかい催促、2回目以降、前日のリマインド など）
・断り（依頼、営業、お誘い、条件の変更 など）
・依頼・お願い（仕事の依頼、資料の送付、チェック など）
・社内の報告・連絡・相談、社外へのあいさつ
・自分の下書きをていねいに直す・短くする・最終チェックする

【この本の特長】
・すべてのテンプレに、実際にAIに頼んで出てきた「出力例」つき
・「長すぎる」「かたすぎる」「言っていないことが足された」など、うまくいかないときの直し方つき
・特定のAIサービスに頼らない書き方で、ふだん使っている対話型AIで使えるようにしています
・個人情報の扱いや、送る前に確かめたいことなど、安全に使うための約束も紹介
・巻末に、テンプレ一覧と、どの場面にも使える「万能の型」、困ったときの「追加の注文」集つき

案内役は、メールが苦手なスライムの「ぷるの」。ゆるく読めて、明日のメールからすぐ使えます。

※この本は、AIが企画・執筆し、表紙もAIが作成しています。出力例はAIが出した文章の一例で、同じ頼み方でも結果は毎回変わります。出力例に登場する会社名・人名はすべて架空のものです。
```

### 内容紹介
```
PTAの係になった。町内会の班長が回ってきた。サークルの幹事をたのまれた。
そんなときに必ずやってくるのが「お知らせ文」の仕事です。

「清掃の案内、どう書けば来てもらえる？」
「会費を払っていない人に、角を立てずに伝えたい」
「回覧板は、ご高齢の方も読むから読みやすくしたい」

この本は、そんな「ちょっと気をつかう文」の下書きを、AIに頼むためのテンプレ集です。
スライムの案内係「ぷるの」といっしょに、場面ごとに、そのままコピペして使える頼み方を59個まとめました。

【この本で扱う場面】
・行事の案内（清掃、夏まつり、講演会、防災訓練、総会の通知など）
・集金・会費（集金のお知らせ、やわらかい催促、値上げ、会計報告）
・役員・係の募集（役員募集、くじ引きの案内、お手伝い募集、断りの返事）
・お礼と報告（参加者・お店・講師へのお礼、会報用の報告）
・中止・延期・変更の連絡（雨天中止、延期、訂正とお詫び）
・LINEグループ用の短文（リマインド、出欠の取り方、使い方ルール）
・回覧板・掲示板（ごみ出しや駐車のお願い、ご高齢の方向けの言い直し）
・アンケート（質問づくり、日程調整、結果のまとめ）
・仕上げ（見直し、やわらかい言い方への直し、敬語のチェック、紙・LINE・掲示板用の作り分け）

【各テンプレの中身】
①どんな場面で使うか
②コピペ用の頼み方（［　］を書きかえるだけ）
③実際にAIに頼んで返ってきた出力例
④うまくいかないときの直し方

さらに、「角が立たない言い方のコツ」「ご高齢の方にも読みやすい書き方のコツ」「曜日と金額を自分で確かめる理由」「個人情報を入れないための工夫」も、最初の章にまとめています。巻末には、答えを直したいときに続けて送るだけの「ひとこと」早見表もつけました。

特定のAIサービスの画面や料金には頼らない書き方なので、ふだん使っているAIのチャットにそのまま貼って使えます。

※この本は、AIが企画・執筆し、表紙もAI（プログラム）で作成しました。出力例は、架空の内容を入れた頼み方を、実際に対話型のAIに送って得た答えです。AIの答えは毎回少しずつ変わります。
※シリーズ第1巻は「仕事のメール」、第2巻は「議事録・要約」がテーマです。
```

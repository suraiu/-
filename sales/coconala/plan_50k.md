## 2. 逆算：必要な売上と件数

### 前提（すべて仮置き・要確認）
- ココナラの販売手数料：**22%（税込）**（公式お知らせの検索抜粋より。`policy_check.md` 1-1）→ 手取り＝売上×78%
- 期間中の経費：**5,500円**（AIツール等の11月分 5,000円＋振込手数料などの予備 500円。実額は人が確認）
- 購入者側のサービス料は出品者の手取りに影響しない前提（要確認 1-3）
- 税金は計算に入れない（税引前の利益）

### 計算
```
利益 = 売上 × 0.78 − 経費
50,000 = 売上 × 0.78 − 5,500
売上 = 55,500 ÷ 0.78 = 71,154円  →  必要な売上 約 72,000円
```
（経費を10月分も含めて10,500円で見る場合：60,500 ÷ 0.78 ＝ 77,564円 → 約7.8万円）

### 件数の組み合わせ（目標シナリオ）
初回価格（実績づくり）で売る期間が長いので、ほとんどは安い価格で計算する。

| 出品 | 件数 | 内訳 | 売上 |
|---|---|---|---|
| ① 海外リサーチ | 5件 | スタンダード初回5,000円×5 | 25,000円 |
| ② リール台本3本 | 7件 | 初回3,000円×5 ＋ 通常5,500円×2 | 26,000円 |
| ③ ブログ・note記事 | 3件 | 2,000字2,500円×1 ＋ 4,000字4,000円×1 ＋ 2,500円＋オプション500円×1 | 9,500円 |
| ④ スライム診断 | 16件 | 初回500円×10 ＋ 通常1,000円×6 ＋ 相性オプション500円×2 | 12,000円 |
| **合計** | **31件** | | **72,500円** |

- 手取り：72,500 × 0.78 ＝ 56,550円 → 経費5,500円を引いて **利益 約51,050円**
- **1日あたり約0.75件**（41日間）。ただし最初の1週間は出品準備で売れないので、実質は **約35日で31件＝ほぼ毎日1件**。

## 5. 達成確率の正直な見込み

| 結果 | 見込み | 理由 |
|---|---|---|
| 1件以上売れる | **約70%** | 公開依頼への提案と500円の④があれば、1件は取れる可能性が高い |
| 利益1万円以上 | **約40%** | 10件前後。新規出品者でも届きうる |
| 利益3万円以上 | **約20%** | 20件前後 |
| **利益5万円以上（目標）** | **約10%（よくて15%）** | 31件はレビュー0の新規出品者には多い。出品審査・本人確認で数日失う可能性、取引完了のずれ、人の作業時間（週9〜10時間）が続くかが不確実 |

- ここでの%は、実績データがない段階でのAIの見立て（根拠のある統計ではない）。第2週の数字で更新する。
- **上がる要因**：①が1件でも「詳しい版」（`sales/offer.md` の価格帯）につながる／知人が**本当に必要として**依頼してくれる（自作自演・レビュー目的の購入は不可）／B2B直接営業で1〜2件取れる（手数料なしで1.5万円）
- **下がる要因**：AIや占いカテゴリのルールで②③④が出せない／出品審査が長い／人の時間が平日30分しか取れない

## 6. うまくいかないときの切り替え案

### 判断のタイミングと基準
| 日付 | 状態 | 切り替え |
|---|---|---|
| 11/8（日） | 問い合わせ0件 | タイトル・サムネイルを差し替え（AIが2案ずつ）、提案を1日5件に増やす |
| 11/15（日） | 累計売上 2万円未満 | 下の1〜3から人が選ぶ |
| 11/22（日） | 累計売上 4万円未満 | 目標の組み替え（4）を検討 |
| 随時 | ④が規約上出せない | ④の時間を②に回す。スライム診断はSNSの無料コンテンツ（集客用）にする |

### 切り替えの選択肢
1. **B2B直接営業を並行で再開**（`sales/plan_november.md`・`sales/outreach.md`）：ライト1.5万円×2件で利益約3万円（手数料なし）。1日6件の連絡（人30分）。ココナラで知り合った相手とは外部で取引しない。
2. **買い手の募集に応募する側に回る**：ランサーズ・クラウドワークスなどの募集案件（台本・記事・リサーチ）に応募。手数料・規約は各サービスで要確認。
3. **出品を2本に絞る**：数字の良い出品だけに時間を集中し、他は一時停止。
4. **目標の組み替え**（人が決める）：「11月末に利益3万円＋12月の受注確定2万円」、または期限を12月20日に延ばす。
5. **note有料記事**（500円前後）：①のリサーチを依頼主の許可がある範囲／自主調査で再利用。11月中の売上は小さい見込み（フォロワーゼロのため）。

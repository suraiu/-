# 受注〜納品の流れと納品テンプレート

> **ステータス：案（未承認）**。作成：収益化AI ／ 2026-10-20
> 原則：**購入者とのメッセージ送信・納品ボタンを押すのは人。** AIは下書きだけ作る。
> 購入者の情報（依頼内容・回答）は `sales/coconala/orders/注文番号/` にまとめ、公開リポジトリにはコミットしない（`.gitignore` に追加する案。人が判断）。

---

## 1. 全体の流れ

| # | 段階 | AIがやること | 人がやること | 目安時間（人） |
|---|---|---|---|---|
| 0 | 購入前の相談（DM） | 返信の下書き（テンプレートA）、受けられるかの判定メモ（お断り事項に当たらないか） | 内容を確認して送信。受ける／断るを決める | 5分 |
| 1 | 購入・トークルーム開始 | お礼＋ヒアリング（テンプレートB）の下書き | 送信 | 3分 |
| 2 | ヒアリング完了 | `orders/注文番号/brief.md` に要件を整理。不明点があれば質問案 | brief.md を確認 | 3分 |
| 3 | 下書き作成 | 各サービスの手順（2章）で下書き。出典URLの一覧と「未確認」リストを付ける | — | — |
| 4 | 品質管理AIのチェック | `quality-checker` に事実・出典・禁止表現・重複をチェックさせ、指摘を直す（最大2回） | — | — |
| 5 | 人の確認 | 確認ポイントのチェックリスト（3章）を添える | **出典を開いて数字を確認**、表現を直す、チェックリストに○ | サービス別（下表） |
| 6 | 納品 | 納品メッセージ（テンプレートC）の下書き | 納品・送信 | 3分 |
| 7 | 修正対応 | 修正案の下書き | 確認して再納品 | 10〜20分 |
| 8 | 取引完了・評価 | お礼メッセージ（テンプレートD）の下書き。`data/revenue.md` に記録 | 送信、購入者の評価（出品者からの評価）を入力 | 3分 |

**人の確認時間の目安（5の段階）**：①リサーチ 40〜60分／②台本 25〜35分／③記事 30〜50分／④診断 10〜15分
**1件あたりの人の合計時間（0〜8）**：①1〜1.5時間／②約1時間／③1〜1.5時間／④20〜25分

### 断る基準（0の段階で人が判断）
- `listings.md` の「できないこと／お受けできないもの」に当たる
- 締切に間に合わない（人の確認時間を削らないと無理なもの）
- 依頼者がつらそう・深刻な悩みを抱えていそう（④）→ やさしく断り、専門の相談窓口を案内する（具体的な窓口名・電話番号は人が公式ページで確認してから入れる）

## 2. 共通メッセージ（テンプレート）

### A. 購入前の相談への返信
```
はじめまして、スライムの知識の【担当者名】です。ご相談ありがとうございます。

いただいた内容（{テーマ／要件の要約}）で、対応可能です。
・お届けする内容：{プランの中身}
・納期：ご購入から{N}日
・{確認したい点があれば1〜2個}

なお、本サービスはAIツールで下書きを作り、私（人）が内容を確認してからお届けしています。
ご納得いただけましたら、ご購入ください。どうぞよろしくお願いいたします。
```
（断る場合）
```
ご相談ありがとうございます。せっかくご連絡いただいたのですが、
今回の内容（{理由を短く}）は、私のサービスではお受けできない範囲のため、お断りさせてください。
お力になれず申し訳ありません。
```

### B. 購入後のお礼・ヒアリング
```
ご購入ありがとうございます！【担当者名】です。
さっそく進めるため、次の点を教えてください（わかる範囲で大丈夫です）。
{サービス別のヒアリング項目}
いただいてから{N}日以内にお届けします。
```

### C. 納品メッセージ
```
お待たせしました。{サービス名}をお届けします。

【今回のポイント】
・{1行目}
・{2行目}

【ご確認のお願い】
・{未確認の点・注意点があればここに}
・気になる点があれば、{修正回数}回まで無料で修正します。

AIツールで下書きし、私が内容を確認してお届けしています。
問題なければ、取引の承認をお願いいたします。
```
※「★5の評価をお願いします」などレビューの中身を求める文は入れない（`policy_check.md` 5-3）。

### D. 取引完了後のお礼
```
このたびはありがとうございました。
またご縁があれば、いつでもご相談ください。
```

## 3. サービス別の手順と納品テンプレート

### ① 海外の制度・事例リサーチ

**AIの手順**
1. brief.md の「テーマ・国・使い道」から、調べる問いを3つに分ける。
2. 一次資料（政府・自治体・法令・統計）を先に探し、報道・研究は補助に使う。
3. 数字・固有名詞・年ごとに出典番号を付ける。見つからない数字は書かない。
4. 「未確認リスト」を別に作る（人の確認用）。
5. 日本と比べる節は、日本を下げる言い方をしない（ブランドガイドライン）。

**人の確認ポイント**
- [ ] 出典URLを全部開き、数字・年・固有名詞が出典どおりか（最低でも主要な数字は全部）
- [ ] 出典の確認日を記入
- [ ] 「〜とされる」「〜と報道されている」の使い分けが適切か
- [ ] 法的助言のように読める箇所がないか
- [ ] 依頼者の使い道に合っているか

**納品テンプレート**（PDFまたはWord。A4 1〜2枚）
```markdown
# {国}の「{制度名}」― {ひとことで言うと}

> 調査日：{YYYY年M月D日}／作成：スライムの知識
> 公開情報をAIツールで調査し、人が出典を確認してまとめたものです。法的助言ではありません。

## 1. 3行でわかる要約
1. …[1]
2. …[2]
3. …

## 2. 仕組み
| 誰が | 何を | どんなルールで |
|---|---|---|

## 3. 始まった経緯
## 4. 数字で見る実績
（数字が見つからない場合：「公開情報では確認できませんでした」）
## 5. 評価・批判・課題            ← スタンダードのみ
## 6. 日本で考えるなら、の論点     ← スタンダードのみ
- 論点1：…（読者に考えてもらう書き方）

## 未確認の点
- …

## 出典
[1] {発行元}「{タイトル}」{URL}（確認日：{日付}）
```
見本：`sales/sample_report.md`（標準プラン相当。A4 1〜2枚版は、ここから1・2・4・7を抜き出したもの）

### ② ショート動画・リール台本（3本セット）

**AIの手順**
1. ジャンル・読者・尺から、3本のテーマ案（おまかせの場合は5案→購入者に選んでもらう）。
2. 各台本に冒頭のつかみを2案。
3. 事実を含む場合は出典を付ける。出典がないものは入れない。
4. 文字数の目安：ナレーションは1秒あたり約4〜5字（日本語の話し言葉の一般的な目安として置いた仮の数字。読み上げて人が調整）。

**人の確認ポイント**
- [ ] 声に出して読み、尺に収まるか（ストップウォッチで1回）
- [ ] 他の有名な動画の言い回しをなぞっていないか
- [ ] 効果・収益の断定、医療・美容の効能がないか
- [ ] 画面テキストが短いか（1画面15字前後）

**納品テンプレート**（Googleドキュメントまたはテキスト）
```markdown
# リール台本（3本セット）／{アカウントのジャンル}

## 台本1：「{タイトル}」（{尺}秒）
**つかみ案A**：{0〜2秒の画面テキスト／ナレーション}
**つかみ案B**：{…}

| 秒 | 画面（映すもの） | テロップ | ナレーション |
|---|---|---|---|
| 0-2 | | | |
| 2-8 | | | |
| … | | | |
| ラスト | | {締めの一言} | |

**出典**（事実を含む場合）：{URL}
**撮影メモ**：{必要な素材・小物}

## 台本2 … ／ 台本3 …
```

### ③ ブログ・note記事

**AIの手順**
1. 見出し構成（H2を4〜6個）とタイトル案3つを先に作り、購入者のOKをもらう（人が送信）。
2. 本文を書く。事実には出典。体験談は購入者のメモがある場合だけ、その内容の範囲で。
3. 重複チェック（ツールの選定は人。無料ツールで可）。

**人の確認ポイント**
- [ ] 出典の確認（主要な数字）
- [ ] 重複チェックの結果（一致率の基準は人が決める。例：特定の文章と長く一致していないこと）
- [ ] 指定の文体・文字数・キーワード
- [ ] 宣伝を含むなら「PR」表記の提案をしたか

**納品テンプレート**
```markdown
# {タイトル}
（タイトル案：①… ②… ③…）

リード文（3〜4行）

## {見出し1}
## {見出し2}
## {見出し3}
## まとめ

---
【参考にした資料】
- {発行元}「{タイトル}」{URL}
【文字数】約{N}字（見出しを含む）
【重複チェック】{ツール名}で確認済み（{結果}）
```

### ④ エンタメ診断「スライム診断」

**AIの手順**
1. 購入者の10問の回答を、**人が承認した点数表**に当てはめてタイプを決める（同じ回答なら必ず同じタイプ）。
2. タイプ別の基本文（人が事前に承認した12タイプ分）をもとに、回答に合わせて1〜2文だけ調整する。
3. 禁止語チェック（下のリスト）を機械的にかける。
4. カード画像は人が作ったテンプレートに、タイプ名とニックネームを入れる（AIでイラストを描かない）。

**禁止語・禁止表現リスト**（1つでも入っていたら書き直し）
- 断定：必ず／絶対／確実に／100%／運命が決まる／当たる
- 不安あおり：このままだと／不幸／災い／呪い／悪い気／縁が切れる／危険／〜しないと大変
- 霊感・開運：霊視／守護霊／前世／浄化／お祓い／開運グッズ／波動
- 追加販売の誘導：もっと詳しく知りたい方は／特別鑑定／◯◯円で〜できます
- 重大な判断：病気／治る／お金が増える／別れるべき／結婚すべき

**質問10問（案・人が承認して確定）**
1. 休みの日は？（a 家でゆっくり／b ふらっと出かける／c 予定をびっしり）
2. 新しいお店を見つけたら？（a 様子見／b すぐ入る／c 口コミを調べてから）
3. グループでの役割は？（a 聞き役／b 盛り上げ役／c まとめ役）
4. 好きな天気は？（a くもり／b 晴れ／c 雨）
5. 困ったときは？（a ひとりで考える／b 誰かに話す／c とりあえず動く）
6. 部屋の机の上は？（a ものが少ない／b にぎやか／c 決まった場所に置く）
7. 旅行の計画は？（a 行き先だけ決める／b 行き当たりばったり／c 分刻み）
8. 最近うれしかったことに近いのは？（a ひとり時間／b 人との会話／c 目標達成）
9. 苦手なのは？（a 大人数の場／b じっと待つこと／c 予定の変更）
10. スライムになったら何をしたい？（a 日なたで溶けたい／b 跳ねて旅したい／c 仲間を増やしたい）

**人の確認ポイント**
- [ ] 点数表どおりのタイプになっているか
- [ ] 禁止語チェックの結果が0件
- [ ] 読んでいやな気持ちにならないか（「気をつけたいところ」がやさしい言い方か）
- [ ] 冒頭にエンタメ表記があるか
- [ ] ニックネーム以外の個人情報を書いていないか

**納品テンプレート**
```markdown
【これはエンタメ診断です】占い・鑑定・心理検査ではありません。お楽しみとしてお読みください。

# {ニックネーム}さんは…「{タイプ名}スライム」！

{タイプのひとこと紹介（2行）}

## いいところ
- …
- …
- …

## ちょっと気をつけたいところ（やさしめに）
- …（「〜なときは、ひと休みしてもいいかも」くらいの言い方）

## 相性
- 気が合いそう：{タイプ}スライム（{理由1行}）
- ちょっとペースがちがうかも：{タイプ}スライム（{でも、こうすると楽しい、を1行}）

## スライムからのひとこと
「{前向きな一言}」

---
※この診断は、10問の回答をもとにAIツールで下書きし、人が確認してお届けしたエンタメコンテンツです。
カード画像はご自身のSNSで自由にお使いください。
```

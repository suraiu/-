# SNS「スライムの知識」からココナラ・noteへの送客（案）

> **ステータス：案（未承認）**。投稿は `data/config.md` の `AUTO_POST: false` に従い、人が確認して投稿する。
> 作成：収益化AI ／ 2026-10-20
> 正直な前提：**フォロワーゼロからの2〜5週間では、SNS経由の購入は月に数件あればよい方**（見立て）。11月の売上の主力はココナラ内の検索・公開依頼への提案（`plan_50k.md`）。SNSは「信頼の置き場所（プロフィールを見た購入者が安心できる）」と12月以降の集客のために育てる。

---

## 1. 送客の設計

```
X / Threads / Instagram（毎日：雑学・診断のお試し）
        │  プロフィールのリンク（1つにまとめたリンク集ページ、または固定投稿）
        ├──→ note（無料記事：雑学の深掘り・スライム診断の簡易版）
        │        └──→ 記事の末尾に「詳しく調べてほしい方はココナラで」
        └──→ ココナラの出品ページ（①〜④）
```

| SNS | 役割 | ココナラへの導線 |
|---|---|---|
| X | 雑学の1枚画像＋短文。拡散用 | 固定投稿に「出品中のサービス」一覧。宣伝投稿は週2回まで |
| Threads | Xの内容を会話調で。質問を投げてコメントをもらう | プロフィールのリンク |
| Instagram | リール（週3：月水金）と診断カルーセル | プロフィールのリンク・ハイライト「サービス」 |
| note | 無料記事で「調べ方・出典の付け方」を見せる＝①の品質見本 | 記事末尾にココナラのリンク（PR・自分のサービスである旨を明記） |

### ルール
- **投稿の8割は役に立つ・楽しい中身、宣伝は2割以下**（週2回まで）。
- 宣伝投稿は「自分のサービスです」と明記（ステマ規制・ブランドガイドラインの「PR」表記。`policy_check.md` 6-3）。
- 購入者に「SNSで紹介してくれたら割引」などの特典は出さない。
- ココナラのトークルームからSNS・noteへ誘導しない（直接取引の禁止に当たるおそれ。`policy_check.md` 5-1）。**流れは「SNS → ココナラ」の一方向だけ。**
- 同一文面の連投・ハッシュタグの付けすぎをしない（各SNSの規約）。

## 2. スライムのキャラ設定（案）

| 項目 | 案 |
|---|---|
| 名前 | **ぷるの**（仮。「ぷるぷる＋知識の“の”」）。候補：ちしきスライム／スラ博士 |
| 立場 | 世界中をぷるぷる旅して、「日本ではまだ知られていない仕組み」を集めている、ちょっと物知りなスライム |
| 性格 | 好奇心旺盛、のんびり、知ったかぶりはしない（「〜らしいよ」「調べたらこう書いてあった」） |
| 口調 | です・ます は使わない、やわらかいタメ口。語尾に「〜ぷる」は**1投稿に1回まで**（多いとくどい）。例：「へぇ〜って思ったから持ってきたぷる。日本だとどうなるかな？」 |
| 決めゼリフ | 「今日の“へぇ”、置いていくね」 |
| 言わないこと | 海外を持ち上げて日本を下げる／断定（「絶対」）／誰かをからかう |
| 見た目 | **丸い大福型**（しずく型・とがった頭にしない）。体は水色 #38BDF8、背景は濃い紺 #0F172A、丸メガネと小さな本が黄色 #FACC15（「知識」のしるし）、白いハイライト #F8FAFC |
| 表情 | 目は点2つ＋ほっぺ。驚き（目が丸）・考え中（汗1つ）・にっこり の3種 |
| 診断用の12タイプ | ぷるのの色・形ちがいの仲間たち（`listings.md` ④）。同じ丸型のまま、色と小物で描き分ける |

**著作権・商標の注意**：有名ゲームのスライム（しずく型で頭がとがった形・青くて笑顔の口）に似せない。描くのは人（またはAI画像を使う場合も、ココナラのサムネイル・納品物には使わない。SNS用にAI画像を使う場合は「実写と見間違えない」イラストに限る）。名前「ぷるの」の商標の重複は人が確認（要確認）。

## 3. 最初の2週間の投稿テーマ（14本）

- 開始日は出品公開に合わせて **10/26（月）** と仮置き。リールは月水金。
- 雑学ネタは `data/ideas.md`（2026-10-20 リサーチ分）から。**出典はネタ帳のものを投稿前に品質管理AIと人が再確認**し、確認できないものは差し替える。数字は出典どおりに書く。
- 診断系は「無料のミニ診断（3問）」で、フルの④へ興味を持ってもらう。すべて「エンタメです」を付ける。

### 投稿文の例（#7 宣伝）
```
ぷるのの「中の人」から、お知らせです。
ココナラで、こんなお仕事を受けはじめました（自分のサービスです）。

・海外の制度・事例を出典つきでA4にまとめる
・リール台本3本セット
・ブログ／note記事
・【エンタメ】スライム診断

どれもAIで下書きして、人が確認してお届けしています。
くわしくはプロフィールのリンクから。
```

### 診断系投稿の必須表記
- 1枚目または本文の最初に「※エンタメ診断です。占い・鑑定ではありません」
- 禁止語リスト（`delivery_templates.md` ④）を投稿にも適用

## 4. 見る数字（毎週月曜）
- 各SNSのフォロワー・保存数・コメント数
- プロフィールのリンクのクリック数（リンク集ページで計測できる場合）
- ココナラ出品ページの閲覧数（SNS投稿の翌日に増えたか）
- 診断系と雑学系、どちらが保存・フォローにつながったか → 3週目以降の比率を戦略AIが決める

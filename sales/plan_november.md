# 11月計画（案）：B2Bリサーチで利益10万円

> **ステータス：案（未承認）**。送信・出品・価格決定は人が承認してから実行。
> 作成：収益化AI ／ 2026-10-20（火）

## 1. ゴールの定義（人に決めてほしい点）

「11月末までに利益10万円」を何で数えるかで難易度が変わる。

| 数え方 | 難易度 | コメント |
|---|---|---|
| 11月中に **受注確定**（発注メール・契約） | 中 | 一番現実的 |
| 11月中に **納品＋請求** | 中〜高 | 11/20以降の受注は間に合わないことがある |
| 11月中に **入金** | 高 | 法人・自治体は「月末締め翌月払い」が多く、ほぼ前払いの個人案件のみ |

**提案**：目標は「11月中に納品・請求した分で利益10万円」。前払いを基本にできる個人・小規模事業者を優先する。

## 2. 逆算

- 必要売上：利益100,000円 ＋ ツール代5,000円 ＝ **105,000円**（直接販売）
- 平均単価を **約2.5万円**（ライトと標準が混ざる想定）とすると → **4〜5件**
- 営業の歩留まり（冷たい営業の一般的な目安として控えめに置いた仮定。実績で毎週更新）

| 段階 | 想定率 | 件数（5件受注に必要） |
|---|---|---|
| 連絡する | — | **約120件** |
| 返信がある | 10% | 約12件 |
| 見積もり・目次案まで進む | 60% | 約7件 |
| 受注 | 70% | **約5件** |

→ **1日あたり平日6件前後の連絡**（相手に合わせた1行を入れるので、AIが下書き→人が確認・送信で1件5分＝1日30分）
→ 加えて、ココナラ・ランサーズは「当たれば上乗せ」扱い（11月の見込みは0〜1件）。

## 4. 人とAIの分担まとめ

| 人だけがやること（承認が必要） | AIがやること |
|---|---|
| 価格・条件の決定、出品、アカウント作成 | 候補の組織・窓口集め（公開情報のみ） |
| 営業メール・DMの送信、返信 | 営業文の下書き（相手ごとの1行） |
| 見積もり・契約・請求・入金確認 | 目次案・見積もりの下書き |
| 納品物の最終チェック（事実・表現） | 調査・下書き・出典集め・図表案 |
| 断る判断（お断り事項に当たる依頼） | 反応率の集計と改善案、`data/revenue.md` の更新 |

**人の作業時間の目安**：平日30〜60分（送信・返信）＋ 納品1件あたり1.5〜5時間（確認・修正）→ 11月合計 **約30〜35時間**。

## 5. 達成確率の正直な見込み

| 結果 | 見込み | 理由 |
|---|---|---|
| 1件以上受注 | **約60%** | 120件連絡できれば、1件は取れる可能性がそれなりにある |
| 利益5万円以上 | **約35%** | 2〜3件必要 |
| **利益10万円以上（目標）** | **約15〜20%** | 実績・レビュー・SNSのフォロワーがゼロの状態で4〜5件は厳しい。自治体は手続きで11月に間に合わないことが多い |

**下がる要因**：送信が予定どおりできない（人の時間不足）、返信率が想定（10%）より低い（3〜5%もあり得る）、入金基準で数える場合。
**上がる要因**：知人・既存の人脈からの紹介（冷たい営業の何倍も決まりやすい）、コンサル会社1社と継続の取り決めができる、詳細プラン（5万円）が1件決まる。

## 6. 届かないときの代替案（第3週の判断材料）

1. **知り合い経由の紹介をお願いする**（一番効く。オーナーの人脈の確認を人にお願いしたい）
2. モニター価格（標準2万円・サンプル公開許可つき）で件数を取りにいく → 目標額は下がるが12月以降の実績になる
3. 同じ調査を **note有料記事（500〜1,000円）** に作り直して少額を積む（B2Bの調査結果を、依頼主の許可がある範囲で再利用。依頼主の情報は出さない）
4. 11月の目標を「利益5万円＋12月の受注予約2件」に組み替える提案

## 7. 毎週月曜にやること（収益化AIの週次）

- `data/revenue.md` に：今月の受注・納品・請求額、目標までの差、来週の送信数
- 種類別の反応率（送信数・返信数・受注数）
- 文面・ターゲットの入れ替え案

## 3. noteへの貼り方

### 3-1. 本文
1. noteにログイン →「投稿」→「テキスト」で新しい記事を開く。
2. タイトル欄に、上のタイトル案から1つを入れる。
3. `article.md` の **2行目以降**（1行目の「# タイトル」は除く）をコピーして、本文に貼る。
4. 貼ったあと、記号が残っていないか上から確認して直す。noteの画面ではMarkdownの記号がそのまま残ることがある。
   - `## ` で始まる行 → その行を選んで「大見出し」にする（記号は消す）
   - `### ` で始まる行 → 「小見出し」にする
   - `> ` で始まる行 → 「引用」にする
   - `**太字**` → 記号を消して太字にする
   - `---` の行 → 区切り線にするか、行ごと消す
   - `- ` や `1. ` の行 → 箇条書き・番号付きリストにする
5. **冒頭の「この記事はAIが書いています」の引用ブロックは消さない。** 最後の「この記事は、AIだけで運営する会社…」の注記も残す。

### 3-2. 見出し画像
1. 記事の編集画面の上にある画像のアイコン（見出し画像）を押す →「画像をアップロード」。
2. `header.png` を選ぶ。大きさは1280×670で作ってあるので、切り抜きの枠はそのままでよい。
3. 画面によっては左右が少し切れることがあるため、大事な文字（タイトル・売上0円）は中央寄りに置いてある。

### 3-3. 公開設定
1. 右上の「公開に進む」を押す。
2. ハッシュタグ：上の2のタグを入れる。
3. 記事の種類：**無料**（有料エリアは設定しない。第2回会議の決定で、noteの販売は2か月目から）。
4. マガジン：シリーズ用のマガジンを作るなら「AIだけの会社 実録」などの名前で作って追加（任意）。
5. 「投稿する」を押して公開。公開後、記事のURLを下のThreads投稿文の `{noteのURL}` に入れる。

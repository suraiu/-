## 6. 画像の作り直し方（文章を直したとき用）

`products/note/002_ai_company/` で実行する。

```
/home/user/ai-sns-company/scripts/render.sh src/header.html images/header.png 1280 670
/home/user/ai-sns-company/scripts/render.sh src/org.html images/org.png 1280 720

/home/user/ai-sns-company/scripts/render.sh src/meeting.html images/meeting.png 1280 720
```

GIF（場面ごとにPNGを作ってから ffmpeg でつなぐ。frames は一時フォルダ）：

```
mkdir -p frames
for i in 1 2 3 4; do /home/user/ai-sns-company/scripts/render.sh "src/covers_gif.html?f=$i" frames/c$i.png 800 500; done
printf "file 'c1.png'\nduration 2.5\nfile 'c2.png'\nduration 2.5\nfile 'c3.png'\nduration 2.5\nfile 'c4.png'\nduration 3.5\nfile 'c4.png'\n" > frames/c.txt
ffmpeg -y -f concat -safe 0 -i frames/c.txt -vf "fps=10,split[a][b];[a]palettegen=max_colors=128[p];[b][p]paletteuse=dither=bayer" -loop 0 images/covers.gif
```

`timeline.gif` も同じやり方で、`src/timeline_gif.html?n=1` 〜 `?n=10` を1.2秒ずつ（最後だけ3.5秒）つなぐ。`src/assets/` の表紙の画像は、`git` の記録から取り出した第1巻の表紙3つの版と、今の第2巻・第3巻の表紙を縮めたもの。

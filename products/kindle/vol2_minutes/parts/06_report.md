# 第7章　報告書のたたき台

まとめたメモをもとに、上司への報告や週報、トラブルの報告などの「たたき台（下書き）」を作る場面です。

> **ぷるの**：たたき台は「70点でいいから早く出す」ためのもの。残りの30点は、人が足すんだ。

---

## テンプレ36　議事録から、上司への報告メールを作る

**① 場面**
会議に出ていない上司に、結果をメールで報告したい。

**② コピペ用の頼み方**

```
以下の会議メモをもとに、［上司の呼び方：例 店長］への報告メールの下書きを作ってください。

・件名もつける
・本文は「結論（決まったこと）→ 保留 → 相談したいこと」の順
・相談したいこと：［例：なし／〇〇について判断がほしい］
・メモにないことは書かない
・最後に、送る前に確認したほうがいい所を箇条書きで書く（メールとは別に）

---ここから---
［ここに会議メモを貼る］
---ここまで---
```

**③ 試した出力例**
（入力：素材A、上司＝店長、相談したいこと＝SNS告知の回数を増やしてよいか、店長の考えを聞きたい）

```
件名：10/14 販促ミーティングのご報告

店長

おつかれさまです。10/14の販促ミーティングの結果をご報告します。

■決まったこと
・秋の手帳フェアの売上が先週よりやや下がっているため、棚を入口横に移します（山田さん了承）。
・レイアウト図は木村さんが来週月曜までに、POPは林さんが黄色ベースで金曜までに作ります。
・B5手帳の在庫が少ないため、林さんが今日中に発注を確認します。
・年末の大掃除は12/27で仮決めしました。

■保留
・SNSでの告知回数（週2回→週3回）は結論が出ず、次回10/21に話し合います。

■ご相談
SNSの告知回数を増やすことについて、店長のお考えを、次回の会議までにお聞かせいただけますと助かります。

以上、よろしくお願いいたします。

───
【送る前に確認したほうがいい所】
・「来週月曜」「金曜」を、日付で書くかどうか
・売上が「やや下がっている」の程度（数字を入れるか）
・大掃除の日程について、欠席の森さんに確認する人
```

**④ うまくいかないときの直し方**
- **お詫びや前置きが長い** → 「前置きは1行だけ」と書く。
- **自分の名前や署名がない** → この下書きには署名がありません。自分で足すか、［　］に「署名：〇〇」と書いておく（第2章のとおり、本名を入れたくないときは、あとで自分で足すのが安全です）。

## テンプレ37　1週間の箇条書きから、週報を作る

**① 場面**
毎週の週報。やったことのメモはあるけれど、文章にする時間がない。

**② コピペ用の頼み方**

```
以下の1週間のメモから、週報の下書きを作ってください。

・見出しは「今週やったこと」「うまくいったこと」「困っていること」「来週の予定」
・メモにないことは書かない。当てはまる内容がない見出しは「特になし」
・全体で［例：300字］くらい

---ここから---
［ここに1週間のメモを貼る］
---ここまで---
```

**③ 試した出力例**
（入力：架空のメモ「月：手帳フェアの棚移動のレイアウト図提出 ／ 火：棚を入口横に移動、林さんと2人で ／ 水：販促ミーティング ／ 木：POP設置。お客さんに"見やすくなった"と言われた ／ 金：B5手帳 入荷が来週にずれると連絡あり ／ 来週：SNS告知の回数決める」）

```
【週報】

■今週やったこと
・手帳フェアの棚を移すためのレイアウト図を提出しました（月）。
・林さんと2人で、棚を入口横に移しました（火）。
・販促ミーティングに出ました（水）。
・POPを設置しました（木）。

■うまくいったこと
・POPを設置したあと、お客さまから「見やすくなった」と言っていただきました。

■困っていること
・B5手帳の入荷が来週にずれると連絡がありました。

■来週の予定
・SNS告知の回数を決めます。
```

**④ うまくいかないときの直し方**
- **「売上アップが期待されます」などの予想が足される** → 「予想や感想を足さない」と書く。
- **字数より短くなる** → メモが短いと、週報も短くなります。それでOKです。字数を合わせるために中身を足されるほうが困るので、「字数より短くてもいいので、中身を足さないでください」と書くのがおすすめです。

## テンプレ38　「ためしてみた結果」を、報告書の形にする

**① 場面**
新しいやり方を試した結果を、きちんとした報告書にまとめたい。

**② コピペ用の頼み方**

```
以下の文章を、報告書の形に整えてください。

・見出しは「1. 目的」「2. 実施内容」「3. 結果」「4. 課題」「5. 今後の案」「6. 次回の報告予定」
・数字は元の文章のとおりに書く。計算や言いかえはしない
・元の文章にないことは書かない。当てはまる内容がない見出しは「記載なし」

---ここから---
［ここに文章を貼る］
---ここまで---
```

**③ 試した出力例**（入力：素材B）

```
「本とコーヒー割」実施報告

1. 目的
平日14〜16時の空席を減らすため。

2. 実施内容
・期間：9月の1か月間
・時間：平日14時〜16時
・内容：店の本棚の本を読みながら過ごすお客さま向けに、ドリンクを50円引き

3. 結果
・14〜16時の客数：8月 1日平均18人 → 9月 1日平均23人
・平均滞在時間：約40分 → 約65分
・売上（同時間帯）：割引分を差し引いても、8月より1日平均およそ2,000円増
・15時台に満席となり、テイクアウト以外のお客さまをお断りした日が3日あった

4. 課題
・フードの注文が増えておらず、ドリンク1杯で長く過ごす方が多い印象
・スタッフから「満席時の案内が気まずい」との声
（良い声：「静かに過ごす方が多く、店の雰囲気が良くなった」）

5. 今後の案
①10月も続け、対象を14〜15時半に短くする（すぐ実施可能）
②フードとセットの場合のみ割引にする（メニュー表の作り直しが必要）
③満席時の案内カードを作る（すぐ実施可能）

6. 次回の報告予定
10月末に数字を確認し、11月以降の方針を相談する。
```

**④ うまくいかないときの直し方**
- **「目的」が書かれていない文章だと、AIが目的を作る** → この例では「空席が目立っていた」というきっかけから目的を書いています。元の文章に目的がはっきりないときは「目的は〇〇」と自分で書いて渡すほうが確実です。
- **会社の報告書の形がある** → 見出しの部分を、自社の形式に書きかえてください。

## テンプレ39　トラブルの報告（経緯・原因・対策）のたたき台を作る

**① 場面**
ちょっとしたトラブルが起きた。報告書を早く出したいが、まとまらない。

**② コピペ用の頼み方**

```
以下のメモをもとに、トラブル報告のたたき台を作ってください。

・見出しは「何が起きたか」「経緯（時間の順）」「原因（わかっていること／まだわからないこと）」「すでにしたこと」「これからすること」
・原因は、メモに書かれていることだけ。推測は「（推測）」とつけて分ける
・人を責める書き方はしない

---ここから---
［ここにメモを貼る］
---ここまで---
```

**③ 試した出力例**
（入力：架空のメモ「10/9 朝、レジ横のPOPの値段が旧価格のまま。お客さま1名に指摘されて気づく。10時ごろ差しかえ。差額は返金済み。価格変更の連絡はメールで来てたが、POPの担当に回ってなかったっぽい。今後：価格変更のときはチェック表？」）

```
【トラブル報告（たたき台）】

■何が起きたか
10/9の朝、レジ横のPOPに旧価格が書かれたままになっていた。

■経緯（時間の順）
・10/9 朝：お客さま1名からの指摘で、POPの価格が旧価格のままであることに気づいた。
・同日 10時ごろ：POPを差しかえた。
・差額は、お客さまに返金済み。

■原因
【わかっていること】
・価格変更の連絡はメールで届いていた。
【まだわからないこと】
・連絡がPOPの担当者に伝わっていなかったかどうか。
　（推測）メールがPOPの担当者に回っていなかった可能性がある。

■すでにしたこと
・POPの差しかえ
・お客さまへの差額の返金

■これからすること
・価格変更のときに使うチェック表を作るかどうか検討する（案の段階）。
```

**④ うまくいかないときの直し方**
- **「担当者の確認不足」など、だれかのせいにする書き方になる** → 「人ではなく、しくみの問題として書いてください」と足す。
- **「っぽい」「？」のあいまいさが消えて、断定になる** → この例では「（推測）」「案の段階」と分けてくれましたが、消えることもあります。メモのあいまいな所は、報告書でもあいまいなまま残っているか確認しましょう。

## テンプレ40　報告書を書く前に「構成案」だけ作ってもらう

**① 場面**
報告書を一から書くのはたいへん。まず、どんな順番で何を書くかだけ決めたい。

**② コピペ用の頼み方**

```
これから［例：〇〇の報告書］を書きます。構成案（見出しと、それぞれに書くことのメモ）を作ってください。

・読む人：［例：店のオーナー］
・読む人が知りたいこと：［例：続けるかやめるか判断したい］
・手元にある材料：
［ここに材料を箇条書きで書く］
・本文はまだ書かない。見出しと「ここに〇〇を書く」というメモだけ
・材料が足りない見出しには「材料が足りない：〇〇」と書く
```

**③ 試した出力例**
（入力：報告書＝「本とコーヒー割」10月の報告／読む人＝オーナー／知りたいこと＝11月以降も続けるか／材料＝9月の結果（素材B）、10月は14〜15時半に短縮して実施、案内カードを作った）

```
【構成案：「本とコーヒー割」10月の報告】

1. 結論（続けたいかどうか）
　ここに、11月以降の店長としての考えを1〜2行で書く。
　材料が足りない：10月の結果と、店長の考え

2. 10月にしたこと
　ここに、時間を14〜15時半に短くしたことと、案内カードを作ったことを書く。

3. 結果（9月と10月のくらべ）
　ここに、客数・滞在時間・売上・お断りした日数を、9月と並べて書く。
　材料が足りない：10月の数字

4. 案内カードの効果
　ここに、満席時の案内がどう変わったか（スタッフの声など）を書く。
　材料が足りない：スタッフの声

5. 残っている課題
　ここに、フードの注文の様子などを書く。
　材料が足りない：10月のフードの注文の様子

6. 11月以降の案と、相談したいこと
　ここに、続ける場合・やめる場合の案と、オーナーに決めてほしいことを書く。
```

**④ うまくいかないときの直し方**
- **構成案ではなく、本文を書きはじめる** → 「本文はまだ書かない」を一番上に書く。
- **見出しが多すぎる** → 「見出しは5つまで」と数を決める。

## テンプレ41　報告書を「A4・1枚」に収まる長さにまとめる

**① 場面**
報告書が長くなりすぎた。1枚にまとめるように言われた。

**② コピペ用の頼み方**

```
以下の報告書を、［例：A4・1枚、約600字］に収まるように短くしてください。

・必ず残すこと：［例：数字の結果、今後の案、相談したいこと］
・削ってよいこと：［例：きっかけの説明、スタッフの声のくわしい内容］
・数字は変えない
・最後に「削った内容」を箇条書きで書く（あとで聞かれたときのため）

---ここから---
［ここに報告書を貼る］
---ここまで---
```

**③ 試した出力例**
（入力：素材B、約300字に短く、必ず残すこと＝数字の結果・今後の案、削ってよいこと＝スタッフの声）

```
9月、平日14〜16時に「本とコーヒー割」（ドリンク50円引き）を試しました。
14〜16時の客数は1日平均18人から23人に増え、売上も割引分を引いて1日平均およそ2,000円増えました。一方、滞在時間が約40分から約65分に延び、15時台の満席でお断りした日が3日ありました。フードの注文は増えていません。
今後は、①対象を14〜15時半に短くして続ける、②フードとセットの場合だけ割引にする、③満席時の案内カードを作る、の3案を考えています。①③はすぐできますが、②はメニュー表の作り直しが必要です。
10月末に数字を見て、11月以降をご相談させてください。

【削った内容】
・きっかけ（この時間帯に空席が目立っていたこと）
・ドリンク1杯で長く過ごす方が多い印象
・スタッフの声（雰囲気が良くなった／満席時の案内が気まずい）
```

**④ うまくいかないときの直し方**
- **「A4・1枚」がどのくらいかは、文字の大きさや余白で変わる** → AIは紙の大きさで長さを判断できないので、字数で指定するほうが確実です。
- **残してほしい内容まで削られる** → 「必ず残すこと」をもっと具体的に書く。

## テンプレ42　報告書の「わかりにくい所」を読み手の目線で指摘してもらう

**① 場面**
報告書を書き終えた。提出する前に、読む人にとってわかりにくい所がないか見てほしい。

**② コピペ用の頼み方**

```
以下の報告書を、［読む人：例 この件を初めて聞くオーナー］になったつもりで読んで、
わかりにくい所・質問したくなる所を、5つまで指摘してください。

・書き直しはしない。指摘と、その理由だけ
・大事な順に並べる

---ここから---
［ここに報告書を貼る］
---ここまで---
```

**③ 試した出力例**（入力：素材B、読む人＝この件を初めて聞くオーナー）

```
1. 店長としては、どの案がいちばんよいと考えているのか
　理由：3つの案が並んでいますが、おすすめが書かれていないため、判断のきっかけがつかみにくいです。

2. お断りした3日間で、どのくらいのお客さまをお断りしたのか
　理由：日数はわかりますが、人数がないと、影響の大きさがつかめません。

3. 売上「およそ2,000円増」は、何と何をくらべた数字か
　理由：8月とくらべていることは書かれていますが、8月の同じ時間帯の売上がいくらかがないため、増え方の大きさがわかりにくいです。

4. 「本とコーヒー割」を使ったお客さまは、23人のうち何人か
　理由：客数が増えた理由が割引なのか、ほかの理由なのかが読み取りにくいです。

5. 案②のメニュー表の作り直しには、どのくらいの手間や費用がかかるのか
　理由：「すぐにできない」案を選ぶかどうか判断するのに必要です。
```

**④ うまくいかないときの直し方**
- **指摘が細かすぎる（言葉づかいなど）** → 「内容に関する指摘だけ」と書く。
- **指摘どおりに直すべきかは、自分で判断する** → AIの指摘は「読む人の気持ちの想像」です。すべてに答える必要はありません。

## テンプレ43　報告書の数字を、表やグラフ用の形にまとめる

**① 場面**
報告書の数字を、表計算ソフトで表やグラフにしたい。

**② コピペ用の頼み方**

```
以下の文章から、［例：くらべている前と後］の数字を取り出して、表計算ソフトに貼れる形にしてください。

・1行目は見出し（項目、［前］、［後］、単位）
・タブ区切りで出す
・文章にない数字は空欄にする。計算はしない

---ここから---
［ここに文章を貼る］
---ここまで---
```

**③ 試した出力例**（入力：素材B、前＝8月、後＝9月）
※実際の出力はタブ区切りです。本では読みやすいように表にしています。

| 項目 | 8月 | 9月 | 単位 |
|---|---|---|---|
| 14〜16時の客数（1日平均） | 18 | 23 | 人 |
| 平均滞在時間 | 約40 | 約65 | 分 |
| 満席でお断りした日 | （空欄） | 3 | 日 |
| 売上の増加（1日平均、8月比） | （空欄） | およそ2,000 | 円 |

**④ うまくいかないときの直し方**
- **「約」「およそ」がついた数字は、グラフにしにくい** → この例では残してくれました。グラフにするときは「約」を外すかどうか自分で判断し、グラフの注に「約」と書いておくと正直です。
- **「8月の滞在時間は約40分」と、元の文章にない月を当てはめる** → この例の「約40分」は、元の文章では「8月」とははっきり書かれていません（「約40分から約65分に延びました」）。こうした読み取りがないか、元の文章と見くらべてください。

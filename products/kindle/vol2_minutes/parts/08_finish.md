# 第9章　仕上げ・確認

できあがった議事録や報告書を、送る前に整える場面です。

## テンプレ52　誤字・脱字をチェックしてもらう

**① 場面**
議事録や報告書を送る前に、誤字脱字がないか見てほしい。

**② コピペ用の頼み方**

```
以下の文章の誤字・脱字・変換ミスをチェックしてください。

・直した文章は出さず、「まちがい」「直し方」「何行目か」を一覧にする
・言い回しの好みは指摘しない（まちがいだけ）
・人の名前・商品名・社内の言葉は、まちがいかどうか判断せず「要確認」とする

---ここから---
［ここに文章を貼る］
---ここまで---
```

**③ 試した出力例**
（入力：架空の文章「1行目：本日の会議の議事禄を送ります。／2行目：POPは金曜日までに作成しまします。／3行目：ご確認のほど、よろしくおねがいします。／4行目：次回は10/21 10時からでず。」）

```
| 何行目か | まちがい | 直し方 |
|---|---|---|
| 1行目 | 議事禄 | 議事録 |
| 2行目 | 作成しまします | 作成します |
| 4行目 | からでず | からです |

※3行目の「おねがいします」はひらがなでもまちがいではありません。表記をそろえたい場合は「お願いします」にできます。
```

**④ うまくいかないときの直し方**
- **まちがいではない所まで直される** → 「まちがいだけ」と強めに書く。
- **見落としがある** → AIのチェックも完全ではありません。とくに数字・日付・名前は、自分で読み合わせをしてください。

## テンプレ53　敬語・言い回しを、相手に合わせて整える

**① 場面**
議事録や報告を、目上の人や社外の人に送る。言葉づかいが失礼になっていないか心配。

**② コピペ用の頼み方**

```
以下の文章を、［相手：例 取引先の担当者／上司］に送ります。
敬語や言い回しで、失礼に聞こえる所・くだけすぎた所を直してください。

・内容（事実・数字・日付）は変えない
・直した所は、元の言い方と直した言い方を並べて一覧にする
・そのあとに、直した文章の全体を出す

---ここから---
［ここに文章を貼る］
---ここまで---
```

**③ 試した出力例**
（入力：相手＝上司、架空の文章「おつかれさまです。会議の結果、送っときます。POPは林さんが金曜までにやってくれるそうです。SNSの件はまだ決まってないので、次回また話します。了解しました。」）

```
【直した所】
・「送っときます」→「お送りします」
・「やってくれるそうです」→「作成してくれることになりました」
・「まだ決まってないので」→「まだ決まっていないため」
・「次回また話します」→「次回あらためて話し合います」
・「了解しました」→ 文の最後にあると意味がわかりにくいため、「以上です。よろしくお願いいたします。」に置きかえました。

【直した文章】
おつかれさまです。会議の結果をお送りします。
POPは、林さんが金曜までに作成してくれることになりました。
SNSの件はまだ決まっていないため、次回あらためて話し合います。
以上です。よろしくお願いいたします。
```

**④ うまくいかないときの直し方**
- **ていねいすぎて長くなる** → 「社内の上司なので、ていねいすぎない言い方で」と、距離感を伝える。
- **「了解しました」の扱いのように、AIが文の意味を読み取って変える** → 置きかえた理由を一覧で見せてもらうと、意図しない変更に気づけます。

## テンプレ54　チャットに貼れる、ひとことの共有文にする

**① 場面**
議事録はできた。チャットでは、全文ではなく「ひとこと＋リンク」で共有したい。

**② コピペ用の頼み方**

```
以下の議事録を、チームのチャットで共有するための短い文にしてください。

・2〜3行
・1行目に、何の議事録か
・2行目以降に、とくに見てほしいこと（担当者がいる作業など）
・最後に「詳しくはこちら：［議事録の置き場所］」と入れる

---ここから---
［ここに議事録を貼る］
---ここまで---
```

**③ 試した出力例**（入力：テンプレ01の出力、置き場所＝［共有フォルダのリンク］のまま）

```
10/14の販促ミーティングの議事録です。
手帳フェアの棚を入口横に移します。木村さん（レイアウト図・来週月曜）、林さん（POP・金曜／B5手帳の発注確認・今日中）、ご確認ください。
詳しくはこちら：［共有フォルダのリンク］
```

**④ うまくいかないときの直し方**
- **名前をたくさん入れると長くなる** → 「名前は入れず、『担当の方は確認をお願いします』とまとめて」と頼む。
- **［　］が、それらしいURLに勝手に置きかえられる** → AIがありもしないリンクを作ることがあります。「［　］の所はそのまま残してください」と書き、リンクは自分で貼りましょう。

## テンプレ55　自分専用の「頼み方テンプレ」を、AIといっしょに作る

**① 場面**
この本のテンプレを、自分の職場の形式に合わせて作りかえたい。

**② コピペ用の頼み方**

```
私は、［例：毎週の定例会議の議事録］をAIにまとめてもらいたいと思っています。
次の条件を入れた「頼み方のテンプレ」を作ってください。

・私の職場の議事録の形式：［例：見出しは「決定事項」「継続審議」「宿題」］
・気をつけたいこと：［例：メモにないことを足さない／名前は役職で書く］
・テンプレの中で、毎回書きかえる所は［　］で示す
・テンプレのあとに、使うときの注意を3つまで書く
```

**③ 試した出力例**
（入力：毎週の定例会議の議事録／形式＝見出しは「決定事項」「継続審議」「宿題」／気をつけたいこと＝メモにないことを足さない、名前は役職で書く）

```
【頼み方のテンプレ】
以下の会議メモを、議事録にまとめてください。

【形式】
・見出しは「決定事項」「継続審議」「宿題」の3つ
・「宿題」には、担当（役職）と期限を書く。書かれていなければ「不明」

【ルール】
・メモに書かれていないことは足さない
・人の名前は書かず、役職（例：課長、担当者）で書く
・わからない所は「（不明）」と書く

会議名：［会議の名前］
日付：［会議の日付］
---ここから---
［ここに会議メモを貼る］
---ここまで---

【使うときの注意】
1. メモの中で、名前と役職の対応がわかるようにしておく（例：「田中＝課長」を最初に書く）。
2. 「来週」などの期限は、送る前に日付で確認する。
3. できた議事録は、メモと見くらべてから共有する。
```

**④ うまくいかないときの直し方**
- **注意1のように、名前をAIに入れる前提になる** → 第2章のとおり、名前をAIに入れたくないときは、**メモの段階で自分で役職に置きかえてから**貼るのが安全です。そのように、テンプレの注意を書きかえてもOKです。
- **できたテンプレがうまく動かない** → いちど架空のメモで試してから、本番で使いましょう。この本の素材A〜Fも、試し用に使えます。

# おわりに

> **ぷるの**：ここまで読んでくれて、ありがとう！ぷるぷる。

この本では、議事録・要約まわりの55個の頼み方を紹介しました。
最後に、この本でくり返しお伝えしてきたことを、3つにまとめます。

1. **「足さない」「不明と書く」を先に言う。** まとめる仕事では、AIが気をきかせて足した一文が、いちばんのトラブルのもとになります。
2. **日付・数字・名前は、人が確かめる。** この本の出力例でも、AIが日付を計算したり、言葉を言いかえたりする場面がありました。合っていることも多いですが、確認は人の仕事です。
3. **入れる前に、置きかえる。** 名前や取引先は、記号にしてから貼る。会社のルールがあれば、それに従う。

この本の出力例は、架空の素材でAIが出した、ある1回の結果です。みなさんが同じ頼み方をしても、まったく同じ答えにはなりません。うまくいかなかったら、各テンプレの「直し方」を見ながら、少しずつ頼み方を変えてみてください。

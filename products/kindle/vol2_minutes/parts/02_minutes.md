# 第3章　会議の議事録

会議のあとに残った走り書きを、ほかの人が読める「議事録」にする場面です。
この章のテンプレは、ほとんどが**素材A（架空の会議メモ）**で試しています。

> **ぷるの**：議事録で大事なのは「決まったこと」「だれが」「いつまでに」。この3つがそろっていれば、だいたい勝ち！

---

## テンプレ01　走り書きのメモを、議事録の形に整える

**① 場面**
会議中にとったメモが、自分にしか読めない状態。チームに共有できる形にしたい。

**② コピペ用の頼み方**

```
以下の会議メモを、議事録の形に整えてください。

【ルール】
・見出しは「日時」「出席者」「欠席者」「話し合ったこと」「決まったこと」「保留」「次回」にする
・メモに書かれていないことは足さない
・わからない所は「（不明）」と書く

---ここから---
［ここに会議メモを貼る］
---ここまで---
```

**③ 試した出力例**（入力：素材A）

```
■日時：10/14（時刻は不明）
■会議名：販促ミーティング（みどり文具）
■出席者：山田（リーダー）、木村、林
■欠席者：森

■話し合ったこと
・秋の手帳フェアの売上が、先週よりやや下がっている。
　木村さんから「棚の位置が奥すぎるのでは」という意見があった。
・SNSでの告知回数を、週2回から週3回に増やすかどうか。

■決まったこと
・手帳フェアの棚を入口横に移す（山田さん了承）。
　レイアウト図は木村さんが来週月曜までに作る。
・POPは林さんが作る。黄色ベース。金曜まで。
・B5手帳の在庫が少ないため、林さんが今日中に発注を確認する。

■保留
・SNS告知の回数（週2→週3）：結論が出ず、次回に持ちこし。
・年末の大掃除：12/27で仮決定。森さんへの確認が必要（確認する人は不明）。

■次回
・10/21　10時〜
```

**④ うまくいかないときの直し方**
- **「次回までに各自検討」など、メモにない一文が足された** → 「メモにない文はすべて消して、もう一度出してください」と頼む。【ルール】の「足さない」を一番上に移すのも効きます。
- **見出しが会社の形式とちがう** → 見出しの行を、自社の議事録の見出しに書きかえてから頼む。
- **「来週月曜」などがそのまま残る** → これは正しい動きです。日付に直したいときは、テンプレ04を続けて使ってください。

## テンプレ02　「決まったこと」「保留」「やること」の3つに分ける

**① 場面**
議事録の形にするほどでもないけれど、結局なにが決まったのかだけ、パッと知りたい。

**② コピペ用の頼み方**

```
以下の会議メモを読んで、次の3つに分けて箇条書きにしてください。
1. 決まったこと
2. 決まらなかったこと（保留）
3. だれかがやること（担当者と期限つき。書かれていなければ「担当：不明」「期限：不明」）

メモにないことは書かないでください。

---ここから---
［ここに会議メモを貼る］
---ここまで---
```

**③ 試した出力例**（入力：素材A）

```
1. 決まったこと
・手帳フェアの棚を入口横に移す
・POPは黄色ベースで作る
・年末の大掃除は12/27（仮）
・次回は10/21 10時〜

2. 決まらなかったこと（保留）
・SNS告知を週2回から週3回に増やすか（次回に話す）

3. だれかがやること
・レイアウト図を作る　担当：木村　期限：来週月曜
・POPを作る　担当：林　期限：金曜
・B5手帳の発注を確認する　担当：林　期限：今日中
・大掃除の日程を森さんに確認する　担当：不明　期限：不明
```

**④ うまくいかないときの直し方**
- **「仮」の決定が「決まったこと」に入ってしまう** → この例でも12/27が「決まったこと」に入りました。気になるときは「『仮』『予定』と書かれたものは保留に入れてください」と1行足します。
- **3つの分け方が自分の感覚とちがう** → 「〇〇は保留に移してください」と、1つずつ指示して直すのが早いです。

## テンプレ03　欠席した人向けに「3行でわかる」共有文を作る

**① 場面**
会議を休んだ人に、チャットで要点だけ伝えたい。

**② コピペ用の頼み方**

```
以下の会議メモをもとに、会議を欠席した［欠席した人の呼び方］さんに送る、チャット用の短い共有文を作ってください。

・最初にあいさつを1行
・要点は3行以内
・［欠席した人の呼び方］さんに関係することがあれば、最後に別にして書く
・メモにないことは書かない

---ここから---
［ここに会議メモを貼る］
---ここまで---
```

**③ 試した出力例**（入力：素材A、欠席した人＝森）

```
森さん、おつかれさまです。10/14の販促ミーティングの共有です。

・手帳フェアの棚を入口横に移すことになりました（レイアウト図は木村さん）。
・POPは林さんが黄色ベースで作ります。SNS告知の回数は次回に持ちこしです。
・次回は10/21の10時からです。

【森さんに関係すること】
年末の大掃除を12/27で仮決めしています。森さんのご都合を確認させてください。
```

**④ うまくいかないときの直し方**
- **3行に収まらず長くなる** → 「1行は40字以内」と字数も指定する。
- **ていねいすぎる／くだけすぎる** → 「同僚に送る、ややくだけた言い方で」「上司に送るていねいな言い方で」と相手を書く。
- **欠席者に関係する話がないのに、無理に作る** → 「関係することがなければ、その欄は書かないでください」と足す。

## テンプレ04　議事録の「抜け」を指摘してもらう

**① 場面**
議事録を送る前に、担当者や期限が抜けていないか、あいまいな所がないか確認したい。

**② コピペ用の頼み方**

```
以下の議事録（またはメモ）を、送る前にチェックしてください。
直すのではなく、気になる所を一覧で指摘してください。

【チェックすること】
・担当者が書かれていないやること
・期限が書かれていない、またはあいまいなもの（「来週」「今度」など）
・読む人によって意味が変わりそうな言葉
・決まったのか決まっていないのか、わかりにくいもの

---ここから---
［ここに議事録を貼る］
---ここまで---
```

**③ 試した出力例**（入力：素材A）

```
【担当者がない】
・「森さんに確認いる（だれが？）」：森さんに確認する人が決まっていません。

【期限があいまい】
・「来週月曜まで」：会議日（10/14）から見て、具体的な日付を書くと安心です。
・「金曜まで」：今週の金曜か、来週の金曜か、日付で書くと確実です。
・「今日中」：会議日の10/14のことだと思われますが、念のため日付を書くとよいです。

【意味が変わりそうな言葉】
・「ちょい下」：どのくらい下がったか（数字や割合）があると、休んだ人にも伝わりやすいです。
・「黄色ベース」：店のロゴの黄色など、具体的な色の指定があればそろえやすいです。

【決まったかどうかわかりにくい】
・「12/27で仮」：仮決定なのか、ほぼ決定なのか。いつ正式に決めるかを書くとよいです。
・「週2→週3？」：保留であることを、はっきり書くとよいです。
```

**④ うまくいかないときの直し方**
- **指摘ではなく、勝手に書き直してしまう** → 「書き直さないでください。指摘だけ一覧にしてください」と強めに言う。
- **「来週月曜」を、AIが勝手に日付に直す** → 会議の日付や曜日をAIが取りちがえることがあります。日付への置きかえは、**カレンダーを見て自分で**するのが安全です。
- **指摘が多すぎる** → 「大事な順に5つまで」と数をしぼる。

## テンプレ05　会議の前に、アジェンダ（話す順番）を作る

**① 場面**
会議で話したいことはあるけれど、順番や時間配分が決まっていない。

**② コピペ用の頼み方**

```
次の会議のアジェンダ（議題と時間配分）を作ってください。

・会議の時間：［例：30分］
・目的：［例：来月のイベントの担当を決める］
・話したいこと：
［ここに話したいことを箇条書きで書く］

【ルール】
・決めなければいけないことを先に置く
・それぞれに「決めること」または「共有するだけ」を書く
・時間の合計が会議の時間に収まるようにする
```

**③ 試した出力例**
（入力：架空。時間30分／目的「年末の大掃除と手帳フェアの続きを決める」／話したいこと「SNS告知の回数」「大掃除の担当」「手帳フェアの棚を移したあとの様子」「POPの感想」）

```
【販促ミーティング　アジェンダ（30分）】
目的：年末の大掃除と手帳フェアの続きを決める

1. SNS告知の回数（週2→週3）　8分　【決めること】
2. 年末の大掃除の担当　8分　【決めること】
3. 手帳フェア：棚を移したあとの様子　7分　【共有するだけ】
4. POPの感想　5分　【共有するだけ】
5. まとめ・次回の日程　2分

合計：30分
```

**④ うまくいかないときの直し方**
- **時間の合計が合わない** → AIは足し算をまちがえることがあります。「最後に合計時間を計算して、会議の時間と合っているか確かめてください」と足すか、自分で足し算して確認する。
- **議題が勝手に増える** → 「話したいことにない議題は足さないでください」と書く（この例の「まとめ・次回の日程」のような、進行のための項目は残してよいかも決めておく）。

## テンプレ06　前回の議事録から、今回のアジェンダを作る

**① 場面**
定例会議。前回の「保留」や「宿題」を、今回ちゃんと確認したい。

**② コピペ用の頼み方**

```
以下は前回の会議の議事録（またはメモ）です。
これをもとに、今回の会議のアジェンダを作ってください。

・前回の「やること」は、それぞれ「進み具合の確認」として入れる
・前回の「保留」は、「決めること」として入れる
・新しい議題は足さず、最後に「その他」の枠だけ作る

---ここから---
［ここに前回の議事録を貼る］
---ここまで---
```

**③ 試した出力例**（入力：素材A）

```
【10/21 販促ミーティング　アジェンダ】

■前回のやることの確認
1. レイアウト図（木村さん）：できたか確認
2. 手帳フェアの棚の移動：入口横に移せたか確認
3. POP（林さん）：できたか確認
4. B5手帳の発注（林さん）：発注できたか確認

■決めること
5. SNS告知の回数：週2回のままか、週3回に増やすか
6. 年末の大掃除：12/27でよいか（森さんの都合の確認結果）

■その他
7. その他
```

**④ うまくいかないときの直し方**
- **「確認」だけでなく、AIが勝手に結論を書く** → 「結論や予想は書かず、議題名だけにしてください」と足す。
- **前回の議事録が長すぎて、一部が抜ける** → 前回の「決まったこと」「保留」「やること」の部分だけを貼る。

## テンプレ07　上司やほかの部署に出す、ていねいな議事録にする

**① 場面**
チーム内のメモを、上司や他部署にも共有することになった。言葉づかいを整えたい。

**② コピペ用の頼み方**

```
以下の会議メモを、［読む人：例 部長／ほかの部署の人］に提出する、ていねいな議事録にしてください。

・です・ます調、または「〜する」「〜とした」の文末にそろえる（［どちらか選ぶ］）
・くだけた言葉（「ちょい」「OK」など）は、ふつうの言葉に直す
・内容は足さない、減らさない

---ここから---
［ここに会議メモを貼る］
---ここまで---
```

**③ 試した出力例**（入力：素材A、読む人＝店長、文末＝「〜する」「〜とした」）

```
販促ミーティング議事録

日時：10月14日
出席者：山田（リーダー）、木村、林
欠席者：森

1. 秋の手帳フェアについて
　売上が前週と比べてやや減少している。原因として、棚の位置が店の奥にあることが挙げられた。
　→ 棚を入口横に移すこととした（山田了承）。レイアウト図は木村が来週月曜までに作成する。
　→ POPは林が作成する。色は黄色を基調とする。期限は金曜。

2. SNSでの告知回数について
　週2回から週3回に増やす案が出たが、結論に至らず、次回に継続して検討する。

3. 在庫について
　B5手帳の在庫が少ないため、林が本日中に発注状況を確認する。

4. 年末の大掃除について
　12月27日で仮決定とした。欠席の森に都合を確認する必要がある（確認者は未定）。

次回：10月21日 10時〜
```

**④ うまくいかないときの直し方**
- **かたすぎて読みにくい** → 「社内向けなので、かたすぎない言い方で」と足す。
- **人の名前に「さん」をつけるか迷う** → 社外に出すときは名前を外すことが多いので、自社のルールに合わせて「名前には〇〇をつけてください」と指定する。
- **「原因として〜挙げられた」のように、意見が事実っぽくなる** → この例でも、木村さんの「棚が奥すぎ？」という疑問が、少し強い書き方になっています。「意見は『〜という意見があった』と書いてください」と足すと、ニュアンスが残りやすいです。

## テンプレ08　話した人ごとに、発言をまとめる

**① 場面**
録音の文字起こしから、「だれが、どんな意見を言ったか」を整理したい。

**② コピペ用の頼み方**

```
以下は会議の文字起こしです。話した人ごとに、主な発言を箇条書きでまとめてください。

・話者の呼び方：［例：話者1＝店長、話者2＝大野さん］
・意見と、引き受けたこと（「私がやります」など）は分けて書く
・言っていないことは書かない

---ここから---
［ここに文字起こしを貼る］
---ここまで---
```

**③ 試した出力例**（入力：素材C、話者1＝店長、話者2＝大野さん、話者3＝竹内さん）

```
■店長
【意見・進行】
・来月の期間限定メニューについて話したい（去年はかぼちゃのマフィン）。
・冷凍ペーストを使う案について、まず原価を調べてほしい。
・試食会は再来週の月曜の閉店後にする。
・ポスターは去年のものを使い回さず、新しく作りたい。

■大野さん
【意見】
・さつまいもは仕込み（蒸す、つぶす）に時間がかかるのでは。
・スタッフで試食会をやりたい。
【引き受けたこと】
・ポスターを作る。

■竹内さん
【意見】
・さつまいもがよい。お客さんから「さつまいもはないの？」と何回か聞かれた。
・仕込みの手間を減らすため、冷凍のペーストを使ってはどうか。
【引き受けたこと】
・冷凍ペーストの原価を、来週の水曜までに調べる。
```

**④ うまくいかないときの直し方**
- **「機関限定」「マッフィン」などの変換ミスを、AIがそのまま使う／勝手に直す** → この例では、AIが「期間限定」「マフィン」に直していました。直してほしくないとき、または直した所を知りたいときは「変換ミスと思われる所を直した場合は、直した所を最後に一覧にしてください」と足す（テンプレ46も参考に）。
- **話者の取りちがえ** → 文字起こしの話者の区切り自体がまちがっていることもあります。大事な発言は、録音を聞き直して確認してください。

## テンプレ09　議事録を表にする

**① 場面**
やることが多い会議。表にして、あとで進み具合を書きこめるようにしたい。

**② コピペ用の頼み方**

```
以下の会議メモから、やることを表にしてください。

・列は「No.」「やること」「担当」「期限」「状態」
・「状態」はすべて「未着手」にする
・担当や期限が書かれていなければ「不明」と書く
・表のあとに、表に入れなかった決定事項を箇条書きで書く

---ここから---
［ここに会議メモを貼る］
---ここまで---
```

**③ 試した出力例**（入力：素材A）

```
| No. | やること | 担当 | 期限 | 状態 |
|---|---|---|---|---|
| 1 | 手帳フェアのレイアウト図を作る | 木村 | 来週月曜 | 未着手 |
| 2 | POPを作る（黄色ベース） | 林 | 金曜 | 未着手 |
| 3 | B5手帳の発注を確認する | 林 | 今日中 | 未着手 |
| 4 | 年末の大掃除の日程を森さんに確認する | 不明 | 不明 | 未着手 |

【表に入れなかった決定事項】
・手帳フェアの棚を入口横に移す（山田さん了承）
・年末の大掃除は12/27で仮決め
・SNS告知の回数は次回に話す
・次回は10/21 10時〜
```

**④ うまくいかないときの直し方**
- **表がくずれて表示される** → 使うアプリによっては、表の記号（｜）がそのまま見えることがあります。「表ではなく、タブ区切りで出してください」と頼むと、表計算ソフトに貼りやすくなります。
- **「棚を移す」作業自体の担当が抜ける** → この例でも、棚を実際に移す人はメモに書かれていません。表を見て「担当がいない作業はないか」を自分でも確認しましょう。

## テンプレ10　オンライン会議のチャット欄から、議事録を作る

**① 場面**
オンライン会議で、話した内容の一部がチャット欄に流れていった。それを議事録にまとめたい。

**② コピペ用の頼み方**

```
以下は、会議やグループのチャットのやりとりです。
議事録として、次の形でまとめてください。

■決まったこと
■まだ決まっていないこと
■やること（担当・期限。なければ「不明」）

・時刻や「了解です」だけの発言は省く
・書かれていないことは足さない

---ここから---
［ここにチャットのやりとりを貼る］
---ここまで---
```

**③ 試した出力例**（入力：素材D）

```
■決まったこと
・秋の社内勉強会は11/12（木）15時から、3階の会議室で行う。
・お菓子と飲み物の予算は1万円以内。

■まだ決まっていないこと
・前日の買い出しに行く人（小川さんが、予定を見て明日返事する）。
・資料の印刷のタイミング（当日の朝で間に合うか）と部数（出欠しだい）。

■やること
```

**④ うまくいかないときの直し方**
- **「明日」を日付に直すとき、まちがえる** → この例では、発言の日付（10/15）から「10/16」と書いてくれましたが、いつもうまくいくとは限りません。日付は自分でも確かめてください。
- **「了解です」の人を担当者にしてしまう** → 「引き受けると言った人だけを担当者にしてください」と足す。

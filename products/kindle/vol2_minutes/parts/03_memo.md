# 第4章　メモの整理

スマホのメモ帳、付せん、ノートの切れはし。たまったメモを、使える形に並べかえる場面です。

> **ぷるの**：メモは「書いたときの自分」しか意味がわからないことが多いんだ。AIに分けてもらうと、未来の自分が助かるよ。

---

## テンプレ11　ばらばらのメモを、ジャンルごとに分ける

**① 場面**
仕事のこと、家のこと、思いつきがまざったメモを、ざっくり分けたい。

**② コピペ用の頼み方**

```
以下のメモを、ジャンルごとに分けてください。

・ジャンルは［例：仕事／家・買い物／やりたいこと／その他］
・どのジャンルにも入らないものは「その他」に入れる
・メモの文は書きかえず、そのまま使う

---ここから---
［ここにメモを貼る］
---ここまで---
```

**③ 試した出力例**（入力：素材E、ジャンル＝仕事／家・買い物／やりたいこと／その他）

```
【仕事】
・企画書、表紙だけ先に作る
・企画書の締切 金曜
・会議で「数字の根拠は？」と聞かれた件 調べ直す
・新人さん向けのマニュアル、古い

【家・買い物】
・電球 2個
・プリンターのインク
・母の誕生日 11月 何か送る

【やりたいこと】
・ジム 週1でいいから再開したい
・ブログのネタ：朝10分の片付け
・ブログ：100円ショップの収納

【その他】
・駅前のパン屋 火曜休み
```

**④ うまくいかないときの直し方**
- **ジャンル分けが自分の感覚とちがう**（例：ブログは「仕事」に入れたい） → 「ブログに関するものは仕事に入れてください」と、ルールを1つ足す。
- **メモの文が勝手に書きかえられる** → 「1文字も変えずに」と強めに書く。
- **ジャンルを自分で決めるのが面倒** → ［　］の所を「ジャンルは、メモを見て3〜5個に決めてください」に変えると、AIに決めてもらえます。

## テンプレ12　メモの中から、急ぎのものを先に並べる

**① 場面**
メモにやることがたまっている。どれから手をつけるか決めたい。

**② コピペ用の頼み方**

```
以下のメモから「やること」だけを取り出して、急ぐ順に並べてください。

・期限が書かれているものを先にする
・期限がないものは、そのあとにまとめる
・それぞれ、なぜその順番にしたか、ひとことそえる
・メモに書かれていない期限を、推測で決めない

---ここから---
［ここにメモを貼る］
---ここまで---
```

**③ 試した出力例**（入力：素材E）

```
【期限が書かれているもの】
1. 企画書（締切：金曜）……締切がはっきりしているため。
   ・表紙だけ先に作る、というメモもあるので、まず表紙から。
2. 母の誕生日に何か送る（11月）……月はわかっているが、日は書かれていないため2番目に。

【期限が書かれていないもの】
・「数字の根拠は？」と聞かれた件を調べ直す……仕事で聞かれたことなので、早めがよさそうです。
・新人さん向けのマニュアルを見直す
・電球を2個買う
・プリンターのインクを買う
・ジムを再開する（週1）
・ブログを書く（朝10分の片付け／100円ショップの収納）

※「駅前のパン屋 火曜休み」は、やることではなく情報なので外しました。
```

**④ うまくいかないときの直し方**
- **AIが「たぶん今週中」など、期限を勝手に決める** → 「期限が書かれていないものは『期限なし』とだけ書いてください」と足す。
- **自分の事情（誕生日の日付など）を反映したい** → 「母の誕生日は11/［日］です」のように情報を足してから、もう一度頼む。

## テンプレ13　箇条書きのメモを、ふつうの文章にする

**① 場面**
メモの箇条書きを、報告やメールに使える「文章」にしたい。

**② コピペ用の頼み方**

```
以下の箇条書きを、つながりのある文章にしてください。

・です・ます調
・［例：200字くらい］
・箇条書きにない情報は足さない
・順番は、読みやすいように入れかえてもよい

---ここから---
［ここに箇条書きを貼る］
---ここまで---
```

**③ 試した出力例**（入力：素材Aの「手帳フェア」に関する3行だけ、200字くらい）

```
秋の手帳フェアの売上が、先週と比べて少し下がっています。木村さんから「棚の位置が奥すぎるのではないか」という意見があり、棚を入口横に移すことになりました。山田さんも了承しています。移すためのレイアウト図は木村さんが来週月曜までに作り、あわせて林さんが黄色を基調にしたPOPを金曜までに作ります。
```

**④ うまくいかないときの直し方**
- **「これで売上の回復が期待されます」など、まとめの一文が足される** → AIは文章の最後に「しめの一文」を足したがることがあります。「最後にまとめや感想の文を足さないでください」と書いておく。
- **字数が大きくずれる** → AIは字数をぴったり守るのが苦手なことがあります。「〇字くらい」はあくまで目安にして、長ければ「もう2割短く」と頼み直す。

## テンプレ14　長い文章を、箇条書きにほどく

**① 場面**
メールや報告の文章が長くて、要点がつかみにくい。箇条書きにして見やすくしたい。

**② コピペ用の頼み方**

```
以下の文章を、箇条書きにしてください。

・1つの項目は1文で、できるだけ短く
・元の文章の順番を守る
・数字・日付・名前はそのまま残す
・元の文章にない言葉で言いかえない

---ここから---
［ここに文章を貼る］
---ここまで---
```

**③ 試した出力例**（入力：素材Bの2段落目と3段落目）

```
・14〜16時のお客さまの数は、8月の1日平均18人から、9月は1日平均23人に増えた。
・1人あたりの滞在時間が、平均約40分から約65分に延びた。
・そのため、15時台に満席になった。
・テイクアウト以外のお客さまをお断りした日が3日あった。
・この時間帯の売上は、割引分を差し引いても、8月より1日平均およそ2,000円増えた。
・ケーキなどのフードの注文は増えていない。
・ドリンク1杯だけで長く過ごす方が多い印象。
```

**④ うまくいかないときの直し方**
- **「印象」が事実のように書かれる** → この例では「〜印象」が残りましたが、消えてしまうこともあります。「『印象』『〜と思う』などの言葉は消さないでください」と足す。
- **項目が細かくなりすぎる** → 「10項目以内」と数を決める。

## テンプレ15　アイデアのメモから「次の一歩」を決める

**① 場面**
「やりたい」「いつか」と書いたまま、何も進んでいないメモがある。最初の一歩を決めたい。

**② コピペ用の頼み方**

```
以下のメモの中から「やりたいこと」「アイデア」にあたるものを選び、
それぞれ「5分でできる最初の一歩」を1つずつ提案してください。

・提案は1行で
・お金がかかることや、だれかに頼むことは入れない
・メモに書かれていない目標を勝手に作らない

---ここから---
［ここにメモを貼る］
---ここまで---
```

**③ 試した出力例**（入力：素材E）

```
・ジム 週1でいいから再開したい
　→ 今週、行けそうな曜日と時間を1つだけカレンダーに書く。

・ブログのネタ：朝10分の片付け
　→ 明日の朝、片付けた場所の「前」と「後」をメモに3行で書く。

・ブログ：100円ショップの収納
　→ いま家で使っている100円ショップの収納グッズを、メモに書き出す。

・新人さん向けのマニュアル、古い
　→ 古くなっている所を、気づいた順に3つだけメモする。
```

**④ うまくいかないときの直し方**
- **「最初の一歩」が大きすぎる** → 「もっと小さく。1分でできることにしてください」と頼み直す。
- **ジムの例のように、すでにやり方がわかっているものまで出てくる** → 「〇〇は外してください」と1つずつ外す。

## テンプレ16　メモの言葉づかい・表記をそろえる

**① 場面**
何人かで書いたメモや、日をまたいで書いたメモで、言葉の書き方（表記）がばらばら。

**② コピペ用の頼み方**

```
以下のメモの中で、同じものを指しているのに書き方がちがう言葉（表記ゆれ）を見つけて、
一覧にしてください。そのうえで、どれにそろえるとよいか提案してください。

・メモの内容は変えない
・どちらにそろえるか迷うものは「要相談」と書く

---ここから---
［ここにメモを貼る］
---ここまで---
```

**③ 試した出力例**
（入力：架空のメモ「・打ち合わせは来週。・打合せ資料はＡ４で2枚。・ミーティング後に議事録。・A4用紙を追加で発注。・お客様アンケート回収済み。・お客さまへのお礼メール」）

```
【表記ゆれの一覧】
1. 「打ち合わせ」「打合せ」「ミーティング」
　→ 提案：「打ち合わせ」にそろえる。
　　※「ミーティング」が別の会議を指している可能性もあるので「要相談」。
2. 「Ａ４」（全角）と「A4」（半角）
　→ 提案：半角の「A4」にそろえる。
3. 「お客様」と「お客さま」
　→ 提案：「お客さま」にそろえる（社内のルールがあれば、そちらに合わせてください）。
```

**④ うまくいかないときの直し方**
- **意味がちがうものまで「ゆれ」にされる** → この例のように、AIも「要相談」としてくれることがありますが、最後の判断は自分でしてください。
- **社内の決まった書き方がある** → 「表記のルール：〇〇は△△と書く」を先に貼っておくと、それに合わせてくれます。

## テンプレ17　手書きメモの「読めない所」を、候補つきで直す

**① 場面**
手書きのメモを書き写したら、読めない字があった。前後の文から、何と書いてあったか候補を出してほしい。

**② コピペ用の頼み方**

```
以下は手書きのメモを書き写したものです。読めなかった所を「？」にしています。
前後の文から、入りそうな言葉の候補を出してください。

・候補は1か所につき2〜3個
・どれが正しいかは決めつけない
・「？」以外の所は変えない

---ここから---
［ここに書き写したメモを貼る］
---ここまで---
```

**③ 試した出力例**
（入力：架空のメモ「・来月の？？会は、駅前の会館で。・参加ひは500円。・？？？の人は名札をつける」）

```
1つ目「来月の？？会は」
　候補：「新年会」「親睦会」「勉強会」
　（会館で開く行事で、参加費があるので、こうした集まりの名前が考えられます）

2つ目「参加ひは500円」
　「？」ではありませんが、「参加ひ」は「参加費」の書きまちがい・読みまちがいの可能性があります。

3つ目「？？？の人は名札をつける」
　候補：「初参加」「受付係」「スタッフ」
```

**④ うまくいかないときの直し方**
- **候補を1つに決めて、本文を書きかえてしまう** → 「本文は書きかえず、候補の一覧だけ出してください」と足す。
- **大事なメモ（日時・金額など）が読めない** → AIの候補はあくまで推測です。**書いた本人に確認する**のがいちばん確実です。

## テンプレ18　研修やセミナーのメモを、見出しつきのノートにする

**① 場面**
研修や勉強会で聞きながら書いたメモを、あとで見返せるノートにしたい。

**② コピペ用の頼み方**

```
以下は、研修を聞きながら書いたメモです。あとで見返せるノートに整えてください。

・内容ごとに小見出しをつける
・最後に「自分がやってみること」の欄を作る（メモに書かれているものだけ）
・メモにない説明は足さない。意味がわからない所は「（メモのみ）」と書いて残す

---ここから---
［ここにメモを貼る］
---ここまで---
```

**③ 試した出力例**
（入力：架空の研修メモ「・電話は3コール以内 ・名乗る→用件→相手の都合 ・メモは5W1H ・折り返しは"いつまでに"を言う ・クッション言葉→恐れ入りますが等 ・自分：折り返しの時間を言うのやってみる ・NG例 保留長い」）

```
【電話応対の研修ノート】

■出るとき
・3コール以内に出る。

■話す順番
・名乗る → 用件 → 相手の都合

■メモのとり方
・5W1Hでメモする。

■折り返しの電話
・「いつまでに」折り返すかを伝える。

■言葉づかい
・クッション言葉を使う（例：「恐れ入りますが」など）。

■よくない例
・保留が長い（メモのみ）

■自分がやってみること
・折り返しの電話で、時間を伝える。
```

**④ うまくいかないときの直し方**
- **研修で聞いていない説明（5W1Hの意味など）が足される** → 自分用なら便利なこともありますが、研修の記録として残すなら「説明を足さないでください」と書く。
- **「自分がやってみること」をAIが作り出す** → 「メモに『自分』と書かれているものだけ」と、目印を決めておくと見分けやすくなります。

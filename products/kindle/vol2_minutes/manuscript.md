# この本について

- この本は、AI（人工知能）が企画・執筆し、表紙もAI（プログラム）で作りました。
- のっている「出力例」は、この本を書いたAI（Anthropic社のClaude）が、**架空の会議メモや文章**を入力にして、テンプレどおりに頼んだときに出した結果です。長いものは一部を省いています。
- 入力に出てくる会社・お店・人の名前・数字は、**すべて架空**です。実在のものとは関係ありません。
- AIの答えは、**同じ頼み方でも毎回少しずつ変わります**。使うAIのサービスによっても変わります。「必ずこうなる」ものではなく、「こんな感じで返ってくることが多い」という目安として読んでください。
- 特定のAIサービスの機能・料金・設定については、この本では扱いません。お使いのサービスの公式の案内を確認してください。

# はじめに

> **ぷるの**：こんにちは。スライム国の案内係、スライムの「ぷるの」です。ぷるぷる。

会議が終わったあと、手元に残るのは、走り書きのメモ。
「あれ、これ誰がやるんだっけ？」「期限、いつって言ってた？」
長い報告書を読む時間がない。録音を文字にしたら「えーと」だらけで読めない。

そんな「まとめる仕事」は、AIがわりと得意な分野です。ただし、頼み方がふわっとしていると、AIもふわっとした答えを返してきます。

> **ぷるの**：「いい感じにまとめて」とだけ頼むと、メモに書いてない「次回までに検討」みたいな一文が、勝手に足されることがあるんだ。ぷるっとするよね。

この本では、**議事録・メモの整理・長文の要約・ToDoの抜き出し・報告書のたたき台・文字起こしの整形**の6つの場面で使える頼み方を、55個のテンプレにまとめました。

## この本の使い方

各テンプレは、次の4つでできています。

1. **場面**：どんなときに使うか
2. **コピペ用の頼み方**：そのままAIに貼れる文章です。**［　］の中**を、自分の内容に書きかえてください。
3. **試した出力例**：架空の素材を入れて、実際に頼んでみた結果です。
4. **うまくいかないときの直し方**：よくあるズレと、その直し方です。

使うときの流れは、とてもかんたんです。

1. 場面に合うテンプレを探す
2. 「コピペ用の頼み方」をコピーして、AIのチャット欄に貼る
3. ［　］の部分を書きかえる（メモや文章を貼る）
4. 送る。返ってきた答えを**自分の目で確認**する

> **ぷるの**：4番目がいちばん大事！AIのまとめは「下書き」。最後に人がチェックして完成だよ。

# 第1章　AIへの頼み方の基本

テンプレを使う前に、5つのコツを押さえておくと、自分でテンプレを直すときに迷いにくくなります。

## コツ1　「何をするか」を最初の1行で言う

AIは、最初に何を頼まれたかで、全体の方向を決めることが多いようです。「以下の会議メモを、議事録の形に整えてください。」のように、**動詞まで入れて1行目に書く**のがおすすめです。

## コツ2　「材料」と「お願い」を分ける

メモや文章を貼るときは、お願いの文と混ざらないように、区切りを入れます。この本のテンプレでは、

```
---ここから---
［ここにメモを貼る］
---ここまで---
```

のように、材料をはさむ形にしています。

## コツ3　「書かないこと」もはっきり言う

要約や議事録で一番こわいのは、**元のメモにないことをAIが足してしまう**ことです。「メモに書かれていないことは書かないでください」「わからない所は『不明』と書いてください」と、**禁止とルールを先に言っておく**と、足されにくくなります（ゼロにはなりません）。

## コツ4　出来上がりの「形」を見せる

「見出しは〇〇と〇〇」「表にして」「1行30字くらい」など、**形を指定する**と、そのまま使える答えが返ってきやすくなります。

## コツ5　一発で決めようとしない

最初の答えがズレていたら、やり直しを頼めばOKです。

- 「2番目の項目だけ、もっと短くしてください」
- 「〇〇の部分は、元のメモのどこに書いてありますか？」
- 「さっきの答えから、推測で書いた所を全部消してください」

> **ぷるの**：AIとの会話は、キャッチボール。投げ返してちょっとずつ近づけるのがコツだよ。

## 長い文章を貼るときの注意

AIのサービスによって、一度に入れられる文章の長さには限りがあります（どのくらいかはサービスやプランによって違います）。長すぎるときは、**途中で区切って、何回かに分けて頼む**方法を、テンプレ51で紹介しています。

# 第2章　個人情報・機密をAIに入れるときの注意

議事録や報告書には、人の名前、取引先、お金の話など、**外に出してはいけない情報**が入りがちです。テンプレを使う前に、この章だけは必ず読んでください。

> **ぷるの**：ここはまじめな話。ぷるぷるしないで聞いてね。

## 1. まず「会社・団体のルール」を確認する

勤め先や団体によっては、「業務の情報を外部のAIサービスに入れてはいけない」「決められたAIだけ使ってよい」などのルールがあります。**ルールがあるなら、この本よりもそちらが優先**です。わからないときは、入れる前に担当の人に聞きましょう。

## 2. 入れた情報がどう扱われるかは、サービスごとに違う

入力した内容が保存されるか、AIの学習に使われるか、設定で変えられるかは、**サービスや契約の種類によって違います**。この本では、特定のサービスについて「安全」「危険」とは言い切りません。使う前に、そのサービスの利用規約やプライバシーの説明を、自分で確認してください。

## 3. 入れる前に「置きかえ」をする

いちばん手軽で効く方法は、AIに貼る前に、**固有名詞を記号に置きかえる**ことです。

| 元の情報 | 置きかえの例 |
|---|---|
| 人の名前（山田さん） | Aさん、リーダー、担当1 |
| 取引先・お客さまの名前 | 取引先X、お客さまB |
| 電話番号・メールアドレス・住所 | 消す、または［連絡先］ |
| 金額・売上の具体的な数字 | 必要なければ消す、または「約〇割」 |
| 社内だけで使うプロジェクト名 | 案件1 |

まとめが終わったら、**自分の手元で元の名前に戻します**。置きかえ表は、AIには貼らずに自分で持っておきましょう。

> **ぷるの**：「山田さん」を「Aさん」にするだけでも、ずいぶん違うよ。

## 4. そもそも入れないほうがいいもの

次のような情報は、置きかえても特定されるおそれがあったり、もれたときの影響が大きかったりします。**AIに入れない**のが基本です。

- 人事・評価・病気・家族の事情など、個人のくわしい事情
- パスワード、口座番号、カード番号、マイナンバーなど
- 契約前の取引条件、公表前の決算や新商品の情報
- お客さまから預かった個人情報の一覧

## 5. 録音・文字起こしは「話した人の了解」から

会議を録音して文字にするときは、**参加者に録音すること・AIで整理することを伝え、了解をもらってから**にしましょう。了解のない録音や、それを外部のサービスに入れることは、トラブルのもとになります。

## 6. AIのまとめは「確認してから」共有する

AIは、ときどき**言っていないことを足したり、数字や名前を取りちがえたり**します。議事録や報告書を人に送る前に、

- 決まったこと・担当・期限が、元のメモと合っているか
- 数字・日付・名前がまちがっていないか
- 推測で書かれた所がないか

を、必ず自分の目で確かめてください。この本の多くのテンプレには、「推測で書かない」「不明と書く」という指示を入れていますが、それでもチェックは必要です。

# 第3章　会議の議事録

会議のあとに残った走り書きを、ほかの人が読める「議事録」にする場面です。この章のテンプレは、ほとんどが**素材A（架空の会議メモ）**で試しています。

> **ぷるの**：議事録で大事なのは「決まったこと」「だれが」「いつまでに」。この3つがそろっていれば、だいたい勝ち！

## テンプレ01　走り書きのメモを、議事録の形に整える

**① 場面**

会議中にとったメモが、自分にしか読めない状態。チームに共有できる形にしたい。

**② コピペ用の頼み方**

```
以下の会議メモを、議事録の形に整えてください。

【ルール】
・見出しは「日時」「出席者」「欠席者」「話し合ったこと」「決まったこと」「保留」「次回」にする
・メモに書かれていないことは足さない
・わからない所は「（不明）」と書く

---ここから---
［ここに会議メモを貼る］
---ここまで---
```

**③ 試した出力例**（入力：素材A）

```
■日時：10/14（時刻は不明）
■会議名：販促ミーティング（みどり文具）
■出席者：山田（リーダー）、木村、林
■欠席者：森

■話し合ったこと
・秋の手帳フェアの売上が、先週よりやや下がっている。
　木村さんから「棚の位置が奥すぎるのでは」という意見があった。
・SNSでの告知回数を、週2回から週3回に増やすかどうか。

■決まったこと
・手帳フェアの棚を入口横に移す（山田さん了承）。
　レイアウト図は木村さんが来週月曜までに作る。
・POPは林さんが作る。黄色ベース。金曜まで。
・B5手帳の在庫が少ないため、林さんが今日中に発注を確認する。

■保留
・SNS告知の回数（週2→週3）：結論が出ず、次回に持ちこし。
・年末の大掃除：12/27で仮決定。森さんへの確認が必要（確認する人は不明）。

■次回
・10/21　10時〜
```

**④ うまくいかないときの直し方**

- **「次回までに各自検討」など、メモにない一文が足された** → 「メモにない文はすべて消して、もう一度出してください」と頼む。【ルール】の「足さない」を一番上に移すのも効きます。
- **見出しが会社の形式とちがう** → 見出しの行を、自社の議事録の見出しに書きかえてから頼む。
- **「来週月曜」などがそのまま残る** → これは正しい動きです。日付に直したいときは、テンプレ04で「あいまいな期限」を洗い出してから、カレンダーを見て自分で書きかえてください。

## テンプレ02　「決まったこと」「保留」「やること」の3つに分ける

**① 場面**

議事録の形にするほどでもないけれど、結局なにが決まったのかだけ、パッと知りたい。

**② コピペ用の頼み方**

```
以下の会議メモを読んで、次の3つに分けて箇条書きにしてください。
1. 決まったこと
2. 決まらなかったこと（保留）
3. だれかがやること（担当者と期限つき。書かれていなければ「担当：不明」「期限：不明」）

メモにないことは書かないでください。

---ここから---
［ここに会議メモを貼る］
---ここまで---
```

**③ 試した出力例**（入力：素材A）

```
1. 決まったこと
・手帳フェアの棚を入口横に移す
・POPは黄色ベースで作る
・年末の大掃除は12/27（仮）
・次回は10/21 10時〜

2. 決まらなかったこと（保留）
・SNS告知を週2回から週3回に増やすか（次回に話す）

3. だれかがやること
・レイアウト図を作る　担当：木村　期限：来週月曜
・POPを作る　担当：林　期限：金曜
・B5手帳の発注を確認する　担当：林　期限：今日中
・大掃除の日程を森さんに確認する　担当：不明　期限：不明
```

**④ うまくいかないときの直し方**

- **「仮」の決定が「決まったこと」に入ってしまう** → この例でも12/27が「決まったこと」に入りました。気になるときは「『仮』『予定』と書かれたものは保留に入れてください」と1行足します。
- **3つの分け方が自分の感覚とちがう** → 「〇〇は保留に移してください」と、1つずつ指示して直すのが早いです。

## テンプレ03　欠席した人向けに「3行でわかる」共有文を作る

**① 場面**

会議を休んだ人に、チャットで要点だけ伝えたい。

**② コピペ用の頼み方**

```
以下の会議メモをもとに、会議を欠席した［欠席した人の呼び方］さんに送る、チャット用の短い共有文を作ってください。

・最初にあいさつを1行
・要点は3行以内
・［欠席した人の呼び方］さんに関係することがあれば、最後に別にして書く
・メモにないことは書かない

---ここから---
［ここに会議メモを貼る］
---ここまで---
```

**③ 試した出力例**（入力：素材A、欠席した人＝森）

```
森さん、おつかれさまです。10/14の販促ミーティングの共有です。

・手帳フェアの棚を入口横に移すことになりました（レイアウト図は木村さん）。
・POPは林さんが黄色ベースで作ります。SNS告知の回数は次回に持ちこしです。
・次回は10/21の10時からです。

【森さんに関係すること】
年末の大掃除を12/27で仮決めしています。森さんのご都合を確認させてください。
```

**④ うまくいかないときの直し方**

- **3行に収まらず長くなる** → 「1行は40字以内」と字数も指定する。
- **ていねいすぎる／くだけすぎる** → 「同僚に送る、ややくだけた言い方で」「上司に送るていねいな言い方で」と相手を書く。
- **欠席者に関係する話がないのに、無理に作る** → 「関係することがなければ、その欄は書かないでください」と足す。

## テンプレ04　議事録の「抜け」を指摘してもらう

**① 場面**

議事録を送る前に、担当者や期限が抜けていないか、あいまいな所がないか確認したい。

**② コピペ用の頼み方**

```
以下の議事録（またはメモ）を、送る前にチェックしてください。
直すのではなく、気になる所を一覧で指摘してください。

【チェックすること】
・担当者が書かれていないやること
・期限が書かれていない、またはあいまいなもの（「来週」「今度」など）
・読む人によって意味が変わりそうな言葉
・決まったのか決まっていないのか、わかりにくいもの

---ここから---
［ここに議事録を貼る］
---ここまで---
```

**③ 試した出力例**（入力：素材A）

```
【担当者がない】
・「森さんに確認いる（だれが？）」：森さんに確認する人が決まっていません。

【期限があいまい】
・「来週月曜まで」：会議日（10/14）から見て、具体的な日付を書くと安心です。
・「金曜まで」：今週の金曜か、来週の金曜か、日付で書くと確実です。
・「今日中」：会議日の10/14のことだと思われますが、念のため日付を書くとよいです。

【意味が変わりそうな言葉】
・「ちょい下」：どのくらい下がったか（数字や割合）があると、休んだ人にも伝わりやすいです。
・「黄色ベース」：店のロゴの黄色など、具体的な色の指定があればそろえやすいです。

【決まったかどうかわかりにくい】
・「12/27で仮」：仮決定なのか、ほぼ決定なのか。いつ正式に決めるかを書くとよいです。
・「週2→週3？」：保留であることを、はっきり書くとよいです。
```

**④ うまくいかないときの直し方**

- **指摘ではなく、勝手に書き直してしまう** → 「書き直さないでください。指摘だけ一覧にしてください」と強めに言う。
- **「来週月曜」を、AIが勝手に日付に直す** → 会議の日付や曜日をAIが取りちがえることがあります。日付への置きかえは、**カレンダーを見て自分で**するのが安全です。
- **指摘が多すぎる** → 「大事な順に5つまで」と数をしぼる。

## テンプレ05　会議の前に、アジェンダ（話す順番）を作る

**① 場面**

会議で話したいことはあるけれど、順番や時間配分が決まっていない。

**② コピペ用の頼み方**

```
次の会議のアジェンダ（議題と時間配分）を作ってください。

・会議の時間：［例：30分］
・目的：［例：来月のイベントの担当を決める］
・話したいこと：
［ここに話したいことを箇条書きで書く］

【ルール】
・決めなければいけないことを先に置く
・それぞれに「決めること」または「共有するだけ」を書く
・時間の合計が会議の時間に収まるようにする
```

**③ 試した出力例**

（入力：架空。時間30分／目的「年末の大掃除と手帳フェアの続きを決める」／話したいこと「SNS告知の回数」「大掃除の担当」「手帳フェアの棚を移したあとの様子」「POPの感想」）

```
【販促ミーティング　アジェンダ（30分）】
目的：年末の大掃除と手帳フェアの続きを決める

1. SNS告知の回数（週2→週3）　8分　【決めること】
2. 年末の大掃除の担当　8分　【決めること】
3. 手帳フェア：棚を移したあとの様子　7分　【共有するだけ】
4. POPの感想　5分　【共有するだけ】
5. まとめ・次回の日程　2分

合計：30分
```

**④ うまくいかないときの直し方**

- **時間の合計が合わない** → AIは足し算をまちがえることがあります。「最後に合計時間を計算して、会議の時間と合っているか確かめてください」と足すか、自分で足し算して確認する。
- **議題が勝手に増える** → 「話したいことにない議題は足さないでください」と書く（この例の「まとめ・次回の日程」のような、進行のための項目は残してよいかも決めておく）。

## テンプレ06　前回の議事録から、今回のアジェンダを作る

**① 場面**

定例会議。前回の「保留」や「宿題」を、今回ちゃんと確認したい。

**② コピペ用の頼み方**

```
以下は前回の会議の議事録（またはメモ）です。
これをもとに、今回の会議のアジェンダを作ってください。

・前回の「やること」は、それぞれ「進み具合の確認」として入れる
・前回の「保留」は、「決めること」として入れる
・新しい議題は足さず、最後に「その他」の枠だけ作る

---ここから---
［ここに前回の議事録を貼る］
---ここまで---
```

**③ 試した出力例**（入力：素材A）

```
【10/21 販促ミーティング　アジェンダ】

■前回のやることの確認
1. レイアウト図（木村さん）：できたか確認
2. 手帳フェアの棚の移動：入口横に移せたか確認
3. POP（林さん）：できたか確認
4. B5手帳の発注（林さん）：発注できたか確認

■決めること
5. SNS告知の回数：週2回のままか、週3回に増やすか
6. 年末の大掃除：12/27でよいか（森さんの都合の確認結果）

■その他
7. その他
```

**④ うまくいかないときの直し方**

- **「確認」だけでなく、AIが勝手に結論を書く** → 「結論や予想は書かず、議題名だけにしてください」と足す。
- **前回の議事録が長すぎて、一部が抜ける** → 前回の「決まったこと」「保留」「やること」の部分だけを貼る。

## テンプレ07　上司やほかの部署に出す、ていねいな議事録にする

**① 場面**

チーム内のメモを、上司や他部署にも共有することになった。言葉づかいを整えたい。

**② コピペ用の頼み方**

```
以下の会議メモを、［読む人：例 部長／ほかの部署の人］に提出する、ていねいな議事録にしてください。

・です・ます調、または「〜する」「〜とした」の文末にそろえる（［どちらか選ぶ］）
・くだけた言葉（「ちょい」「OK」など）は、ふつうの言葉に直す
・内容は足さない、減らさない

---ここから---
［ここに会議メモを貼る］
---ここまで---
```

**③ 試した出力例**（入力：素材A、読む人＝店長、文末＝「〜する」「〜とした」）

```
販促ミーティング議事録

日時：10月14日
出席者：山田（リーダー）、木村、林
欠席者：森

1. 秋の手帳フェアについて
　売上が前週と比べてやや減少している。原因として、棚の位置が店の奥にあることが挙げられた。
　→ 棚を入口横に移すこととした（山田了承）。レイアウト図は木村が来週月曜までに作成する。
　→ POPは林が作成する。色は黄色を基調とする。期限は金曜。

2. SNSでの告知回数について
　週2回から週3回に増やす案が出たが、結論に至らず、次回に継続して検討する。

3. 在庫について
　B5手帳の在庫が少ないため、林が本日中に発注状況を確認する。

4. 年末の大掃除について
　12月27日で仮決定とした。欠席の森に都合を確認する必要がある（確認者は未定）。

次回：10月21日 10時〜
```

**④ うまくいかないときの直し方**

- **かたすぎて読みにくい** → 「社内向けなので、かたすぎない言い方で」と足す。
- **人の名前に「さん」をつけるか迷う** → 社外に出すときは名前を外すことが多いので、自社のルールに合わせて「名前には〇〇をつけてください」と指定する。
- **「原因として〜挙げられた」のように、意見が事実っぽくなる** → この例でも、木村さんの「棚が奥すぎ？」という疑問が、少し強い書き方になっています。「意見は『〜という意見があった』と書いてください」と足すと、ニュアンスが残りやすいです。

## テンプレ08　話した人ごとに、発言をまとめる

**① 場面**

録音の文字起こしから、「だれが、どんな意見を言ったか」を整理したい。

**② コピペ用の頼み方**

```
以下は会議の文字起こしです。話した人ごとに、主な発言を箇条書きでまとめてください。

・話者の呼び方：［例：話者1＝店長、話者2＝大野さん］
・意見と、引き受けたこと（「私がやります」など）は分けて書く
・言っていないことは書かない

---ここから---
［ここに文字起こしを貼る］
---ここまで---
```

**③ 試した出力例**（入力：素材C、話者1＝店長、話者2＝大野さん、話者3＝竹内さん）

```
■店長
【意見・進行】
・来月の期間限定メニューについて話したい（去年はかぼちゃのマフィン）。
・冷凍ペーストを使う案について、まず原価を調べてほしい。
・試食会は再来週の月曜の閉店後にする。
・ポスターは去年のものを使い回さず、新しく作りたい。

■大野さん
【意見】
・さつまいもは仕込み（蒸す、つぶす）に時間がかかるのでは。
・スタッフで試食会をやりたい。
【引き受けたこと】
・ポスターを作る。

■竹内さん
【意見】
・さつまいもがよい。お客さんから「さつまいもはないの？」と何回か聞かれた。
・仕込みの手間を減らすため、冷凍のペーストを使ってはどうか。
【引き受けたこと】
・冷凍ペーストの原価を、来週の水曜までに調べる。
```

**④ うまくいかないときの直し方**

- **「機関限定」「マッフィン」などの変換ミスを、AIがそのまま使う／勝手に直す** → この例では、AIが「期間限定」「マフィン」に直していました。直してほしくないとき、または直した所を知りたいときは「変換ミスと思われる所を直した場合は、直した所を最後に一覧にしてください」と足す（テンプレ46も参考に）。
- **話者の取りちがえ** → 文字起こしの話者の区切り自体がまちがっていることもあります。大事な発言は、録音を聞き直して確認してください。

## テンプレ09　議事録を表にする

**① 場面**

やることが多い会議。表にして、あとで進み具合を書きこめるようにしたい。

**② コピペ用の頼み方**

```
以下の会議メモから、やることを表にしてください。

・列は「No.」「やること」「担当」「期限」「状態」
・「状態」はすべて「未着手」にする
・担当や期限が書かれていなければ「不明」と書く
・表のあとに、表に入れなかった決定事項を箇条書きで書く

---ここから---
［ここに会議メモを貼る］
---ここまで---
```

**③ 試した出力例**（入力：素材A）

```
| No. | やること | 担当 | 期限 | 状態 |
|---|---|---|---|---|
| 1 | 手帳フェアのレイアウト図を作る | 木村 | 来週月曜 | 未着手 |
| 2 | POPを作る（黄色ベース） | 林 | 金曜 | 未着手 |
| 3 | B5手帳の発注を確認する | 林 | 今日中 | 未着手 |
| 4 | 年末の大掃除の日程を森さんに確認する | 不明 | 不明 | 未着手 |

【表に入れなかった決定事項】
・手帳フェアの棚を入口横に移す（山田さん了承）

・SNS告知の回数は次回に話す
・次回は10/21 10時〜
```

**④ うまくいかないときの直し方**

- **表がくずれて表示される** → 使うアプリによっては、表の記号（｜）がそのまま見えることがあります。「表ではなく、タブ区切りで出してください」と頼むと、表計算ソフトに貼りやすくなります。
- **「棚を移す」作業自体の担当が抜ける** → この例でも、棚を実際に移す人はメモに書かれていません。表を見て「担当がいない作業はないか」を自分でも確認しましょう。

## テンプレ10　オンライン会議のチャット欄から、議事録を作る

**① 場面**

オンライン会議で、話した内容の一部がチャット欄に流れていった。それを議事録にまとめたい。

**② コピペ用の頼み方**

```
以下は、会議やグループのチャットのやりとりです。
議事録として、次の形でまとめてください。

■決まったこと
■まだ決まっていないこと
■やること（担当・期限。なければ「不明」）

・時刻や「了解です」だけの発言は省く
・書かれていないことは足さない

---ここから---
［ここにチャットのやりとりを貼る］
---ここまで---
```

**③ 試した出力例**（入力：素材D）

```
■決まったこと
・秋の社内勉強会は11/12（木）15時から、3階の会議室で行う。
・お菓子と飲み物の予算は1万円以内。

■まだ決まっていないこと
・前日の買い出しに行く人（小川さんが、予定を見て明日返事する）。

■やること
・講師への連絡　担当：佐々木　期限：不明

```

**④ うまくいかないときの直し方**

- **「明日」を日付に直すとき、まちがえる** → この例では、発言の日付（10/15）から「10/16」と書いてくれましたが、いつもうまくいくとは限りません。日付は自分でも確かめてください。
- **「了解です」の人を担当者にしてしまう** → 「引き受けると言った人だけを担当者にしてください」と足す。

# 第4章　メモの整理

スマホのメモ帳、付せん、ノートの切れはし。たまったメモを、使える形に並べかえる場面です。

> **ぷるの**：メモは「書いたときの自分」しか意味がわからないことが多いんだ。AIに分けてもらうと、未来の自分が助かるよ。

---

## テンプレ11　ばらばらのメモを、ジャンルごとに分ける

**① 場面**

仕事のこと、家のこと、思いつきがまざったメモを、ざっくり分けたい。

**② コピペ用の頼み方**

```
以下のメモを、ジャンルごとに分けてください。

・ジャンルは［例：仕事／家・買い物／やりたいこと／その他］
・どのジャンルにも入らないものは「その他」に入れる
・メモの文は書きかえず、そのまま使う

---ここから---
［ここにメモを貼る］
---ここまで---
```

**③ 試した出力例**（入力：素材E、ジャンル＝仕事／家・買い物／やりたいこと／その他）

```
【仕事】
・企画書、表紙だけ先に作る
・企画書の締切 金曜
・会議で「数字の根拠は？」と聞かれた件 調べ直す
・新人さん向けのマニュアル、古い

【家・買い物】
・電球 2個
・プリンターのインク
・母の誕生日 11月 何か送る

【やりたいこと】
・ジム 週1でいいから再開したい
・ブログのネタ：朝10分の片付け
・ブログ：100円ショップの収納

【その他】
・駅前のパン屋 火曜休み
```

**④ うまくいかないときの直し方**

- **ジャンル分けが自分の感覚とちがう**（例：ブログは「仕事」に入れたい） → 「ブログに関するものは仕事に入れてください」と、ルールを1つ足す。
- **メモの文が勝手に書きかえられる** → 「1文字も変えずに」と強めに書く。
- **ジャンルを自分で決めるのが面倒** → ［　］の所を「ジャンルは、メモを見て3〜5個に決めてください」に変えると、AIに決めてもらえます。

---

## テンプレ12　メモの中から、急ぎのものを先に並べる

**① 場面**

メモにやることがたまっている。どれから手をつけるか決めたい。

**② コピペ用の頼み方**

```
以下のメモから「やること」だけを取り出して、急ぐ順に並べてください。

・期限が書かれているものを先にする
・期限がないものは、そのあとにまとめる
・それぞれ、なぜその順番にしたか、ひとことそえる
・メモに書かれていない期限を、推測で決めない

---ここまで---
```

**③ 試した出力例**（入力：素材E）

# 第5章　長文の要約

長い報告書、長いメール、ルールの改定案。全部を読む時間がないときに、要点をつかむ場面です。この章のテンプレは、主に**素材B（架空の報告文）**と**素材F（架空のルールの新旧）**で試しています。

> **ぷるの**：要約は、短くするほど「抜ける情報」が増えるよ。何を残したいかを先に伝えるのがコツ！

## テンプレ19　3行で要約する

**① 場面**

長い文章を受け取った。まずは全体を3行でつかみたい。

**② コピペ用の頼み方**

```
以下の文章を3行で要約してください。

・1行目：何についての文章か
・2行目：いちばん大事な結果・結論
・3行目：これからどうするか（書かれていなければ「書かれていない」）
・元の文章にないことは書かない

---ここから---
［ここに文章を貼る］
---ここまで---
```

**③ 試した出力例**（入力：素材B）

```
1. 9月に平日14〜16時限定で「本とコーヒー割」（ドリンク50円引き）を試した報告。
2. 客数は1日平均18人→23人に増え、売上も1日平均約2,000円増えたが、滞在が長くなり満席でお断りした日が3日あった。
3. 時間の短縮・フードとのセット割・満席時の案内カードの3案を考えており、10月末に数字を見て相談したい。
```

**④ うまくいかないときの直し方**

- **1行が長くなりすぎる** → 「1行40字以内」と字数を足す。ただし、字数を短くするほど、数字などが抜けやすくなります。
- **「成功した」「失敗した」など、元の文にない評価がつく** → 「評価や感想は書かないでください」と足す。

## テンプレ20　決まった字数で要約する

**① 場面**

社内報や掲示、チャットの投稿など、字数の決まった場所に要約をのせたい。

**② コピペ用の頼み方**

```
以下の文章を、［例：100字］以内で要約してください。

・必ず残してほしいこと：［例：数字の結果、今後の予定］
・書き終わったら、だいたい何字か最後に書く
・元の文章にないことは書かない

---ここから---
［ここに文章を貼る］
---ここまで---
```

**③ 試した出力例**（入力：素材B、100字以内、残すこと＝数字の結果・今後の予定）

```
9月、平日14〜16時にドリンク50円引きを試した結果、客数は1日平均18人から23人に、売上は約2,000円増えた。一方で満席の日もあり、10月末に数字を見て今後を相談する。

（約90字）
```

※あとで文字数を数えるツールで数えたところ、句読点をふくめて88字でした。

**④ うまくいかないときの直し方**

- **AIが書いた字数が、実際とちがう** → AIは自分の文の字数を正しく数えられないことがあります。字数がきびしい場所に出すときは、**文字数を数えるツールやワープロの機能で自分で確かめて**ください。

## テンプレ21　「結論→理由→次にやること」の順に並べかえる

**① 場面**

話があちこちに飛ぶ長文を、上司に説明できる順番に組みかえたい。

**② コピペ用の頼み方**

```
以下の文章の内容を、次の順番に並べかえて、箇条書きでまとめてください。

1. 結論（いちばん伝えたいこと）
2. 理由・根拠（数字があれば数字で）
3. 気になる点・問題
4. 次にやること

・元の文章に書かれている内容だけを使う
・どこにも当てはまらない内容は「その他」に入れる

---ここから---
［ここに文章を貼る］
---ここまで---
```

**③ 試した出力例**（入力：素材B）

```
1. 結論
・平日午後の「本とコーヒー割」で、客数と売上は増えた。

2. 理由・根拠
・14〜16時の客数：8月 1日平均18人 → 9月 1日平均23人
・この時間帯の売上：割引分を差し引いても、1日平均およそ2,000円増

3. 気になる点・問題
・滞在時間が平均約40分から約65分に延び、15時台に満席になった。
・テイクアウト以外のお客さまをお断りした日が3日あった。
・フードの注文は増えていない。
・スタッフから「満席時の案内が気まずい」という声があった。

4. 次にやること
・案①：10月も続け、対象を14〜15時半に短くする（すぐできる）
・案②：フードとセットの場合だけ割引にする（メニュー表の作り直しが必要）
・案③：満席時の案内カードを作る（すぐできる）
・10月末に数字を見て、11月以降をオーナーと相談する。

その他
・きっかけは、この時間帯に空席が目立っていたこと。
・スタッフから「店の雰囲気が良くなった」という声があった。
```

**④ うまくいかないときの直し方**

- **「結論」をAIが自分で作ってしまう**（元の文章にはっきりした結論がないとき） → 「結論がはっきり書かれていなければ『結論は書かれていない』と書いてください」と足す。この例の「結論」も、AIが文章全体から読み取ったものです。書いた人の考えと合っているか確認しましょう。

---ここまで---
```

**③ 試した出力例**（入力：素材B、読む人A＝オーナー、読む人B＝アルバイトのスタッフ）

**③ 試した出力例**（入力：素材B）

```
| 数字 | 何の数字か | 元の文章の言い方 |
|---|---|---|
| 9月 | 試した期間 | 9月の1か月間 |
| 14時〜16時 | 割引の対象の時間帯 | 平日の14時から16時 |
| 50円 | 割引の金額 | ドリンク50円引き |
| 18人 | 8月の14〜16時の客数（1日平均） | 8月の1日平均18人 |
| 23人 | 9月の14〜16時の客数（1日平均） | 9月は1日平均23人 |
| 約40分 | 以前の平均滞在時間 | 平均で約40分 |
| 約65分 | 9月の平均滞在時間 | 約65分に延びました |
| 15時台 | 満席になった時間帯 | 15時台に満席になり |
| 3日 | お断りした日数 | お断りした日が3日 |
| およそ2,000円 | 売上の増加（1日平均、8月比） | 1日平均およそ2,000円増えています |
| 14〜15時半 | 案①の新しい対象時間 | 対象を14〜15時半に短くする |
| 10月末 | 次に数字を見る時期 | 10月末にもう一度数字を見て |
| 11月以降 | 相談する対象の期間 | 11月以降どうするか |
```

**④ うまくいかないときの直し方**

- **抜けている数字がある** → 長い文章では見落としが出やすいです。「段落ごとに確認して、抜けがないかもう一度見てください」と頼むか、段落ごとに分けて貼る。
- **AIが「5人増（約28%増）」など計算を足す** → 計算はまちがうことがあるので、「計算しないでください」と書いておき、計算は表計算ソフトなどで自分でする。

## テンプレ24　要約が元の文章と食いちがっていないか、確かめる

**① 場面**

AIや人が作った要約を、送る前に元の文章と照らし合わせたい。

**② コピペ用の頼み方**

```
以下の「元の文章」と「要約」をくらべて、要約の中で
・元の文章と食いちがっている所
・元の文章に書かれていないことが書かれている所
・大事なのに抜けている所
を一覧にしてください。要約の書き直しはしないでください。

---元の文章---
［ここに元の文章を貼る］
---要約---
［ここに要約を貼る］
---ここまで---
```

**③ 試した出力例**

（入力：素材Bと、わざとまちがいを入れた架空の要約「9月に平日午後の割引を試したところ、客数は1日平均25人に増え、フードの注文も伸びた。好評だったため、10月からは終日実施する。」）

```
【食いちがっている所】
・「客数は1日平均25人」→ 元の文章では「1日平均23人」です。
・「フードの注文も伸びた」→ 元の文章では「フードの注文は増えておらず」とあります。

【書かれていないことが書かれている所】
・「10月からは終日実施する」→ 元の文章にはありません。元の文章の案①は「対象を14〜15時半に短くする」で、時間を広げるのではなく短くする案です。
・「好評だったため」→ スタッフの声は良いものと気になるものの両方があり、「好評」とまとめられる書き方はされていません。

【大事なのに抜けている所】
・滞在時間が延びて、満席でお断りした日が3日あったこと。
・10月末に数字を見て、11月以降を相談するという予定。
```

**④ うまくいかないときの直し方**

- **AIが「問題ありません」と言うが、本当は食いちがいがある** → AIのチェックも完全ではありません。とくに**数字・日付・名前**は、最後に自分の目で1つずつ確かめてください。
- **細かい言い回しのちがいまで大量に指摘される** → 「意味が変わるものだけを指摘してください」と足す。

## テンプレ25　ルールの「変わった所」だけをまとめる

**① 場面**

規程やルールの改定案が届いた。どこが変わったのかだけ知りたい。

**② コピペ用の頼み方**

```
以下の「旧」と「新」をくらべて、変わった所だけを表にまとめてください。

・列は「項目」「旧」「新」「何が変わったか（ひとこと）」
・変わっていない所は表に入れない
・新しく増えたルール、なくなったルールがあれば、それもわかるように書く
・良い・悪いの評価はしない

---旧---
［ここに古いルールを貼る］
---新---
［ここに新しいルールを貼る］
---ここまで---
```

**③ 試した出力例**（入力：素材F）

```
| 項目 | 旧 | 新 | 何が変わったか |
|---|---|---|---|
| 申し込み方法 | 総務の窓口で、平日9〜17時に受付 | 申請フォームから、いつでも申し込める | 申し込みが窓口からフォームに。時間の制限がなくなった |
| 受け取り | （記載なし） | 総務の窓口で、平日9〜17時 | 受け取りのルールが新しく書かれた |
| 貸し出し期間 | 最長1週間 | 最長2週間 | 期間が1週間から2週間に延びた |
| 延長 | （記載なし） | 1回まで（最長1週間） | 延長のルールが新しく増えた |
| 返却方法 | 総務の担当者に直接手渡し | 窓口横の返却ボックスに入れる | 手渡しから返却ボックスに |
| 紛失時の報告 | 総務に口頭で報告 | 申請フォームの「紛失報告」から報告し、上長にも伝える | 報告の方法がフォームに。上長への連絡が増えた |
```

**④ うまくいかないときの直し方**

- **変わっていない所（受付時間「平日9〜17時」など）を「変わった」と書く** → この例では「受付」が「受け取り」に役割が変わった、と分けて書いてくれました。こうした細かい所は読みちがえやすいので、表を見ながら元の文と照らし合わせてください。
- **ルールが長い** → 1回で全部を貼らず、「第1条〜第5条」のように分けて頼む。

## テンプレ26　長い文章に、見出しをつけて区切る

**① 場面**

見出しのない長い文章。どこに何が書いてあるか、ひと目でわかるようにしたい。

**② コピペ用の頼み方**

```
以下の文章に、内容ごとに短い見出しをつけて区切ってください。

・文章そのものは1文字も変えない
・見出しは1つ15字以内
・見出しの前に「■」をつける

---ここから---
［ここに文章を貼る］
---ここまで---
```

**③ 試した出力例**（入力：素材B。本文は元と同じなので、見出しと各段落の書き出しだけ示します）

```
■試したことと、そのきっかけ
9月の1か月間、平日の14時から16時に、……

■客数と滞在時間の変化
結果として、14〜16時のお客さまの数は、……

■売上とフードの注文
売上は、割引の分を差し引いても、……

■スタッフの声
スタッフからは「静かに過ごす方が多く、……

■今後の3つの案
今後の案としては、①10月も続けるが、……

■次の相談の予定
10月末にもう一度数字を見て、……
```

**④ うまくいかないときの直し方**

- **本文がこっそり書きかえられる** → 「1文字も変えない」と書いても、AIが言い回しを少し直すことがあります。大事な文書では、**元の文と見くらべる**か、「見出しの一覧と、それぞれがどの文から始まるかだけを出してください」と頼み、見出しの入力は自分でする方法が安全です。

## テンプレ27　むずかしい言葉の「ミニ用語集」つきで要約する

**① 場面**

カタカナ語や専門用語の多いお知らせ。内容を、くわしくない人にも伝えたい。

**② コピペ用の頼み方**

```
以下の文章を、［例：この分野にくわしくない人］にもわかるように要約してください。

・要約は5行以内
・要約のあとに、文章に出てくるむずかしい言葉を「ミニ用語集」として、1語1行で説明する
・言葉の説明は、一般的な意味にとどめる。この文章の中での意味がはっきりしない場合は「文章からは不明」と書く

---ここから---
［ここに文章を貼る］
---ここまで---
```

**③ 試した出力例**

（入力：次の架空のお知らせ）

```
来月より、社内チャットのアカウントは二段階認証を必須とします。
設定はプロフィール画面から行ってください。
未設定のアカウントは、移行期間の終了後にログインできなくなります。
詳しくはFAQをご覧ください。
```

↓ AIの出力

```
【要約】
・来月から、社内チャットに入るときの確認が、今より1段階ふえます。
・設定は、チャットのプロフィール画面からできます。
・設定しないままだと、移行期間が終わったあとログインできなくなります。
・くわしいことは「FAQ」に書かれています。
・移行期間がいつまでかは、この文章には書かれていません。

【ミニ用語集】
・アカウント：チャットを使うための、一人ひとりの利用者の登録。
・二段階認証：パスワードに加えて、もう1つ別の方法で本人かどうかを確かめるしくみ。どんな方法を使うかは、文章からは不明。
・移行期間：新しいやり方に切りかえるまでの準備の期間。期間の長さは文章からは不明。
・FAQ：よくある質問と、その答えをまとめたもの。
```

**④ うまくいかないときの直し方**

- **用語の説明が、自社のしくみとちがう** → AIは一般的な意味で説明します。社内のしくみの説明は、担当の部署の案内を確認してください。
- **説明がむずかしい** → 「小学生にもわかる言葉で」など、読む人をもっとはっきり書く。

# 第6章　ToDo（やること）の抜き出し

会議やチャットのあとに「結局、自分は何をすればいいの？」をはっきりさせる場面です。主に**素材A（会議メモ）**と**素材D（チャット）**で試しています。

> **ぷるの**：ToDoは「動詞で終わる」と動きやすいよ。「レイアウト図」じゃなくて「レイアウト図を作る」！

## テンプレ28　会議メモから、ToDoを一覧にする

**① 場面**

会議が終わった直後。やることを全部書き出して、もれをなくしたい。

**② コピペ用の頼み方**

```
以下の会議メモから、やること（ToDo）をすべて抜き出してください。

・1行に1つ、「〇〇を△△する」と動詞で終わる形にする
・それぞれに【担当】【期限】をつける。書かれていなければ「不明」
・「確認が必要」「〜いる」など、やることがはっきりしないものも、ToDoとして入れて「※要確認」とつける

---ここから---
［ここに会議メモを貼る］
---ここまで---
```

**③ 試した出力例**（入力：素材A）

```
1. 手帳フェアのレイアウト図を作る【担当】木村【期限】来週月曜
2. 手帳フェアの棚を入口横に移す【担当】不明【期限】不明
3. 手帳フェアのPOPを黄色ベースで作る【担当】林【期限】金曜
4. B5手帳の発注を確認する【担当】林【期限】今日中
5. 年末の大掃除（12/27仮）の都合を森さんに確認する【担当】不明【期限】不明 ※要確認
6. SNS告知の回数（週2→週3）を次回の会議で話し合う【担当】不明【期限】10/21の会議
```

**④ うまくいかないときの直し方**

- **2番や6番のように、メモにはっきり書かれていないToDoが出る** → 便利なこともありますが、メモから「読み取った」ものです。「メモにはっきり書かれているものだけ」にしたいときは、その一文を足してください。
- **担当者を推測で入れる**（例：「レイアウト図の担当が木村なので、棚を移すのも木村」） → 「担当者は推測しないでください」と書く。

## テンプレ29　チャットの中から「自分あての依頼」だけを拾う

**① 場面**

グループのチャットが流れていって、自分が頼まれたことを見落としそう。

**② コピペ用の頼み方**

```
以下のチャットのやりとりから、［自分の名前］あての依頼・お願いだけを抜き出してください。

・依頼した人、依頼の内容、期限（なければ「不明」）を書く
・［自分の名前］が「やります」と引き受けたものと、まだ返事をしていないものを分ける
・ほかの人あての依頼は入れない

---ここから---
［ここにチャットを貼る］
---ここまで---
```

**③ 試した出力例**（入力：素材D、自分の名前＝小川）

```
【引き受けたもの】
1. 参加者の出欠フォームを作る
　依頼した人：部長　期限：今週中
　追加のお願い（佐々木さん）：フォームに「質問したいこと」の欄を入れる

【まだ返事をしていないもの・返事を約束したもの】
2. 勉強会の前日の買い出しに行けるかどうか
　依頼した人：佐々木さん（「誰か行けますか？」と全体に質問）
　小川さんは「予定を見て明日返事します」と答えています。→ 明日までに返事をする
```

**④ うまくいかないときの直し方**

- **全体あての質問（「誰か行けますか？」）が、入ったり入らなかったりする** → 「全員あての質問も入れてください」または「名前を書かれた依頼だけにしてください」と、どちらか決めて書く。
- **自分の名前の呼ばれ方がいくつかある**（「小川さん」「おがわ」など） → ［自分の名前］の所に、呼ばれ方を全部書いておく。

## テンプレ30　期限があいまいなToDoを洗い出す

**① 場面**

ToDoは出そろったけれど、「今度」「早めに」などの期限が多くて不安。

**② コピペ用の頼み方**

```
以下のToDo（またはメモ）の中から、期限が書かれていないもの・あいまいなものを探してください。

・あいまいな例：「今度」「早めに」「来週」「金曜」（どの週かわからない）など
・それぞれ、「だれに、何を聞けば期限が決まるか」をひとことで提案する
・期限そのものを勝手に決めない

---ここから---
［ここにToDoやメモを貼る］
---ここまで---
```

**③ 試した出力例**（入力：素材A）

```
1. 「レイアウト図は木村、来週月曜まで」
　→ 日付がない。会議日（10/14）から見た「来週月曜」が何日かを、カレンダーで確認して書くとよいです。
2. 「POPは林。金曜まで」
　→ 今週か来週かが書かれていません。林さんに「何日の金曜か」を確認するとよいです。
3. 「林が今日中に発注確認」
　→ 「今日」は会議日の10/14と思われます。念のため日付で書くと確実です。
4. 「年末の大掃除 森さんに確認いる」
　→ 期限も担当もありません。山田さん（リーダー）に、だれがいつまでに確認するか決めてもらうとよいです。
5. 「SNSの告知 週2→週3？」
　→ 次回（10/21）の会議で話すことになっているので、期限は「10/21の会議」と書けます。
```

**④ うまくいかないときの直し方**

- **AIが「来週月曜＝〇日」と日付を計算して書く** → 合っていることもありますが、曜日を1日ずらすなど、まちがえることもあります。日付は自分でカレンダーを見て決めてください。
- **提案が多すぎる** → 「提案は1つ20字以内」と短くする。

---

## テンプレ31　ToDoを「今日」「今週」「あとで」に分ける

**① 場面**

やることが多すぎて、どれから手をつけたらいいかわからない。

**② コピペ用の頼み方**

```
今日は［例：10月14日（水）］です。
以下のToDoを、「今日やる」「今週中にやる」「あとでいい・期限なし」の3つに分けてください。

・期限が書かれているものは、その期限で分ける
・期限が書かれていないものは「あとでいい・期限なし」に入れる（勝手に急ぎにしない）
・分け方に迷ったものは「迷ったもの」として別に書く

---ここから---
［ここにToDoを貼る］
---ここまで---
```

**③ 試した出力例**

（入力：今日＝10月14日（水）、ToDo＝テンプレ28の出力の1〜6）

```
【今日やる】
・B5手帳の発注を確認する（林・今日中）

【今週中にやる】
・手帳フェアのPOPを黄色ベースで作る（林・金曜）
　※「今週の金曜（10/16）」と考えて、ここに入れました。

【あとでいい・期限なし】
・手帳フェアの棚を入口横に移す（担当・期限ともに不明）
・年末の大掃除の都合を森さんに確認する（担当・期限ともに不明）

【迷ったもの】
・手帳フェアのレイアウト図を作る（木村・来週月曜）
　→ 来週月曜（10/19）が期限なので「今週中」ではありませんが、週末をはさむので早めの着手がよさそうです。
・SNS告知の回数を次回の会議で話し合う（10/21の会議）
　→ 来週の会議までに、意見を考えておくとよいかもしれません。
```

**④ うまくいかないときの直し方**

- **曜日と日付がずれる** → 「今日の日付と曜日」を最初に書いておくと、ずれにくくなります。この例のように、AIが日付を書いたときは、カレンダーで確認してください（この例の10/16は金曜、10/19は月曜で合っていました）。
- **期限なしのものまで「今日」に入る** → 【ルール】の「勝手に急ぎにしない」を強調する。

---

## テンプレ32　大きなToDoを、小さな作業に分ける

**① 場面**

「勉強会の準備」のように、大きすぎて何から始めればいいかわからないToDoがある。

**② コピペ用の頼み方**

```
次のToDoを、1つ30分以内で終わるくらいの小さな作業に分けてください。

・ToDo：［例：秋の社内勉強会の準備］
・わかっていること：［例：日時、場所、予算、自分の担当］
・作業は、やる順番に並べる
・わかっていないことを前提にしない。決まっていないことは「〇〇を確認する」という作業にする
```

**③ 試した出力例**

（入力：ToDo＝秋の社内勉強会の準備のうち、小川さんの担当分／わかっていること＝素材Dの内容）

```
1. 出欠フォームに入れる項目を書き出す（名前、出欠、「質問したいこと」の欄）
2. 出欠フォームを作る
3. フォームを自分で1回試しに送って、うまく動くか確かめる
4. フォームのリンクを、部長に見てもらう
5. フォームのリンクを参加者に送る（今週中）
6. 勉強会の前日の予定を確認する
7. 買い出しに行けるかどうか、佐々木さんに返事をする（明日）
8. （行ける場合）予算1万円以内で、買うもののリストを作る
9. 出欠の結果を部長に伝える（資料の印刷部数を決めるため）
```

**④ うまくいかないときの直し方**

- **4番や9番のように、頼まれていない作業が入る** → 「あったほうがいい」作業としてAIが足したものです。必要なければ消してください。「チャットに書かれた作業だけで」と言えば減ります。
- **作業が細かすぎる／大きすぎる** → 「1つ10分以内」「全部で5個まで」など、大きさや数を調整する。

## テンプレ33　ToDoを担当者ごとにまとめ直す

**① 場面**

全員のToDoがまざった一覧を、人ごとに分けて、それぞれに送りたい。

**② コピペ用の頼み方**

```
以下の会議メモ（またはToDo一覧）を、担当者ごとにまとめ直してください。

・担当者ごとに見出しをつけ、その下にToDoと期限を書く
・担当者がいないToDoは、最後に「担当者が決まっていないもの」として書く
・欠席者がいれば、その人あての確認ごとも書く

---ここから---
［ここに会議メモやToDo一覧を貼る］
---ここまで---
```

**③ 試した出力例**（入力：素材A）

```
■木村さん
・手帳フェアのレイアウト図を作る（来週月曜まで）

■林さん
・手帳フェアのPOPを黄色ベースで作る（金曜まで）
・B5手帳の発注を確認する（今日中）

■山田さん
・（メモに書かれたToDoはありません。棚を入口横に移す案を了承しています）

■森さん（欠席）
・年末の大掃除を12/27にする仮決定について、都合を伝える

■担当者が決まっていないもの
・手帳フェアの棚を入口横に実際に移す
・森さんに大掃除の都合を確認する
```

**④ うまくいかないときの直し方**

- **ToDoがない人を消してしまう／勝手に作る** → この例では、山田さんの欄に「ToDoはありません」と書いてくれました。ToDoがない人の扱いを「書かない」「ToDoなしと書く」のどちらにするか、先に決めて書いておくと安心です。

## テンプレ34　依頼に返事する前に「確認したいこと」を洗い出す

**① 場面**

仕事を頼まれた。引き受ける前に、聞いておくべきことをもれなく確認したい。

**② コピペ用の頼み方**

```
以下は、私（［自分の名前］）が受けた依頼のやりとりです。
この依頼を進める前に、依頼した人に確認しておいたほうがよいことを、質問の形で5つまで挙げてください。

・やりとりの中で、すでに答えが出ていることは聞かない
・大事な順に並べる
・最後に、その質問をまとめた、依頼した人あての短いメッセージ文も作る

---ここから---
［ここに依頼のやりとりを貼る］
---ここまで---
```

**③ 試した出力例**（入力：素材D、自分の名前＝小川、依頼＝出欠フォーム）

```
【確認したいこと】
1. 出欠の回答のしめ切りは、いつにしますか？
2. フォームを送る相手（参加の対象者）は、どの範囲ですか？
3. 名前と出欠、「質問したいこと」のほかに、入れたい項目はありますか？
4. フォームのリンクは、私から送ってよいですか？それとも部長から送りますか？
5. 回答の結果は、だれにどのように伝えればよいですか？

【部長あてのメッセージ案】
部長、出欠フォームの件、今週中に作ります。進める前に3点だけ確認させてください。
①回答のしめ切りはいつにしますか？
②送る相手は、どの範囲の方ですか？
③名前・出欠・「質問したいこと」以外に、入れたい項目はありますか？
```

**④ うまくいかないときの直し方**

- **メッセージ案の質問が、5つから3つに減る** → この例でも、AIが「多すぎると相手の負担になる」と考えたのか、3つにしぼっていました。全部聞きたいときは「5つ全部入れてください」と書く。
- **すでに答えが出ている質問が入る** → 「やりとりのどこにも答えがないものだけ」と強調する。

## テンプレ35　ToDoを、そのまま貼れるチェックリストにする

**① 場面**

ToDoを、メモアプリやチャットにそのまま貼れるチェックリストにしたい。

**② コピペ用の頼み方**

```
以下のToDoを、チェックリストの形にしてください。

・1行目の先頭に「□」をつける（［例：□ ／ - [ ] など、使いたい記号］）
・1行に1つ。「やること（担当・期限）」の形にする
・期限が近い順に並べる。期限がないものは最後
・ほかの説明は書かず、チェックリストだけを出す

---ここから---
［ここにToDoや会議メモを貼る］
---ここまで---
```

**③ 試した出力例**（入力：素材A、記号＝□）

**④ うまくいかないときの直し方**

- **使うアプリでチェックボックスにならない** → アプリによって、チェックボックスになる書き方がちがいます。使うアプリの書き方（例：「- [ ]」）を［　］に入れてください。

## テンプレ36　議事録から、上司への報告メールを作る

**① 場面**

会議に出ていない上司に、結果をメールで報告したい。

**② コピペ用の頼み方**

```
以下の会議メモをもとに、［上司の呼び方：例 店長］への報告メールの下書きを作ってください。

・件名もつける
・本文は「結論（決まったこと）→ 保留 → 相談したいこと」の順
・相談したいこと：［例：なし／〇〇について判断がほしい］
・メモにないことは書かない
・最後に、送る前に確認したほうがいい所を箇条書きで書く（メールとは別に）

---ここから---
［ここに会議メモを貼る］
---ここまで---
```

**③ 試した出力例**

（入力：素材A、上司＝店長、相談したいこと＝SNS告知の回数を増やしてよいか、店長の考えを聞きたい）

```
件名：10/14 販促ミーティングのご報告

店長

おつかれさまです。10/14の販促ミーティングの結果をご報告します。

■決まったこと
・秋の手帳フェアの売上が先週よりやや下がっているため、棚を入口横に移します（山田さん了承）。
・レイアウト図は木村さんが来週月曜までに、POPは林さんが黄色ベースで金曜までに作ります。
・B5手帳の在庫が少ないため、林さんが今日中に発注を確認します。
・年末の大掃除は12/27で仮決めしました。

■保留
・SNSでの告知回数（週2回→週3回）は結論が出ず、次回10/21に話し合います。

■ご相談
SNSの告知回数を増やすことについて、店長のお考えを、次回の会議までにお聞かせいただけますと助かります。

以上、よろしくお願いいたします。

───
【送る前に確認したほうがいい所】
・「来週月曜」「金曜」を、日付で書くかどうか
・売上が「やや下がっている」の程度（数字を入れるか）
・大掃除の日程について、欠席の森さんに確認する人
```

**④ うまくいかないときの直し方**

- **お詫びや前置きが長い** → 「前置きは1行だけ」と書く。
- **自分の名前や署名がない** → この下書きには署名がありません。自分で足すか、［　］に「署名：〇〇」と書いておく（第2章のとおり、本名を入れたくないときは、あとで自分で足すのが安全です）。

## テンプレ37　1週間の箇条書きから、週報を作る

**① 場面**

毎週の週報。やったことのメモはあるけれど、文章にする時間がない。

**② コピペ用の頼み方**

```
以下の1週間のメモから、週報の下書きを作ってください。

・見出しは「今週やったこと」「うまくいったこと」「困っていること」「来週の予定」
・メモにないことは書かない。当てはまる内容がない見出しは「特になし」
・全体で［例：300字］くらい

---ここから---
［ここに1週間のメモを貼る］
---ここまで---
```

**③ 試した出力例**

（入力：次の架空の1週間のメモ）

```
月：手帳フェアの棚移動のレイアウト図提出
火：棚を入口横に移動、林さんと2人で
水：販促ミーティング
木：POP設置。お客さんに"見やすくなった"と言われた
金：B5手帳 入荷が来週にずれると連絡あり
来週：手帳フェアの売上を先週とくらべる
```

↓ AIの出力

```
【週報】

■今週やったこと
・手帳フェアの棚を移すためのレイアウト図を提出しました（月）。
・林さんと2人で、棚を入口横に移しました（火）。
・販促ミーティングに出ました（水）。
・POPを設置しました（木）。

■うまくいったこと
・POPを設置したあと、お客さまから「見やすくなった」と言っていただきました。

■困っていること
・B5手帳の入荷が来週にずれると連絡がありました。

■来週の予定
・手帳フェアの売上を、先週とくらべます。
```

**④ うまくいかないときの直し方**

- **「売上アップが期待されます」などの予想が足される** → 「予想や感想を足さない」と書く。
- **字数より短くなる** → メモが短いと、週報も短くなります。それでOKです。字数を合わせるために中身を足されるほうが困るので、「字数より短くてもいいので、中身を足さないでください」と書くのがおすすめです。

## テンプレ38　「ためしてみた結果」を、報告書の形にする

**① 場面**

新しいやり方を試した結果を、きちんとした報告書にまとめたい。

**② コピペ用の頼み方**

```
以下の文章を、報告書の形に整えてください。

・見出しは「1. 目的」「2. 実施内容」「3. 結果」「4. 課題」「5. 今後の案」「6. 次回の報告予定」
・数字は元の文章のとおりに書く。計算や言いかえはしない
・元の文章にないことは書かない。当てはまる内容がない見出しは「記載なし」

---ここから---
［ここに文章を貼る］
---ここまで---
```

**③ 試した出力例**（入力：素材B）

```
「本とコーヒー割」実施報告

1. 目的
平日14〜16時の空席を減らすため。

2. 実施内容
・期間：9月の1か月間
・時間：平日14時〜16時
・内容：店の本棚の本を読みながら過ごすお客さま向けに、ドリンクを50円引き

3. 結果
・14〜16時の客数：8月 1日平均18人 → 9月 1日平均23人
・平均滞在時間：約40分 → 約65分
・売上（同時間帯）：割引分を差し引いても、8月より1日平均およそ2,000円増
・15時台に満席となり、テイクアウト以外のお客さまをお断りした日が3日あった

4. 課題
・フードの注文が増えておらず、ドリンク1杯で長く過ごす方が多い印象
・スタッフから「満席時の案内が気まずい」との声
（良い声：「静かに過ごす方が多く、店の雰囲気が良くなった」）

5. 今後の案
①10月も続け、対象を14〜15時半に短くする（すぐ実施可能）
②フードとセットの場合のみ割引にする（メニュー表の作り直しが必要）
③満席時の案内カードを作る（すぐ実施可能）

6. 次回の報告予定
10月末に数字を確認し、11月以降の方針を相談する。
```

**④ うまくいかないときの直し方**

- **「目的」が書かれていない文章だと、AIが目的を作る** → この例では「空席が目立っていた」というきっかけから目的を書いています。元の文章に目的がはっきりないときは「目的は〇〇」と自分で書いて渡すほうが確実です。
- **会社の報告書の形がある** → 見出しの部分を、自社の形式に書きかえてください。

## テンプレ39　トラブル報告（経緯・原因・対策）のたたき台を作る

**① 場面**

ちょっとしたトラブルが起きた。報告書を早く出したいが、まとまらない。

**② コピペ用の頼み方**

```
以下のメモをもとに、トラブル報告のたたき台を作ってください。

・見出しは「何が起きたか」「経緯（時間の順）」「原因（わかっていること／まだわからないこと）」「すでにしたこと」「これからすること」
・原因は、メモに書かれていることだけ。推測は「（推測）」とつけて分ける
・人を責める書き方はしない

---ここから---
［ここにメモを貼る］
---ここまで---
```

**③ 試した出力例**

（入力：次の架空のメモ）

```
10/9 朝、レジ横のPOPの値段が旧価格のまま。
お客さま1名に指摘されて気づく。10時ごろ差しかえ。差額は返金済み。
価格変更の連絡はメールで来てたが、POPの担当に回ってなかったっぽい。
今後：価格変更のときはチェック表？
```

↓ AIの出力

```
【トラブル報告（たたき台）】

■何が起きたか
10/9の朝、レジ横のPOPに旧価格が書かれたままになっていた。

■経緯（時間の順）
・10/9 朝：お客さま1名からの指摘で、POPの価格が旧価格のままであることに気づいた。
・同日 10時ごろ：POPを差しかえた。
・差額は、お客さまに返金済み。

■原因
【わかっていること】
・価格変更の連絡はメールで届いていた。
【まだわからないこと】
・連絡がPOPの担当者に伝わっていなかったかどうか。
　（推測）メールがPOPの担当者に回っていなかった可能性がある。

■すでにしたこと
・POPの差しかえ
・お客さまへの差額の返金

■これからすること
・価格変更のときに使うチェック表を作るかどうか検討する（案の段階）。
```

**④ うまくいかないときの直し方**

- **「担当者の確認不足」など、だれかのせいにする書き方になる** → 「人ではなく、しくみの問題として書いてください」と足す。
- **「っぽい」「？」のあいまいさが消えて、断定になる** → この例では「（推測）」「案の段階」と分けてくれましたが、消えることもあります。メモのあいまいな所は、報告書でもあいまいなまま残っているか確認しましょう。

## テンプレ40　報告書を書く前に「構成案」だけ作ってもらう

**① 場面**

報告書を一から書くのはたいへん。まず、どんな順番で何を書くかだけ決めたい。

**② コピペ用の頼み方**

```
これから［例：〇〇の報告書］を書きます。構成案（見出しと、それぞれに書くことのメモ）を作ってください。

・読む人：［例：店のオーナー］
・読む人が知りたいこと：［例：続けるかやめるか判断したい］
・手元にある材料：
［ここに材料を箇条書きで書く］
・本文はまだ書かない。見出しと「ここに〇〇を書く」というメモだけ
・材料が足りない見出しには「材料が足りない：〇〇」と書く
```

**③ 試した出力例**

（入力：報告書＝「本とコーヒー割」10月の報告／読む人＝オーナー／知りたいこと＝11月以降も続けるか／材料＝9月の結果（素材B）、10月は14〜15時半に短縮して実施、案内カードを作った）

```
【構成案：「本とコーヒー割」10月の報告】

1. 結論（続けたいかどうか）
　ここに、11月以降の店長としての考えを1〜2行で書く。
　材料が足りない：10月の結果と、店長の考え

2. 10月にしたこと
　ここに、時間を14〜15時半に短くしたことと、案内カードを作ったことを書く。

3. 結果（9月と10月のくらべ）
　ここに、客数・滞在時間・売上・お断りした日数を、9月と並べて書く。
　材料が足りない：10月の数字

4. 案内カードの効果
　ここに、満席時の案内がどう変わったか（スタッフの声など）を書く。
　材料が足りない：スタッフの声

5. 残っている課題
　ここに、フードの注文の様子などを書く。
　材料が足りない：10月のフードの注文の様子

6. 11月以降の案と、相談したいこと
　ここに、続ける場合・やめる場合の案と、オーナーに決めてほしいことを書く。
```

**④ うまくいかないときの直し方**

- **構成案ではなく、本文を書きはじめる** → 「本文はまだ書かない」を一番上に書く。
- **見出しが多すぎる** → 「見出しは5つまで」と数を決める。

## テンプレ41　報告書を「A4・1枚」に収まる長さにまとめる

**① 場面**

報告書が長くなりすぎた。1枚にまとめるように言われた。

**② コピペ用の頼み方**

```
以下の報告書を、［例：A4・1枚、約600字］に収まるように短くしてください。

・必ず残すこと：［例：数字の結果、今後の案、相談したいこと］
・削ってよいこと：［例：きっかけの説明、スタッフの声のくわしい内容］
・数字は変えない
・最後に「削った内容」を箇条書きで書く（あとで聞かれたときのため）

---ここから---
［ここに報告書を貼る］
---ここまで---
```

**③ 試した出力例**

（入力：素材B、約300字に短く、必ず残すこと＝数字の結果・今後の案、削ってよいこと＝スタッフの声）

```
9月、平日14〜16時に「本とコーヒー割」（ドリンク50円引き）を試しました。

**④ うまくいかないときの直し方**

- **残してほしい内容まで削られる** → 「必ず残すこと」をもっと具体的に書く。

## テンプレ42　報告書の「わかりにくい所」を指摘してもらう

**① 場面**

報告書を書き終えた。提出する前に、読む人にとってわかりにくい所がないか見てほしい。

**② コピペ用の頼み方**

```
以下の報告書を、［読む人：例 この件を初めて聞くオーナー］になったつもりで読んで、
わかりにくい所・質問したくなる所を、5つまで指摘してください。

・書き直しはしない。指摘と、その理由だけ
・大事な順に並べる

---ここから---
［ここに報告書を貼る］
---ここまで---
```

**③ 試した出力例**（入力：素材B、読む人＝この件を初めて聞くオーナー）

```
1. 店長としては、どの案がいちばんよいと考えているのか
　理由：3つの案が並んでいますが、おすすめが書かれていないため、判断のきっかけがつかみにくいです。

2. お断りした3日間で、どのくらいのお客さまをお断りしたのか
　理由：日数はわかりますが、人数がないと、影響の大きさがつかめません。

3. 売上「およそ2,000円増」は、元の売上から見てどのくらいの増え方か
　理由：8月とくらべていることは書かれていますが、8月の同じ時間帯の売上がいくらかがないため、増え方の大きさがわかりにくいです。

4. 「本とコーヒー割」を使ったお客さまは、23人のうち何人か
　理由：客数が増えた理由が割引なのか、ほかの理由なのかが読み取りにくいです。

5. 案②のメニュー表の作り直しには、どのくらいの手間や費用がかかるのか
　理由：「すぐにできない」案を選ぶかどうか判断するのに必要です。
```

**④ うまくいかないときの直し方**

- **指摘が細かすぎる（言葉づかいなど）** → 「内容に関する指摘だけ」と書く。
- **指摘どおりに直すべきかは、自分で判断する** → AIの指摘は「読む人の気持ちの想像」です。すべてに答える必要はありません。

## テンプレ43　報告書の数字を、表やグラフ用の形にまとめる

**① 場面**

報告書の数字を、表計算ソフトで表やグラフにしたい。

**② コピペ用の頼み方**

```
以下の文章から、［例：くらべている前と後］の数字を取り出して、表計算ソフトに貼れる形にしてください。

・1行目は見出し（項目、［前］、［後］、単位）
・タブ区切りで出す
・文章にない数字は空欄にする。計算はしない

---ここから---
［ここに文章を貼る］
---ここまで---
```

**③ 試した出力例**（入力：素材B、前＝8月、後＝9月）

※実際の出力はタブ区切りです。本では読みやすいように表にしています。

| 項目 | 8月 | 9月 | 単位 |
|---|---|---|---|
| 14〜16時の客数（1日平均） | 18 | 23 | 人 |
| 平均滞在時間 | 約40 | 約65 | 分 |
| 満席でお断りした日 | （空欄） | 3 | 日 |
| 売上の増加（1日平均、8月比） | （空欄） | およそ2,000 | 円 |

**④ うまくいかないときの直し方**

- **「約」「およそ」がついた数字は、グラフにしにくい** → この例では残してくれました。グラフにするときは「約」を外すかどうか自分で判断し、グラフの注に「約」と書いておくと正直です。
- **「8月の滞在時間は約40分」と、元の文章にない月を当てはめる** → この例の「約40分」は、元の文章では「8月」とははっきり書かれていません（「約40分から約65分に延びました」）。こうした読み取りがないか、元の文章と見くらべてください。

## テンプレ44　「えーと」「あのー」などを取りのぞく

**① 場面**

文字起こしが「えーと」だらけで読みにくい。中身はそのままで、読みやすくしたい。

**② コピペ用の頼み方**

```
以下の文字起こしから、「えーと」「あのー」「えー」「なんか」などの、意味のないつなぎの言葉だけを取りのぞいてください。

・それ以外の言葉は変えない（言い回しも、話し言葉のままでよい）
・話者の表記はそのまま
・意味のある言葉かどうか迷うものは、残す

---ここから---
［ここに文字起こしを貼る］
---ここまで---
```

**③ 試した出力例**（入力：素材C。前半の6行を示します）

```
話者1：じゃあ始めます。来月の機関限定メニューの話なんですけど。
話者2：はい。
話者1：去年はかぼちゃのマッフィンだったじゃないですか。で、今年はどうしようかなと。
話者3：私はさつまいもがいいと思ってて、お客さんからも、さつまいもないの？って何回か聞かれたんですよね。
話者1：あー、なるほど。
話者2：でも、さつまいもって、仕込みが、けっこう時間かかりません？蒸して、つぶして、みたいな。
```

**④ うまくいかないときの直し方**

- **「あー、なるほど」の「あー」は残る** → あいづちとして意味があるとAIが判断したようです。消したいときは「『あー』も消してください」と、消す言葉を具体的に足す。
- **変換ミス（機関限定、マッフィン）は残る** → このテンプレでは「それ以外は変えない」と言っているので、正しい動きです。変換ミスはテンプレ46で直します。

## テンプレ45　話し言葉を、読みやすい書き言葉にする

**① 場面**

文字起こしを、記録として残せる文章にしたい。発言の中身は変えずに、文章を整えたい。

**② コピペ用の頼み方**

```
以下の文字起こしを、話し言葉から、読みやすい書き言葉に直してください。

・つなぎの言葉、言いよどみ、くり返しを取る
・発言の中身（意見・数字・日付・引き受けたこと）は変えない、足さない
・です・ます調にそろえる
・話者の表記：［例：話者1＝店長、話者2＝大野、話者3＝竹内］

---ここから---
［ここに文字起こしを貼る］
---ここまで---
```

**③ 試した出力例**（入力：素材C、話者1＝店長、話者2＝大野、話者3＝竹内）

```
店長：それでは始めます。来月の期間限定メニューについてです。
店長：去年はかぼちゃのマフィンでしたが、今年はどうしようかと考えています。
竹内：私はさつまいもがよいと思います。お客さまからも「さつまいもはないの？」と何回か聞かれました。
大野：さつまいもは、蒸してつぶすなど、仕込みにかなり時間がかかりませんか。
竹内：そうですね。なので、冷凍のペーストを使うのはどうかと考えています。
店長：まず、その原価がどのくらいか調べてもらえますか。
竹内：はい、私が来週の水曜までに調べます。
大野：あと、スタッフで試食会をしませんか。
店長：いいですね。では、再来週の月曜の閉店後にしましょう。
店長：ポスターは、去年のものを使い回すのではなく、新しく作りたいです。
大野：私が作れます。
店長：では、お願いします。以上です。
```

**④ うまくいかないときの直し方**

- **「了解です」「はい」などの短い発言が消える** → この例でも消えています。記録として全部残したいときは「短い返事も消さないでください」と足す。
- **「ちょっと、あれなんで」のような、はっきりしない言い方が、意味をつけて書きかえられる** → この例では、その部分が消えました。言いよどみに本音がかくれていることもあるので、大事な会議では元の文字起こしも残しておきましょう。

## テンプレ46　変換ミスと思われる所を、候補つきで指摘してもらう

**① 場面**

自動の文字起こしには、音が似た別の言葉への変換ミスがよくある。勝手に直さず、まず一覧で見たい。

**② コピペ用の頼み方**

```
以下の文字起こしの中で、変換ミス（音が似た別の言葉になっている所）と思われる所を探してください。

・本文は直さない
・「元の言葉」「正しいと思われる言葉」「そう思う理由」を表にする
・自信がないものには「自信なし」とつける

---ここから---
［ここに文字起こしを貼る］
---ここまで---
```

**③ 試した出力例**（入力：素材C）

```
| 元の言葉 | 正しいと思われる言葉 | そう思う理由 |
|---|---|---|
| 機関限定メニュー | 期間限定メニュー | 「来月の」メニューの話なので、時期を区切った「期間限定」と考えられます |
| マッフィン | マフィン | お菓子の名前として、一般的な書き方は「マフィン」です（言い方のくせの可能性もあり） |
| つかいまわす | 使い回す | 変換ミスではなく、ひらがなのまま書かれているだけと思われます（自信なし） |
```

**④ うまくいかないときの直し方**

- **変換ミスではないものまで出る** → 3行目のように、AIが「自信なし」と書いたものは、自分で判断してください。
- **専門用語・人の名前・商品名が、まちがって直される** → AIは社内の言葉や人の名前を知りません。「次の言葉は正しいので直さない：〇〇、△△」と、先にリストを渡しておくと減ります。

## テンプレ47　「話者1」「話者2」を、役割の名前に置きかえる

**① 場面**

文字起こしの話者が「話者1」「話者2」になっている。だれの発言かわかるようにしたい。

**② コピペ用の頼み方**

```
以下の文字起こしの話者の表記を、次のとおりに置きかえてください。

・［例：話者1 → 店長］
・［例：話者2 → スタッフA］
・［例：話者3 → スタッフB］

・置きかえ以外は、1文字も変えない
・表にない話者が出てきたら、そのままにして最後に知らせる

---ここから---
［ここに文字起こしを貼る］
---ここまで---
```

**③ 試した出力例**

（入力：素材C、話者1→店長、話者2→スタッフA、話者3→スタッフB。前半4行を示します）

```
店長：えーと、じゃあ始めます。あの、来月の機関限定メニューの話なんですけど。
スタッフA：はい。
店長：えー、去年はかぼちゃのマッフィンだったじゃないですか。で、今年はどうしようかなと。
スタッフB：あのー、私はさつまいもがいいと思ってて、えっと、お客さんからも、なんか、さつまいもないの？って何回か聞かれたんですよね。

（表にない話者はいませんでした）
```

**④ うまくいかないときの直し方**

- **本名ではなく役割名にしておくと、第2章の「置きかえ」にもなる** → AIに入れる前に、自分で「話者1→店長」と置きかえておく使い方もおすすめです。この場合、置きかえは**メモ帳の「置換」機能などで自分でやる**ほうが、名前をAIに入れずにすみます。
- **文字起こしの話者の区切りがまちがっている** → AIには直せません。録音を聞き直してください。

## テンプレ48　段落に分けて、小見出しをつける

**① 場面**

1時間の打ち合わせの文字起こしが、ずっと続いていて読みにくい。話題ごとに区切りたい。

**② コピペ用の頼み方**

```
以下の文字起こしを、話題が変わる所で区切って、それぞれに短い小見出しをつけてください。

・小見出しは「■」から始めて15字以内
・発言そのものは変えない（つなぎの言葉も残してよい）
・最後に、小見出しだけの一覧（目次）をつける

---ここから---
［ここに文字起こしを貼る］
---ここまで---
```

**③ 試した出力例**（入力：素材C。区切りと最初の発言だけを示します）

```
■期間限定メニューの候補
話者1：えーと、じゃあ始めます。あの、来月の機関限定メニューの話なんですけど。
（〜話者3：…さつまいもないの？って何回か聞かれたんですよね。まで）

■さつまいもの仕込みと原価
話者2：でも、さつまいもって、仕込みが、えー、けっこう時間かかりません？…
（〜話者3：はい、じゃあ、私、調べます。来週の水曜までに。まで）

■スタッフの試食会
話者2：あと、あの、試食会、やりません？スタッフで。
（〜話者2：了解です。まで）

■ポスターの作り直し
話者1：えっと、あと、ポスターは、去年のをつかいまわすのは、…
（〜話者1：じゃあ、お願いします。えー、以上かな。まで）

【目次】
■期間限定メニューの候補
■さつまいもの仕込みと原価
■スタッフの試食会
■ポスターの作り直し
```

**④ うまくいかないときの直し方**

- **小見出しに変換ミスがうつる／勝手に直る** → この例では小見出しは「期間限定」と直されていました。本文と小見出しで表記がちがうと混乱するので、先にテンプレ46で変換ミスを直してから使うのがおすすめです。
- **区切りが細かすぎる** → 「区切りは5つまで」と数を決める。

## テンプレ49　発言の中から「要点」だけを一覧にする

**① 場面**

長い文字起こしを全部読む時間はない。話の要点だけをつかみたい。

**② コピペ用の頼み方**

```
以下の文字起こしから、要点だけを箇条書きで5つ以内にまとめてください。

・それぞれの要点に、だれの発言かを（　）で書く
・決まったこと、引き受けたこと、意見のちがいがあれば優先する
・発言にないことは書かない

---ここから---
［ここに文字起こしを貼る］
---ここまで---
```

**③ 試した出力例**（入力：素材C、話者1＝店長、話者2＝大野、話者3＝竹内と伝えたうえで）

```
・来月の期間限定メニューに、さつまいもを使う案が出た。お客さまからの要望もあるとのこと（竹内）。
・さつまいもは仕込みに時間がかかるという心配があり（大野）、冷凍ペーストを使う案が出た（竹内）。
・冷凍ペーストの原価を、竹内さんが来週の水曜までに調べる（店長の依頼、竹内が引き受け）。
・スタッフでの試食会を、再来週の月曜の閉店後に行う（大野の提案、店長が決定）。
・ポスターは新しく作り、大野さんが担当する（店長の希望、大野が引き受け）。
```

**④ うまくいかないときの直し方**

- **「さつまいもに決定」のように、まだ決まっていないことが決まったように書かれる** → この例では「案が出た」と書いてくれましたが、要約が短いほど、こうしたズレが出やすくなります。「決まったことと、案の段階のことを分けて書いてください」と足すと安心です。

## テンプレ50　インタビューの文字起こしを「Q&A」の形にする

**① 場面**

お客さまの声や、社内報のインタビューを文字にしたもの。読みやすいQ&Aの形にしたい。

**② コピペ用の頼み方**

```
以下はインタビューの文字起こしです。Q&A（質問と答え）の形に整えてください。

・質問する人を「Q」、答える人を「A」にする
・答えは、話し言葉のやわらかさを少し残しつつ、読みやすくする
・答えの中身は変えない、足さない
・質問の言葉は、短く整えてよい

---ここから---
［ここに文字起こしを貼る］
---ここまで---
```

**③ 試した出力例**

（入力：次の架空の社内報インタビュー）

```
聞き手：えっと、入社してどのくらいですか？
回答者：あ、半年です、ちょうど。
聞き手：お仕事で、えー、楽しいことって何ですか？
回答者：うーん、なんだろう、お客さんに、ありがとうって言われたときですかね、やっぱり。あと、先輩が、あの、すごく丁寧に教えてくれるので、それもうれしいです。
聞き手：最後に、ひとこと。
回答者：えー、まだまだですけど、がんばります！
```

↓ AIの出力

```
Q. 入社してどのくらいですか？
A. ちょうど半年です。

Q. お仕事で楽しいことは何ですか？
A. やっぱり、お客さまに「ありがとう」と言われたときですね。
　 あと、先輩がすごく丁寧に教えてくれるので、それもうれしいです。

Q. 最後にひとことお願いします。
A. まだまだですけど、がんばります！
```

**④ うまくいかないときの直し方**

- **「お客さん」が「お客さま」に変わる** → この例でも、AIがていねいな言葉に直しました。話した人の言葉をそのまま残したいときは「言葉づかいは変えない」と足す。
- **社内報などで外に出すときは、本人に見せてから** → 整えた文が、本人の言いたかったことと合っているか、公開前に本人に確認してもらいましょう。

## テンプレ51　長い文字起こしを、何回かに分けて頼む

**① 場面**

1時間以上の会議の文字起こしなど、長すぎて一度に貼れない（または、途中から答えが雑になる）。

**② コピペ用の頼み方**

（1回目に送る文）

```
これから、長い会議の文字起こしを［例：3回］に分けて送ります。
各回の文字起こしを受け取ったら、次のことだけをしてください。

・その回の要点を5つ以内の箇条書きにする
・決まったこと・引き受けたこと（だれが・いつまでに）は、必ず入れる
・最後の回を送ったあとに「全体をまとめてください」と言うので、それまでは全体のまとめをしない

では、1回目です。
---ここから---
［ここに文字起こしの1つ目のかたまりを貼る］
---ここまで---
```

（2回目以降に送る文）

```
［例：2回目／3回目（最後）］です。同じルールでお願いします。
---ここから---
［ここに次のかたまりを貼る］
---ここまで---
```

（最後に送る文）

```
全体をまとめてください。
・各回の要点をもとに、「決まったこと」「保留」「やること（担当・期限）」の3つにまとめる
・各回の要点にないことは書かない
```

**③ 試した出力例**

（入力：素材Cを「最初〜話者1：あー、なるほど。」「話者2：でも、〜話者2：了解です。」「話者1：えっと、あと、ポスターは〜最後」の3つに分けて送った）

```
【1回目の要点】
・来月の期間限定メニューについて話し合いを始めた（話者1）。
・去年はかぼちゃのマフィンだった（話者1）。
・さつまいもがよいという意見。お客さまから何回か要望があった（話者3）。

【2回目の要点】
・さつまいもは仕込みに時間がかかるという心配（話者2）。
・冷凍のペーストを使う案（話者3）。
・ペーストの原価を、話者3が来週の水曜までに調べる。
・スタッフの試食会を、再来週の月曜の閉店後に行う（話者2の提案、話者1が決定）。

【3回目の要点】
・ポスターは去年のものを使わず、新しく作る（話者1）。
・ポスターは話者2が作る。

【全体のまとめ】
■決まったこと
・スタッフの試食会を、再来週の月曜の閉店後に行う。
・ポスターは新しく作る。
■保留
・来月の期間限定メニューに、さつまいも（冷凍ペースト）を使うかどうか（原価を調べてから）。
■やること
・冷凍ペーストの原価を調べる　担当：話者3　期限：来週の水曜
・ポスターを作る　担当：話者2　期限：不明
```

**④ うまくいかないときの直し方**

- **途中で全体のまとめを始めてしまう** → 「それまでは全体のまとめをしない」を、毎回の文にも入れる。
- **前の回の内容を忘れたような答えになる** → 長い会話では、前の内容が反映されにくくなることがあります。各回の要点を自分でコピーしておき、最後に「以下の要点をまとめてください」と、要点をまとめて貼り直す方法が確実です。
- **かたまりの区切り方** → 話の途中で切ると、発言の意味が切れてしまいます。話題が変わる所や、発言の切れ目で区切りましょう。

## テンプレ53　敬語・言い回しを、相手に合わせて整える

**① 場面**

議事録や報告を、目上の人や社外の人に送る。言葉づかいが失礼になっていないか心配。

**② コピペ用の頼み方**

```
以下の文章を、［相手：例 取引先の担当者／上司］に送ります。
敬語や言い回しで、失礼に聞こえる所・くだけすぎた所を直してください。

・内容（事実・数字・日付）は変えない
・直した所は、元の言い方と直した言い方を並べて一覧にする
・そのあとに、直した文章の全体を出す

---ここから---
［ここに文章を貼る］
---ここまで---
```

**③ 試した出力例**

（入力：相手＝上司、次の架空の文章）

```
おつかれさまです。会議の結果、送っときます。
POPは林さんが金曜までにやってくれるそうです。
SNSの件はまだ決まってないので、次回また話します。
了解しました。
```

↓ AIの出力

```
【直した所】
・「送っときます」→「お送りします」
・「やってくれるそうです」→「作成してくれることになりました」
・「まだ決まってないので」→「まだ決まっていないため」
・「次回また話します」→「次回あらためて話し合います」
・「了解しました」→ 文の最後にあると意味がわかりにくいため、「以上です。よろしくお願いいたします。」に置きかえました。

【直した文章】
おつかれさまです。会議の結果をお送りします。
POPは、林さんが金曜までに作成してくれることになりました。
SNSの件はまだ決まっていないため、次回あらためて話し合います。
以上です。よろしくお願いいたします。
```

**④ うまくいかないときの直し方**

- **ていねいすぎて長くなる** → 「社内の上司なので、ていねいすぎない言い方で」と、距離感を伝える。
- **「了解しました」の扱いのように、AIが文の意味を読み取って変える** → 置きかえた理由を一覧で見せてもらうと、意図しない変更に気づけます。

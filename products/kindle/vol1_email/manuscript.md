# この本について

- この本は、AI（スライム王国のライターAI）が企画・執筆しました。表紙もAIがプログラムで作りました。
- 本の中の「出力例」は、執筆したAI（Claude）が、それぞれのテンプレに例の内容を入れて、実際に答えた文章です。**AIの答えは毎回変わります。** 同じ頼み方でも、あなたの画面では少し違う文章が出てきます。
- 出力例に出てくる会社名・人名・日付・商品名は、すべて説明のための架空のものです。
- ChatGPTやClaudeなど、ふだん使っている対話型AIで使えるように、特定のサービスに頼らない書き方にしています。特定のサービスの画面・機能・料金の説明はしていません。AIによって答え方のくせはちがうので、出力例と同じ文になるとはかぎりません。
- AIが書いたメールは、**送る前に必ず自分の目で読んでください。** 日付・金額・名前・約束した内容は、AIがまちがえることがあります。

# はじめに　ぷるのがご案内します

こんにちは。スライムの**ぷるの**です。ぷるぷるしています。

メールが苦手、という人は多いかもしれません。お礼を書こうとすると「いつもお世話になっております」で手が止まり、お詫びを書こうとすると、どこまで謝ればいいのかわからなくなって、気づくと30分たっている……。

そこでAIに頼んでみました。最初はこう書きました。

> お礼のメールを書いて

出てきたのは、だれにでも送れる、だれにも響かないメールでした。

次に、こう書きました。

> 取引先の山田さんに、昨日の打ち合わせのお礼メールを書いて。見積もりを金曜までに送ると約束したので、それも入れて。200字くらいで、かたすぎない感じで。

今度は、そのまま送れそうなメールが出てきました。

ちがいは**「だれに」「何があって」「何を入れて」「どのくらいの長さで」**を伝えたかどうか、だけです。AIは、言われていないことはわかりません。逆に言えば、言えばちゃんとやってくれます。

この本には、仕事のメールでよくある場面ごとに、**コピペしてそのまま使える頼み方**を56個のせました。使い方はかんたんです。

1. 自分の場面に近いテンプレを探す
2. ［　］のところを自分の内容に書きかえる
3. AIにはりつけて送る
4. 出てきた文章を読んで、気になるところを直してもらう

それぞれのテンプレには、ぼくが実際に試したときの**出力例**と、**うまくいかないときの直し方**もつけました。出力例は「こんな感じのものが出てくる」という見本です。そのまま使うより、あなたの言葉に寄せて直すと、もっとよくなります。

では、いっしょにぷるぷる始めましょう。

# 第1章　AIへの頼み方の基本

テンプレに入る前に、どの場面でも使える「頼み方の基本」を5つだけ覚えておきましょう。この5つがわかると、テンプレを自分で改造できるようになります。

## 基本1　「だれに送るか」を書く

同じお礼でも、社長に送るのと、同期に送るのとでは、言葉づかいがまったくちがいます。

- 社外か、社内か
- 相手の立場（上司・取引先の担当者・初めての相手など）
- 相手との距離（何度もやりとりしている／初めて）

この3つを書くだけで、敬語の強さがちょうどよくなります。

## 基本2　「何があったか」を事実で書く

AIは、あなたの仕事の事情を知りません。「昨日の件」と書いても、何の件かはわかりません。

- いつ、何があったか
- 相手が何をしてくれたか（してしまったか）
- こちらがこれから何をするか

この3つを、箇条書きでかまわないので書きます。**AIが勝手に事実を足すことがある**ので、事実はこちらから渡すのが安全です。

## 基本3　「入れてほしいこと」「入れてほしくないこと」を書く

- 入れてほしいこと：日付、締め切り、次の約束、具体的なお礼のポイント
- 入れてほしくないこと：言い訳、大げさな表現、「させていただく」の連発 など

「〜は書かないで」と言うのも、立派な頼み方です。

## 基本4　「長さ」と「かたさ」を決める

- 長さ：「200字くらい」「3〜4行で」「件名と本文で」
- かたさ：「ていねいに」「かたすぎない感じで」「社内向けのふつうの敬語で」

何も言わないと、AIは長めで、かための文章を出しがちです。

## 基本5　1回で完成させようとしない

出てきた文章が「ちょっとちがう」ときは、最初から書き直さずに、**続けて注文を出す**のがコツです。

- 「もう少し短くして」
- 「2文目の言い訳っぽいところを消して」
- 「件名を3つ考えて」
- 「もっとやわらかく」

同じ会話（チャット）の中なら、AIは前のやりとりをふまえて答えてくれるので、少しずつ直していけます。新しい会話を始めると前の内容は引きつがれないことがあるので、直すときは同じ会話の続きで頼みましょう。

## 安全のための3つの約束

AIは便利ですが、メールには大事な情報がふくまれます。ぷるのと約束してください。

1. **個人情報や社外秘は入れない。** 本名・電話番号・住所・契約の中身などは、「Aさん」「〇〇の件」のようにぼかして入れ、送る前に自分で書き戻しましょう。会社にAIの使い方のルールがあれば、そちらを優先してください。
2. **事実は自分で確かめる。** 日付・曜日・金額・名前は、AIがまちがえたり、勝手に作ったりすることがあります。
3. **最後は自分の言葉で送る。** AIの文章はたたき台です。送るボタンを押すのは、あなたです。

## この本のテンプレの読み方

各テンプレは、次の4つでできています。

- **場面**：どんなときに使うか
- **頼み方（コピペ用）**：AIにはりつける文章。［　］のところを書きかえます
- **試してみた**：［　］に入れた例と、そのときAIが出した文章
- **うまくいかないときは**：よくあるズレと、その直し方

［　］の中に書いてあるのは「ここに何を入れるか」の説明です。全部埋めなくても動きますが、埋めるほど、あなたらしいメールになります。

> **ぷるののひとこと**\
> テンプレの最後にはだいたい「200字程度」と書いてあります。長さは好みで変えてOK。ぼくは短めが好きです。

# 第2章　お礼のメール

お礼のメールは「早く・具体的に」が大事とよく言われます。AIに頼むときも、**相手が何をしてくれたか**を具体的に書くのがいちばんのコツです。

## テンプレ01　打ち合わせのお礼（社外）

**場面**：取引先と打ち合わせをした当日〜翌日に送るお礼。次にやることも伝えたいとき。

**頼み方（コピペ用）**

```
取引先への、打ち合わせのお礼メールを書いてください。
・相手：［会社名・部署・名前］
・打ち合わせの日と内容：［いつ・何について話したか］
・特に助かったこと：［相手の発言や資料など］
・こちらが次にやること：［何を・いつまでに］
件名もつけて、本文は200字程度、ていねいだけどかたすぎない文にしてください。
```

**試してみた**

入れた内容：相手＝株式会社みなと企画 営業部 山田様／10月20日、新商品の販促の打ち合わせ／店頭の写真を見せてもらって売り場のイメージがわいた／見積もりを10月23日までに送る

出力例：

> 件名：本日のお打ち合わせのお礼（新商品の販促について）
>
> 株式会社みなと企画　営業部　山田様
>
> いつもお世話になっております。本日はお忙しいところ、お時間をいただきありがとうございました。\
> 店頭のお写真を拝見でき、売り場のイメージを具体的につかむことができました。大変助かりました。\
> お話しした内容をもとに、お見積もりを10月23日（金）までにお送りいたします。\
> 引き続きどうぞよろしくお願いいたします。

**うまくいかないときは**

- 自分の名前・会社名が入っていない → 「最後に署名として［自分の会社名・名前］を入れて」と追加します。
- 曜日が入っていてもいなくても、**曜日は自分で確認**しましょう。AIは曜日をまちがえることがあります。
- 「大変助かりました」が軽く見える相手なら → 「お礼の部分をもう一段ていねいに」と頼みます。

## テンプレ02　資料を送ってもらったお礼

**場面**：頼んでいた資料やデータを送ってもらったとき。受け取ったことも伝えたい。

**頼み方（コピペ用）**

```
資料を送ってもらったお礼のメールを書いてください。
・相手：［名前と、社内か社外か］
・受け取ったもの：［資料の名前］
・何に使うか：［使い道］
・ひとこと感想：［あれば。例：わかりやすかった］
3〜4行で、短めにお願いします。
```

**試してみた**

入れた内容：社外の佐藤様／製品カタログの最新版／来週の社内説明会で使う／図が多くて説明しやすそう

出力例：

> 佐藤様
>
> お世話になっております。製品カタログの最新版をお送りいただき、ありがとうございます。無事に受け取りました。\
> 図が多く、来週の社内説明会でもとても説明しやすそうです。\
> 取り急ぎ、お礼と受領のご連絡まで失礼いたします。

**うまくいかないときは**

- 長くなりすぎた → 「2行に減らして」と言うと、さらに短くなります。
- 「取り急ぎ」を使いたくない → 「『取り急ぎ』を使わない言い方にして」と頼みます。相手によっては気にする人もいるので、言いかえの候補を聞いてもいいです。

## テンプレ03　紹介してもらったお礼

**場面**：知り合いや取引先から、別の人や会社を紹介してもらったとき。

**頼み方（コピペ用）**

```
人を紹介してもらったお礼のメールを書いてください。
・紹介してくれた人：［名前・関係］
・紹介された人：［名前・会社など］
・その後どうなったか：［連絡を取った、会う予定 など］
・感謝の気持ちを伝えたいポイント：［例：自分では会えなかった人だった］
件名つき、200字程度でお願いします。
```

**試してみた**

入れた内容：紹介してくれた人＝前の部署でお世話になった高橋さん（社外に移った元上司）／紹介された人＝デザイン会社の中村さん／来週の火曜にオンラインで話す予定／自分では探せなかった専門の人だった

出力例：

> 件名：中村様をご紹介いただいたお礼
>
> 高橋さん
>
> ご無沙汰しております。先日は、デザイン会社の中村様をご紹介いただき、本当にありがとうございました。\
> さっそくご連絡したところ、来週火曜日にオンラインでお話しできることになりました。自分ではなかなか探せなかった分野の方なので、とても心強いです。\
> お話しした内容は、また改めてご報告させてください。

**うまくいかないときは**

- 元上司なのに、かたすぎる／くだけすぎる → 「元上司で、今も親しくしている相手です」と関係を詳しく書くと、ちょうどよくなります。
- 「改めてご報告」のように**後で約束が増える**ことがあります。本当にやるつもりがなければ消してもらいましょう。

## テンプレ04　手伝ってもらったお礼（社内）

**場面**：同じ部署や別の部署の人に、作業を手伝ってもらったとき。社内チャットでもメールでも。

**頼み方（コピペ用）**

```
社内の人に、手伝ってもらったお礼のメッセージを書いてください。
・相手：［名前・部署・自分との関係（先輩、同期など）］
・手伝ってもらったこと：［具体的に］
・その結果：［例：締め切りに間に合った］
社内向けのふつうの敬語で、3行くらいでお願いします。
```

**試してみた**

入れた内容：経理部の木村さん（先輩）／月末の集計表のチェックを手伝ってもらった／入力ミスが2か所見つかって、提出前に直せた

出力例：

> 木村さん
>
> 昨日は集計表のチェックを手伝っていただき、ありがとうございました。\
> 入力ミスを2か所見つけていただいたおかげで、提出前に直すことができました。\
> 次に何かあれば、私にもぜひお手伝いさせてください。

**うまくいかないときは**

- チャット用にもっと軽くしたい → 「社内チャット用に、1〜2文で」と頼みます。
- 「ぜひお手伝いさせてください」が大げさに感じたら → 「最後の一文はなしで」と消せます。

## テンプレ05　お祝いへのお礼（昇進・異動など）

**場面**：昇進や異動、受賞などでお祝いのメッセージや品物をもらったとき。

**頼み方（コピペ用）**

```
お祝いをもらったことへのお礼のメールを書いてください。
・相手：［名前・関係］
・何のお祝いか：［例：課長への昇進］
・もらったもの：［メッセージ、花、品物など］
・これからの抱負をひとこと：［例：チームの話をよく聞く課長になりたい］
200字程度、うれしい気持ちが伝わるようにお願いします。
```

**試してみた**

入れた内容：取引先の松本様／課長への昇進／お花をいただいた／チームの声をよく聞く課長になりたい

出力例：

> 松本様
>
> いつもお世話になっております。このたびは、昇進のお祝いにすてきなお花をお送りいただき、ありがとうございました。職場に飾らせていただき、メンバーとともに楽しんでおります。\
> まだまだ至らない点も多いですが、チームの声をよく聞く課長になれるよう努めてまいります。\
> 今後とも変わらぬご指導のほど、よろしくお願いいたします。

**うまくいかないときは**

- 「職場に飾らせていただき」のように、**AIが事実を足す**ことがあります。実際にそうしていなければ消してください。この本の出力例でも、何度か起きています。
- 抱負がかたい → 「抱負の部分を、自分の言葉っぽく、少しくだけた感じに」と頼みます。

## テンプレ06　食事やイベントに招いてもらったお礼

**場面**：会食、懇親会、展示会などに招待してもらった翌日に送るお礼。

**頼み方（コピペ用）**

```
招待してもらったお礼のメールを書いてください。
・相手：［名前・関係］
・招いてもらったもの：［会食・懇親会・イベントの名前と日にち］
・印象に残ったこと：［話題、料理、展示など1つ］
・今後について：［例：また情報交換したい］
件名つき、200字程度でお願いします。
```

**試してみた**

入れた内容：取引先の井上部長／10月17日の懇親会／物流の話がおもしろかった（倉庫の配置の工夫）／また情報交換したい

出力例：

> 件名：昨日の懇親会のお礼
>
> 井上部長
>
> いつも大変お世話になっております。昨日は懇親会にお招きいただき、誠にありがとうございました。\
> 倉庫の配置の工夫についてのお話は大変興味深く、私どもの業務にも活かせそうなヒントをたくさんいただきました。\
> ぜひまた、情報交換の機会をいただけましたら幸いです。\
> 今後ともどうぞよろしくお願いいたします。

**うまくいかないときは**

- 日付が「昨日」になっているので、**送る日がずれたら直す**のを忘れずに。「日付は『10月17日』と書いて」と頼むと安全です。
- どの会でも同じような文になる → 「印象に残ったこと」をもっと具体的に書くと、その人だけのメールになります。

## テンプレ07　問い合わせへの返信でのお礼（お客さま向け）

**場面**：お客さまからの問い合わせや意見に、まずお礼を伝えてから答えるとき。

**頼み方（コピペ用）**

```
お客さまからの問い合わせへの返信を書いてください。
・お客さまの問い合わせ内容：［要点］
・こちらの答え：［答え・対応］
・お礼したいポイント：［例：わかりやすく書いてくれた、意見をくれた］
最初にお礼、次に答え、最後に結びの順で、250字程度、ていねいな言葉でお願いします。
答えの部分は、私が書いた内容以外のことを足さないでください。
```

**試してみた**

入れた内容：注文した商品の色を変えられるか／発送前なら変更できる、注文番号を返信してもらえれば対応する／くわしく書いてくれたので確認しやすかった

出力例：

> このたびはお問い合わせいただき、ありがとうございます。ご注文内容をくわしくお書きいただいたおかげで、すぐに確認することができました。
>
> ご注文商品の色の変更についてですが、発送前であれば変更が可能です。お手数ですが、このメールにご注文番号を添えてご返信いただけますでしょうか。確認のうえ、こちらで変更の手続きをいたします。
>
> ご不明な点がございましたら、お気軽にお問い合わせください。

**うまくいかないときは**

- 「私が書いた内容以外のことを足さないで」は、お客さま向けではとくに大事です。これを消すと、AIが「〇日以内に」など、決めていない約束を書くことがあります。
- 会社名や担当者名を入れたい → 「最後に［会社名・担当者名］の署名を入れて」と追加します。

> **ぷるののひとこと**\
> お礼メールは、AIに頼むと「ありがとうございました」が3回くらい出てくることがあります。そんなときは「お礼の言葉は1回だけにして」と言うと、すっきりします。

# 第3章　お詫びのメール

お詫びは、いちばんAIに頼みたくなる場面かもしれません。ただし、**何をまちがえたか・どう直すか**は、自分で決めてからAIに渡しましょう。AIは事情を知らないので、そこを任せると、ふわっとしたお詫びになります。

## テンプレ08　返信が遅れたお詫び

**場面**：メールの返信が数日遅れてしまったとき。用件にもちゃんと答えたい。

**頼み方（コピペ用）**

```
返信が遅れたことのお詫びと、用件への答えをまとめたメールを書いてください。
・相手：［名前・社内か社外か］
・遅れた期間：［例：3日］
・相手の用件：［何を聞かれていたか］
・こちらの答え：［答え］
お詫びは最初に短く1〜2文、そのあと答え、という順で、言い訳は書かないでください。200字程度でお願いします。
```

**試してみた**

入れた内容：社外の小林様／4日／来月の展示会に出展するかどうか／出展する、ブースは小さいサイズで申し込みたい

出力例：

> 小林様
>
> お世話になっております。ご連絡をいただいてから返信が遅くなり、大変申し訳ございません。
>
> 来月の展示会につきまして、弊社は出展させていただく予定です。ブースは小さいサイズでの申し込みを希望しております。\
> お手続きに必要な書類などがございましたら、お知らせいただけますと幸いです。
>
> 引き続きよろしくお願いいたします。

**うまくいかないときは**

- 「言い訳は書かないで」を消すと、「立て込んでおりまして」などが入りやすくなります。理由を伝えたいなら、自分で一言書いて渡しましょう。
- 最後の「書類などがございましたら」は、AIが気をきかせて足した部分です。いらなければ消してもらいます。

## テンプレ09　まちがった内容を送ってしまったお詫び（訂正）

**場面**：日時・金額・資料などをまちがえて送ってしまい、訂正したいとき。

**頼み方（コピペ用）**

```
前に送ったメールの内容をまちがえていたので、訂正とお詫びのメールを書いてください。
・相手：［名前・関係］
・まちがえた内容：［誤］
・正しい内容：［正］
・相手にお願いしたいこと：［例：前の資料を削除してほしい］
件名に「訂正」と入れて、誤と正がひと目でわかるように書いてください。200字程度。
```

**試してみた**

入れた内容：社外の田中様／打ち合わせの日時を「11月5日 14時」と書いた／正しくは「11月6日 14時」／カレンダーに入れていたら直してほしい

出力例：

> 件名：【訂正】お打ち合わせ日時について
>
> 田中様
>
> お世話になっております。先ほどお送りしたメールで、お打ち合わせの日時に誤りがございました。大変失礼いたしました。
>
> 誤：11月5日 14時\
> 正：11月6日 14時
>
> すでにご予定に入れていただいている場合は、お手数ですが修正をお願いいたします。\
> 確認不足でご迷惑をおかけし、申し訳ございません。

**うまくいかないときは**

- 訂正メールで、**さらにまちがえる**のがいちばん怖いです。誤と正の日付は、AIの出力を必ず自分で見くらべてください。
- 「誤」「正」の並べ方を表にしたい → 「誤と正を表の形で」と頼むこともできますが、メールでは表がくずれることがあるので、行を分けるほうが安全です。

## テンプレ10　納期・締め切りに遅れるお詫び

**場面**：約束した納期や提出日に間に合わないことがわかったとき。早めに知らせたい。

```
納期に遅れることを知らせるお詫びのメールを書いてください。
・相手：［名前・関係］
・もともとの約束：［何を・いつまでに］
・新しい予定：［いつまでに出せるか］
・遅れる理由（短く）：［例：確認に時間がかかっている］
・相手への影響を減らすためにできること：［例：先に一部だけ送る］
お詫び、新しい予定、できること、の順で、言い訳っぽくならないように250字程度で。
```

**試してみた**

入れた内容：社外の渡辺様／提案書を10月23日までに／10月28日に出せる／価格の社内確認に時間がかかっている／目次と前半を先に23日に送る

出力例：

> 渡辺様
>
> お世話になっております。10月23日にお送りするお約束をしておりました提案書ですが、価格の社内確認に時間を要しており、期日までにお届けすることが難しくなりました。ご迷惑をおかけし、誠に申し訳ございません。
>
> 完成版は10月28日にお送りいたします。\
> なお、目次と前半部分につきましては、お約束どおり10月23日にお送りいたしますので、先にご確認いただけますと幸いです。
>
> 何卒よろしくお願いいたします。

**うまくいかないときは**

- 理由が長くなる → 「理由は1文以内で」と書くとまとまります。
- 新しい日付は、**本当に守れる日**だけを書きましょう。AIは書いた日付をそのまま約束として書きます。

## テンプレ11　会議に遅刻・欠席したお詫び

**場面**：打ち合わせに遅れた、または急に出られなかったときの、あとからのお詫び。

**頼み方（コピペ用）**

```

・相手：［名前・関係］
・会議：［日時・内容］
・理由（短く）：［例：電車の遅れ］
・これからすること：［例：議事録を確認して、意見を明日までに送る］
3〜5行で、くどくならないようにお願いします。
```

**試してみた**

入れた内容：欠席／社内の課長の岡田さん／10月21日10時の定例会議／子どもの急な発熱／議事録を読んで、自分の担当分の意見を翌日の昼までに送る

出力例：

> 岡田課長
>
> 本日10時の定例会議を、子どもの急な発熱のため欠席してしまい、申し訳ありませんでした。\
> 議事録を確認し、私の担当分についての意見を明日の昼までにお送りします。\
> ご迷惑をおかけしますが、よろしくお願いいたします。

**うまくいかないときは**

- 家庭の事情などを**どこまで書くか**は、自分で決めましょう。書きたくなければ「理由は『私用のため』として」と頼めます。
- 社外の会議なら → 相手を社外にして「ていねいな言葉で」と変えるだけで、そのまま使えます。

## テンプレ12　こちらのミスで迷惑をかけたお詫び（社外）

**場面**：発送ミス、入力ミスなど、こちらのミスで取引先に迷惑をかけたとき。

**頼み方（コピペ用）**

```
こちらのミスで迷惑をかけたことへのお詫びメールを書いてください。
・相手：［会社名・名前］
・起きたこと：［何が・いつ］
・原因（わかっている範囲で）：［例：確認の手順が抜けていた］
・すでにした対応：［例：正しい品を今日発送した］
・再発を防ぐためにすること：［例：発送前に2人で確認する］
お詫び、対応、再発防止、の順で、300字程度、誠実な言葉で。大げさにはしないでください。
```

**試してみた**

入れた内容：株式会社やまびこ 購買部 石井様／10月18日に届いた品の数が10箱のところ8箱だった／出荷の数え直しが抜けていた／足りない2箱を本日発送、明日着／出荷前に別の人がもう一度数える

出力例：

> 株式会社やまびこ　購買部　石井様
>
> いつもお世話になっております。10月18日にお届けした商品につきまして、10箱のところ8箱しかお届けできておりませんでした。ご迷惑をおかけし、誠に申し訳ございません。
>
> 原因は、出荷時の数量の確認が一部抜けていたことでした。不足分の2箱は本日発送いたしましたので、明日にはお手元に届く予定です。
>
> 今後は、出荷前に別の担当者がもう一度数量を確認する手順を加え、同じことが起きないよういたします。
>
> 今後ともどうぞよろしくお願いいたします。

**うまくいかないときは**

- 「深くお詫び申し上げます」「心より」などが何度も出る → 「お詫びの言葉は最初と最後の2回だけ」と頼みます。
- 原因がまだわからないときは、原因の行を「調査中。わかり次第連絡する」にして渡しましょう。AIに原因を考えさせないでください。

## テンプレ13　社内でのお詫び（上司・同僚へ）

**場面**：社内でミスをしてしまい、上司や同僚に謝りたいとき。

**頼み方（コピペ用）**

```

・相手：［名前］
・ミスの内容：［何をしたか］
・影響：［だれに、どんな手間をかけたか］
・対応：［どう直したか・直すか］
社内向けの敬語で、短く、でも反省が伝わるように。4行程度。
```

**試してみた**

入れた内容：上司の藤田さん／共有フォルダの資料を古い版で上書きしてしまった／チームの3人が古い資料で作業してしまった／バックアップから戻して、全員に連絡済み

> 藤田さん
>
> 共有フォルダの資料を、私が古い版で上書きしてしまいました。申し訳ありません。\
> そのため、チームの3人が古い資料で作業する形になってしまいました。\
> 資料はバックアップから元に戻し、3人にはすでに連絡しています。\
> 今後は保存する前に、版の日付を確認するようにします。

**うまくいかないときは**

- 最後の「今後は〜」は、頼んでいないのにAIが足した部分です。実際にやることならそのままで、ちがうなら書きかえましょう。
- 謝りすぎて重い → 「もう少しさっぱりと」と頼むと、文が減ります。

## テンプレ14　お客さまへのお詫び（サービスの不具合など）

```
・お客さまへの影響：［例：予約できたかわからず不安にさせた］
・今の状態：［例：予約はできている。確認メールを再送した］
・これからのこと：［例：送信の設定を直した］
ていねいな言葉で、250字程度。私が書いていない補償やおまけの約束は書かないでください。
```

**試してみた**

入れた内容：オンラインの予約確認メールが届かなかった／予約できたかわからず不安にさせた／予約はできている、確認メールを手で再送した／送信の設定を直した

出力例：

>
> 今後ともよろしくお願いいたします。

**うまくいかないときは**

- 「補償やおまけの約束は書かないで」は大事です。これがないと、AIが「次回割引」など、決めていないことを書くことがあります。
- 原因を書きたくない場合は → 「原因の説明は入れないで」と頼みます。

> **ぷるののひとこと**\
> お詫びは、AIの文章をそのまま送るより、**最後に1行だけ自分の言葉を足す**と、ぐっと気持ちが伝わる気がします。ぷるぷる。

# 第4章　日程調整のメール

日程調整は、**日付と曜日のまちがい**がいちばん起きやすい場面です。AIに頼むときは、候補日を曜日つきで自分で書き、出てきた文章の日付を必ず見くらべましょう。

## テンプレ15　こちらから候補日を出す

**場面**：打ち合わせをしたいので、こちらから候補日をいくつか出して選んでもらうとき。

**頼み方（コピペ用）**

```
打ち合わせの日程を調整するメールを書いてください。
・相手：［名前・関係］
・打ち合わせの目的：［何について］
・所要時間と形式：［例：1時間、オンライン］
・候補日時：［曜日つきで3つほど］
候補日は箇条書きで見やすく。どれも合わなければ別の日を教えてほしい、とひとこと入れて、200字程度で。
```

**試してみた**

入れた内容：社外の森様／来年度の契約内容の確認／1時間、オンライン／11月10日（火）10時〜、11月11日（水）15時〜、11月13日（金）13時〜

出力例：

> 件名：お打ち合わせ日程のご相談（来年度のご契約について）
>
> 森様
>
> いつもお世話になっております。来年度のご契約内容の確認のため、1時間ほどオンラインでお打ち合わせのお時間をいただけないでしょうか。\
> 以下の日程でご都合はいかがでしょうか。
>
> ・11月10日（火）10:00〜11:00\
> ・11月11日（水）15:00〜16:00\
> ・11月13日（金）13:00〜14:00
>
> いずれも難しい場合は、ご都合のよい日時をお知らせいただけますと幸いです。\
> よろしくお願いいたします。

**うまくいかないときは**

- 終わりの時刻はAIが計算して足したものです。**合っているか確認**しましょう。
- オンライン会議のURLをいつ送るかも書きたい → 「日程が決まったら会議のURLを送る、と入れて」と追加します。

## テンプレ16　相手の候補日から選んで返事をする

**場面**：相手から候補日をもらったので、その中から選んで返すとき。

**頼み方（コピペ用）**

```
相手からもらった打ち合わせの候補日に返事をするメールを書いてください。
・相手：［名前］
・選んだ日時：［曜日つき］
・形式・場所：［例：先方の会社にうかがう／オンライン］
・事前に伝えておきたいこと：［例：2名で参加する］
3〜4行で、短くお願いします。
```

**試してみた**

入れた内容：社外の長谷川様／11月12日（木）14時／先方の会社にうかがう／こちらは2名で行く

出力例：

> 長谷川様
>
> 候補日のご連絡をありがとうございます。\
> 11月12日（木）14時からでお願いできますでしょうか。当日は御社にうかがいます。\
> なお、弊社からは2名で参加させていただきます。どうぞよろしくお願いいたします。

**うまくいかないときは**

- 相手の名前や参加者の名前を入れたい → 「参加者は［名前］と［名前］です、と入れて」と頼みます。
- 「でお願いできますでしょうか」が回りくどい → 「『で決めさせてください』くらいの言い方に」と言いかえてもらえます。

## テンプレ17　日程を変更してほしいとお願いする

**場面**：一度決まった打ち合わせの日を、こちらの都合で変えてもらいたいとき。

**頼み方（コピペ用）**

```

・もともとの日時：［曜日つき］
・変えたい理由（短く）：［例：別の急ぎの対応が入った］
・新しい候補日時：［曜日つきで2〜3個］
お詫びを入れつつ、相手が選びやすいように、250字程度で。
```

**試してみた**

入れた内容：社外の清水様／11月6日（金）15時／社内の急ぎの対応が入った／11月10日（火）15時、11月11日（水）10時、11月12日（木）16時

出力例：

> 件名：お打ち合わせ日程変更のお願い
>
> 清水様
>
> お世話になっております。11月6日（金）15時からのお打ち合わせにつきまして、社内で急ぎの対応が入ってしまい、日程を変更していただけないかご相談させてください。\
> こちらの都合で大変申し訳ございません。
>
> 代わりの候補として、以下はいかがでしょうか。\

> ・11月11日（水）10:00〜\
> ・11月12日（木）16:00〜
>

**うまくいかないときは**

- 理由をぼかしたい → 「理由は『やむを得ない事情により』として」と頼みます。
- 相手が目上で、とても大事な打ち合わせ → 「相手は先方の役員です。よりていねいに」と書くと、お詫びが一段重くなります。

## テンプレ18　日程が決まったことの確認メール

**場面**：やりとりの末に日程が決まったので、最後にまとめて確認するとき。

```
・議題：［話すこと］
・当日までにお願いしたいこと：［あれば］
内容は箇条書きでまとめて、前後に短いあいさつを入れてください。
```

**試してみた**

> ・議題：新しい申込書の使い方のご説明\

>

**うまくいかないときは**

- 箇条書きの「・」がメールでずれる → 「箇条書きは『■』を使って」など、記号を指定できます。
- 相手の参加者がわからない → 「先方の参加者を教えてほしい、と一行入れて」と頼めます。

## テンプレ19　大人数の日程調整のお願い（社内）

```
・会議の内容と時間：［例：振り返り会、1時間］

・返事の方法と期限：［例：このメッセージに〇か×で、〇日まで］

```

**試してみた**

**うまくいかないときは**

- 候補にA・B・Cがつくと答えやすくなります。つかなかったら「候補に記号をつけて」と頼みましょう。
- 「いちばん多くの人が〜」はAIが足した決め方です。決め方がちがえば書きかえます。

## テンプレ20　返事がない日程調整をもう一度送る

**場面**：日程の候補を送ったのに返事がなく、もう一度確認したいとき。

**頼み方（コピペ用）**

```
日程調整の返事がまだ来ていない相手に、もう一度確認するメールを書いてください。
・相手：［名前・関係］
・前に送った日：［いつ］
・候補日時：［曜日つき。期限が過ぎた日は除く］
・返事がほしい期限：［いつまで］
責める感じにならないように、相手が忙しいことを気づかう言葉を入れて、150〜200字で。
```

**試してみた**

入れた内容：社外の山口様／10月27日に送った／11月11日（水）15時、11月12日（木）10時／11月6日（金）までに

出力例：

> 山口様
>
> お世話になっております。10月27日にお送りしたお打ち合わせ日程の件で、改めてご連絡いたしました。\
> お忙しいところ恐縮ですが、以下の日程でご都合はいかがでしょうか。
>
> ・11月11日（水）15:00〜\
> ・11月12日（木）10:00〜
>
> 11月6日（金）までにお知らせいただけますと助かります。\
> 行き違いでご連絡をいただいておりましたら、ご容赦ください。

**うまくいかないときは**

- 「行き違いでしたらご容赦ください」は、催促メールでよく使われる一文です。入っていなければ「行き違いの場合の一文を入れて」と頼めます。
- 前のメールの内容を忘れてしまったら → 前のメールをそのままAIにはりつけて「これの再送用の文を書いて」と頼むのが早いです（個人情報はぼかしてから）。

## テンプレ21　オンライン会議の案内（URLの送付）

**場面**：決まったオンライン会議の、参加方法を送るとき。

**頼み方（コピペ用）**

```
オンライン会議の案内メールを書いてください。
・相手：［名前］
・日時：［曜日つき］
・会議のURL：［ここには「（URL）」と書いておき、送る前に自分で入れる］
・当日のお願い：［例：カメラはオンでもオフでも大丈夫、資料は画面で共有する］
・つながらないときの連絡先：［例：このメールに返信］
箇条書きを使って、200字程度で。
```

**試してみた**

入れた内容：社外の斉藤様／11月12日（木）14時〜15時／（URL）／カメラはどちらでもよい、資料はこちらが画面で共有するので準備はいらない／つながらないときはこのメールに返信

出力例：

> 斉藤様
>
> お世話になっております。11月12日（木）のお打ち合わせのご案内をお送りします。
>
> ・日時：11月12日（木）14:00〜15:00\
> ・参加URL：（URL）\
> ・カメラ：オン・オフどちらでも問題ございません\
> ・資料：当日こちらで画面共有いたしますので、ご準備は不要です
>
> 当日つながらない場合は、このメールにご返信ください。\
> どうぞよろしくお願いいたします。

**うまくいかないときは**

- 本物のURLやパスコードは、**AIに入れずに送る前に自分で書き入れる**のがおすすめです。
- ツールの名前を入れたい場合も、「（会議ツール名）」として自分で書きかえるようにしましょう。

> **ぷるののひとこと**\
> 日程調整のテンプレには、ずっと「曜日つきで」と書いています。曜日があると、相手も自分もまちがいに気づきやすいからです。カレンダーと見くらべるのは、人間の大事な仕事です。

# 第5章　催促・リマインドのメール

催促は「言いにくい」メールの代表です。AIに頼むときは、**責めない言い方**と、**いつまでに何がほしいか**の2つをはっきり伝えましょう。

## テンプレ22　返事がほしいときのやわらかい催促

**場面**：質問やお願いのメールを送ったのに、返事がないとき。

**頼み方（コピペ用）**

```
返事が来ていないメールの、やわらかい催促メールを書いてください。
・相手：［名前・関係］
・前に送った日と内容：［いつ・何を聞いたか］
・返事がほしい期限と理由：［例：来週の会議で使うので〇日まで］
相手を責めない言い方で、行き違いの場合の一文も入れて、150〜200字で。
```

**試してみた**

入れた内容：社外の西村様／10月26日に、新しいパンフレットの部数を質問した／11月4日（水）の社内会議で決めたいので、11月2日までに

出力例：

> 西村様
>
> お世話になっております。10月26日にお送りした、新しいパンフレットの部数についてのご質問の件で、ご連絡いたしました。\
> 11月4日（水）の社内会議で決めたいと考えておりますため、11月2日までにご回答いただけますと大変助かります。\
> お忙しいところ恐れ入りますが、よろしくお願いいたします。\
> なお、行き違いでご返信いただいておりましたら、失礼をお許しください。

**うまくいかないときは**

- 期限の理由があると、相手も動きやすくなります。理由がないときは「理由は書かずに」と頼みます。
- 前の質問をもう一度書いてあげると親切です → 「前の質問の内容も短くもう一度書いて」と追加します。

## テンプレ23　書類の提出をお願いする催促

**場面**：提出してもらうはずの書類（申込書、報告書など）がまだ届いていないとき。

**頼み方（コピペ用）**

```
書類の提出をお願いする催促メールを書いてください。
・相手：［名前・社内か社外か］
・書類：［書類の名前］
・もともとの締め切り：［いつ］
・新しくお願いする期限：［いつ］
・出し方：［例：このメールに添付、共有フォルダに保存］
事実だけを淡々と、でも冷たくならないように、200字程度で。
```

**試してみた**

入れた内容：社内の他部署の前田さん／研修の参加申込書／10月30日／11月4日（水）／共有フォルダの「研修」フォルダに保存

出力例：

> 前田さん
>
> お疲れさまです。研修の参加申込書について、10月30日が提出期限となっておりましたが、まだ確認できておりませんでしたのでご連絡しました。\
> お手数ですが、11月4日（水）までに、共有フォルダの「研修」フォルダへ保存していただけますでしょうか。\
> すでにご提出済みでしたら、行き違いですのでご容赦ください。\
> よろしくお願いします。

**うまくいかないときは**

- 社内でも、相手が目上なら → 「相手は他部署の部長です」と書くと、敬語が強くなります。
- 何度目かの催促なら → テンプレ24を使ってください。

## テンプレ24　2回目以降の催促（少しはっきりと）

**場面**：一度催促したのに、まだ返事や提出がないとき。少しはっきり伝えたい。

**頼み方（コピペ用）**

```
2回目の催促メールを書いてください。
・相手：［名前・関係］
・これまでの経緯：［最初にいつ何を送ったか、1回目の催促をいつ送ったか］
・ほしいもの：［何を］
・最終の期限と、それを過ぎたらどうなるか：［例：〇日を過ぎると発注に間に合わない］
失礼にはならないように、でも期限ははっきりと。200〜250字で。
```

**試してみた**

入れた内容：社外の原田様／10月20日に見積もりの確認をお願いし、10月27日に催促した／見積もり内容への承認／11月5日（木）を過ぎると、希望の納期に間に合わなくなる

出力例：

> 件名：【ご確認のお願い】お見積もりのご承認について
>
> 原田様
>
> お世話になっております。10月20日にお送りし、27日にも改めてご連絡いたしましたお見積もりの件で、再度ご連絡いたしました。\
> 恐れ入りますが、11月5日（木）までにご承認のご連絡をいただけますでしょうか。この日を過ぎますと、ご希望の納期に間に合わなくなってしまいます。\
> お忙しいところ大変恐縮ですが、ご確認のほどよろしくお願いいたします。

**うまくいかないときは**

- 強すぎる → 「もう少しやわらかく」と言うと、「〜となってしまう可能性がございます」のように変わります。
- 弱すぎる → メールでは太字が使えないことが多いので、「期限の部分を【】でかこんで」など、目立たせ方を指定できます。

## テンプレ25　前日のリマインド（打ち合わせ・イベント）

**場面**：明日の打ち合わせやイベントを、念のため相手にお知らせするとき。

**頼み方（コピペ用）**

```
明日の［打ち合わせ／イベント］のリマインドメールを書いてください。
・相手：［名前］
・日時と場所：［曜日つき］
・持ち物や準備：［あれば］
・当日の連絡先：［例：このメールへの返信］
押しつけがましくならないように、3〜4行で。
```

**試してみた**

入れた内容：社外の青木様／11月12日（木）14時、弊社3階の会議室／特になし、受付で名前を言えば案内する／このメールに返信

出力例：

> 青木様
>
> お世話になっております。明日11月12日（木）14時からのお打ち合わせについて、念のためご連絡いたします。\
> 場所は弊社3階の会議室です。受付でお名前をお伝えいただければご案内いたします。\
> 何かございましたら、このメールにご返信ください。明日はどうぞよろしくお願いいたします。

**うまくいかないときは**

- 「念のため」が失礼に聞こえないか心配 → 「『念のため』以外の言い方の候補を3つ出して」と聞けます。
- 住所や地図を入れたい → 住所は自分で書き入れましょう（AIが住所を作ることがあります）。

## テンプレ26　締め切り前のリマインド（社内）

**場面**：社内のメンバーに、近づいている締め切りを知らせるとき。

**頼み方（コピペ用）**

```
社内メンバーへの、締め切り前のリマインドメッセージを書いてください。
・あて先：［例：営業部のみなさん］
・何の締め切りか：［例：経費の申請］
・締め切り日時：［曜日つき］
・出し方：［例：申請システムから］
・過ぎたらどうなるか：［例：来月の処理になる］
社内向けで、明るく短く。
```

**試してみた**

入れた内容：営業部のみなさん／10月分の経費の申請／10月30日（金）17時／申請システムから／過ぎると11月分としての処理になる

出力例：

> 営業部のみなさん
>
> お疲れさまです。10月分の経費申請の締め切りが近づいてきましたので、お知らせします。
>
> ・締め切り：10月30日（金）17:00\
> ・方法：申請システムから
>
> 締め切りを過ぎた分は、11月分としての処理になります。お早めの申請をお願いします！

**うまくいかないときは**

- 「！」が社風に合わない → 「感嘆符は使わないで」と頼みます。
- 毎月使いたい → このテンプレの日付だけを変えて、毎月同じ会話で使い回すと楽です。

## テンプレ27　支払い・入金の確認をていねいに聞く

**場面**：請求書を送った相手に、支払いの予定をていねいに確認したいとき（金額の交渉や、法的な督促ではない、ふつうの確認）。

**頼み方（コピペ用）**

```
取引先に、請求書のお支払い予定をていねいに確認するメールを書いてください。
・相手：［会社名・担当者名］
・請求書：［何月分か、送った日］
・お支払い期日：［いつだったか］
・お願い：［例：お支払いの予定日を教えてほしい］
こちらの確認もれの可能性も考えて、責めない言い方で200字程度。金額は「〇〇円」と書いておいてください。
```

**試してみた**

入れた内容：株式会社あおぞら 経理部 ご担当者様／9月分、10月1日に送った／10月31日／お支払いの予定日を教えてほしい

出力例：

> 株式会社あおぞら　経理部　ご担当者様
>
> いつもお世話になっております。10月1日にお送りいたしました9月分の請求書（〇〇円）につきまして、10月31日のお支払い期日を過ぎておりましたため、念のためご連絡いたしました。\
> こちらの確認もれの可能性もございますが、お支払いのご予定日をお知らせいただけますでしょうか。\
> すでにお手続きいただいている場合は、行き違いとしてご容赦ください。\
> 何卒よろしくお願いいたします。

**うまくいかないときは**

- 金額や口座番号は、AIに入れずに「〇〇円」のままにして、送る前に自分で入れるのがおすすめです。
- 何度確認しても支払いがないなど、こじれている場合は、AIの文章ではなく社内の担当部署や専門家に相談しましょう。この本では、お金や法律の判断は扱いません。

> **ぷるののひとこと**\
> 催促メールのコツは「行き違いだったらごめんなさい」を入れること、らしいです。この章の出力例でも、催促のメールの多くにこの一文が入っています。

# 第6章　断りのメール

断りのメールは、「断る」「理由」「代わりの案かお礼」の3つがそろうと角が立ちにくい、と言われます。AIに頼むときも、この3つを渡すと安定します。

## テンプレ28　依頼を断る（社外）

**場面**：取引先からの仕事の依頼を、今回は受けられないとき。

**頼み方（コピペ用）**

```
取引先からの依頼を断るメールを書いてください。
・相手：［名前・関係］
・依頼の内容：［何を頼まれたか］
・断る理由（言える範囲で）：［例：その時期は手がいっぱい］
・代わりにできること：［例：来月以降なら相談できる／なし］
・これからも関係を続けたい気持ち
角が立たないように、でもあいまいにせず「今回はお受けできない」ことははっきりと。250字程度で。
```

**試してみた**

入れた内容：社外の福田様／12月のイベント用のチラシ制作／12月は別の案件で手がいっぱい／1月以降の案件なら相談にのれる

出力例：

> 福田様
>
> いつもお世話になっております。12月のイベント用チラシ制作のご依頼をいただき、ありがとうございます。\
> せっかくお声がけいただいたのですが、12月はすでに別の案件で手がいっぱいの状況のため、今回はお受けすることが難しく、誠に申し訳ございません。\
> 1月以降のご依頼でしたら、ぜひご相談させていただければと思います。\
> 今後ともどうぞよろしくお願いいたします。

**うまくいかないときは**

- 断っているのか、受けるのかがあいまいになる → 「1文目か2文目で、受けられないことをはっきり書いて」と頼みます。
- 代わりの案がないときは、その行を「なし」にすると、お礼と今後のお願いで締めてくれます。

## テンプレ29　営業・売り込みをていねいに断る

**場面**：知らない会社からの営業や、サービスの売り込みに、ていねいに断りを入れたいとき。

**頼み方（コピペ用）**

```
営業のメールに、ていねいに断る返信を書いてください。
・相手：［会社名・担当者名］
・提案された内容：［何の売り込みか］
・断る理由：［例：今は同じようなものを使っている／今は検討していない］
・今後の連絡について：［例：今後のご案内は不要］
短く3〜4行で、冷たくなりすぎないように。
```

**試してみた**

入れた内容：株式会社ひかりソリューション 担当者様／社内の勤怠管理ツール／すでに別のツールを使っていて、変える予定はない／今後のご案内は不要

出力例：

> 株式会社ひかりソリューション　ご担当者様
>
> ご丁寧なご案内をいただき、ありがとうございます。\
> 勤怠管理ツールについてですが、弊社ではすでに別のツールを導入しており、現時点で変更の予定はございません。\
> 誠に恐縮ですが、今後のご案内は控えていただけますと幸いです。

**うまくいかないときは**

- 「現時点では」と入ると、またいつか連絡が来るかもしれません。はっきり断りたいなら「『現時点では』を使わないで」と頼みます。
- 少しでも興味がある場合は → 「資料だけはもらいたい」と書くと、そういう文になります。

## テンプレ30　お誘いを断る（会食・イベント）

**場面**：会食や懇親会、イベントに誘われたけれど、参加できないとき。

**頼み方（コピペ用）**

```
会食やイベントのお誘いを断るメールを書いてください。
・相手：［名前・関係］
・誘われたもの：［会の名前・日にち］
・断る理由（ぼかしてもよい）：［例：先約がある］
・次につなげたいか：［例：また誘ってほしい］
お誘いへのお礼を最初に入れて、150〜200字で。
```

**試してみた**

入れた内容：取引先の上野様／11月20日の忘年会をかねた交流会／先約がある／また機会があればぜひ参加したい

出力例：

> 上野様
>
> いつもお世話になっております。11月20日の交流会にお誘いいただき、ありがとうございます。\
> ぜひ参加したかったのですが、あいにくその日は先約があり、今回は欠席させていただきます。\
> せっかくお声がけいただいたのに申し訳ございません。またの機会がございましたら、ぜひよろしくお願いいたします。

**うまくいかないときは**

- 「先約」と書きたくない → 「理由は『都合がつかず』として」と頼みます。
- 社内の飲み会なら → 「社内の同僚あてに、チャット用の短い文で」と変えると、ぐっと軽くなります。

## テンプレ31　値引き・条件の変更を断る

**場面**：取引先から「もう少し安くならないか」「納期を早めてほしい」などと頼まれたが、応えられないとき。

**頼み方（コピペ用）**

```
取引先からの条件の変更のお願いを、断るメールを書いてください。
・相手：［名前・関係］
・頼まれたこと：［例：納期を1週間早めてほしい］
・応えられない理由：［例：材料の入荷が決まっている］
・代わりにできること：［例：一部だけ先に納品する］
感じよく、でも「できない」ことは変えずに、250字程度で。私が書いていない値段や条件は書かないでください。
```

**試してみた**

入れた内容：社外の三浦様／納品を11月20日から11月13日に早めてほしい／材料の入荷日が決まっていて、早められない／半分の50個だけなら11月16日に先に納品できる

出力例：

> 三浦様
>
> いつもお世話になっております。納品日を11月13日に早めたいとのご相談、ありがとうございます。\
> 社内で検討いたしましたが、材料の入荷日がすでに決まっており、全数を11月13日にお届けすることは難しい状況です。ご期待に沿えず、申し訳ございません。\
> 代わりに、半数の50個につきましては、11月16日に先行してお届けすることが可能です。\
> こちらの方法でよろしければ、ご検討いただけますと幸いです。

**うまくいかないときは**

- 「私が書いていない値段や条件は書かないで」を消すと、AIが気をきかせて別の案を作ることがあります。社内で決めていない条件は、絶対にメールに残さないようにしましょう。
- 断りがやわらかすぎて、まだ交渉できそうに読める → 「全数を早めることはできない、とはっきり」と頼みます。

## テンプレ32　社内の頼まれごとを断る

**場面**：同僚や他部署から仕事を頼まれたけれど、今は手が回らないとき。

**頼み方（コピペ用）**

```
社内の人からの頼まれごとを断るメッセージを書いてください。
・相手：［名前・関係］
・頼まれたこと：［何を］
・断る理由：［例：今週は〇〇の締め切りがある］
・代わりの案：［例：来週なら手伝える／〇〇さんが詳しい］
社内チャット用に、短くやわらかく。
```

**試してみた**

入れた内容：隣の部署の近藤さん（同期）／新人研修の資料づくりを手伝ってほしい／今週は決算の資料の締め切りがある／来週の水曜以降なら少し手伝える

出力例：

> 近藤さん、声をかけてくれてありがとう！\
> ただ、今週は決算資料の締め切りがあって、手伝うのが難しそうです。ごめんなさい。\
> 来週の水曜以降なら少し時間が取れそうなので、そのときでよければ手伝わせてください。

**うまくいかないときは**

- 同期なのに敬語がかたい → 「同期なので、です・ます調でいいけど、くだけた感じで」と頼むと、こういう文になります。
- 上司からの頼みを断るのは難しいので、断る前に「今の仕事の優先順位を相談したい」という文にしてもらうのも手です。

## テンプレ33　応募・提案を見送る連絡

**場面**：応募や提案をもらったが、今回は採用しない（見送る）と伝えるとき。

**頼み方（コピペ用）**

```
いただいた［提案／応募］を、今回は見送る連絡メールを書いてください。
・相手：［名前・会社名など］
・内容：［何の提案・応募か］
・見送る理由（伝えられる範囲で）：［例：今回は予算に合わなかった／書けない］
・感謝したいこと：［例：時間をかけて準備してくれた］
ていねいに、相手の努力を否定しない書き方で、250字程度。
```

**試してみた**

入れた内容：デザイン会社の中島様／会社のロゴの見直しの提案／今回は社内で見直し自体を先送りすることになった／何案も準備してくれた

出力例：

> 中島様
>
> いつもお世話になっております。先日は、ロゴの見直しについてご提案をいただき、誠にありがとうございました。何案もご準備いただき、社内でもじっくり検討させていただきました。\
> 検討の結果、社内でロゴの見直しそのものを先送りすることとなり、今回はご提案を見送らせていただくことになりました。\
> せっかくご尽力いただいたにもかかわらず、申し訳ございません。また改めてご相談させていただく際には、どうぞよろしくお願いいたします。

**うまくいかないときは**

- 採用・人事の結果の連絡（不採用通知など）は、会社ごとに決まった文面があることが多いです。そちらがある場合は優先してください。
- 「また改めてご相談」と書くと期待させることがあります。予定がなければ「最後の一文を、お礼だけにして」と頼みます。

## テンプレ34　一度受けたことを取り消す

**場面**：一度「やります」「参加します」と言ったことを、事情で取り消さなければならないとき。

**頼み方（コピペ用）**

```
一度引き受けたことを取り消すお詫びのメールを書いてください。
・相手：［名前・関係］
・引き受けていたこと：［何を］
・取り消す理由：［言える範囲で］
・相手の負担を減らすためにできること：［例：代わりの人を紹介する、資料は渡す］
お詫びをしっかり入れて、250字程度で。
```

**試してみた**

入れた内容：社外の勉強会の幹事の菅原様／11月27日の勉強会での10分の発表／社内の出張と重なってしまった／発表用に作りかけていた資料は渡せる、同じチームの林が代わりに話せるか確認中

出力例：

> 菅原様
>
> お世話になっております。11月27日の勉強会でお引き受けしておりました10分間の発表について、ご相談とお詫びがあり、ご連絡いたしました。\
> 社内の出張と日程が重なってしまい、当日参加することができなくなりました。一度お引き受けしておきながら、誠に申し訳ございません。\
> 作成途中の発表資料はお渡しできます。また、同じチームの林が代わりに発表できるか、現在確認しております。結果がわかり次第、すぐにご連絡いたします。\
> ご迷惑をおかけし、本当に申し訳ございません。

**うまくいかないときは**

- 取り消しは、メールより先に電話や直接伝えるほうがいい場合もあります。メールは「あとから文字で残す」ためと考えると使いやすいです。
- 「確認しております」のように、まだ決まっていないことは「まだ決まっていない」とわかる書き方になっているか、読んで確かめましょう。

> **ぷるののひとこと**\
> 断りのメールは、AIに「角が立たないように」と言うと、だんだん断っているのかわからない文になることがあります。ぼくは「断ることははっきり」もセットで言うようにしています。

# 第7章　依頼・お願いのメール

お願いのメールでは、**相手が何をすればいいか**がひと目でわかることが大切です。AIには「お願いしたいこと」「期限」「やり方」を分けて渡しましょう。

## テンプレ35　仕事を依頼する（社外）

**場面**：取引先や外部の人に、新しく仕事をお願いするとき。

**頼み方（コピペ用）**

```
社外の人に仕事を依頼するメールを書いてください。
・相手：［名前・関係］
・お願いしたい仕事：［何を］
・期限：［いつまでに］
・こちらが用意できるもの：［例：参考資料、写真］
・決まっていないこと：［例：費用は見積もりをいただいてから相談したい］
依頼内容は箇条書きでまとめて、前後にあいさつを入れて、300字程度で。
```

**試してみた**

入れた内容：以前も頼んだことのあるイラストレーターの野口様／会社案内のパンフレットに入れる挿絵4点／12月11日まで／パンフレットの文章と、ラフのイメージ図／費用は見積もりをもらってから相談したい

出力例：

> 件名：挿絵制作のご依頼（会社案内パンフレット）
>
> 野口様
>
> ご無沙汰しております。以前はすてきなイラストをありがとうございました。\
> このたび、会社案内パンフレットの挿絵を、ぜひ野口様にお願いしたくご連絡いたしました。
>
> ・内容：会社案内パンフレット用の挿絵 4点\
> ・期限：12月11日\
> ・ご用意できるもの：パンフレットの文章、ラフのイメージ図\
> ・費用：お見積もりをいただいたうえで、ご相談させてください
>
> ご検討いただけますと幸いです。ご不明な点がございましたら、お気軽にお知らせください。

**うまくいかないときは**

- 費用や支払いの条件は、**AIに作らせずに自分で書く**のが安全です。
- 初めての相手なら → 「初めて連絡する相手です。自己紹介と、どこで知ったかも入れて」と追加します（テンプレ48も参考に）。

## テンプレ36　資料・データの送付をお願いする

**場面**：相手に資料やデータを送ってもらいたいとき。

**頼み方（コピペ用）**

```
資料を送ってもらうようお願いするメールを書いてください。
・相手：［名前・関係］
・ほしい資料：［名前・形式。例：昨年度の実績の表（表計算のファイル）］
・使い道：［例：来年度の計画づくり］
・期限：［いつまでに］
相手が迷わないように具体的に、200字程度で。
```

**試してみた**

入れた内容：社内の他部署の安藤さん／昨年度の店舗ごとの来店数の表（表計算のファイル）／来年度のチラシ配布の計画づくり／11月6日（金）まで

出力例：

> 安藤さん
>
> お疲れさまです。来年度のチラシ配布の計画をつくるため、昨年度の店舗ごとの来店数の表（表計算のファイル）をお送りいただけないでしょうか。\
> お忙しいところ恐縮ですが、11月6日（金）までにいただけると助かります。\
> ファイルの形がちがっていても大丈夫ですので、今あるものをそのまま送っていただければ十分です。\
> よろしくお願いします。

**うまくいかないときは**

- 3行目はAIが足した一文です。形を指定したいなら消して「形式は〇〇で」と書きかえましょう。
- 個人情報が入っている資料をお願いするときは、送り方（パスワードつき、共有フォルダなど）を社内のルールに合わせて自分で書き足してください。

## テンプレ37　確認・チェックをお願いする

**場面**：作った資料や文章を、上司や相手にチェックしてもらいたいとき。

**頼み方（コピペ用）**

```
作った資料のチェックをお願いするメールを書いてください。
・相手：［名前・関係］
・チェックしてほしいもの：［資料の名前］
・特に見てほしいところ：［例：3ページ目の数字、表現がかたくないか］
・期限：［いつまでに］
・見てもらったあとの流れ：［例：直して、〇日にお客さまへ送る］
相手の手間が少なく見えるように、200字程度で。
```

**試してみた**

入れた内容：上司の小野さん／お客さま向けの新サービスの案内文／料金表の書き方と、敬語がかたすぎないか／11月5日（木）の午前中まで／直して11月6日にお客さまへ送る

出力例：

> 小野さん
>
> お疲れさまです。お客さま向けの新サービスの案内文ができましたので、確認をお願いできますでしょうか。\
> 特に、料金表の書き方と、敬語がかたすぎないかを見ていただけると助かります。\
> 11月5日（木）の午前中までにご意見をいただければ、修正のうえ、11月6日にお客さまへお送りする予定です。\
> お忙しいところすみませんが、よろしくお願いします。

**うまくいかないときは**

- 「全部見てください」だと相手の負担が大きく見えます。見てほしいところを2つくらいにしぼって渡すのがコツです。
- 添付したことを書き忘れがち → 「資料を添付していることも書いて」と追加しましょう。

## テンプレ38　アンケート・協力のお願い

**場面**：社内外の人に、アンケートの回答や、ちょっとした協力をお願いするとき。

**頼み方（コピペ用）**

```
アンケートへの協力をお願いするメールを書いてください。
・あて先：［例：社内の全員／お客さま］
・目的：［何のためのアンケートか］
・かかる時間：［例：3分ほど］
・回答の期限：［いつまで］
・回答の方法：［例：下のURLから。URLは「（URL）」と書く］
・結果の使い方：［例：来年の研修の内容を決める］
押しつけにならないように、200字程度で。
```

**試してみた**

入れた内容：社内の全員／社内研修の満足度を知るため／3分ほど／11月13日（金）まで／（URL）から／来年度の研修の内容を決めるのに使う、名前は集計に出さない

出力例：

> 社員のみなさま
>
> お疲れさまです。今年度の社内研修について、満足度アンケートへのご協力をお願いいたします。\
> 回答は3分ほどで終わります。いただいた回答は、来年度の研修の内容を決めるために使わせていただきます。なお、集計の際にお名前が出ることはありません。
>
> ・回答期限：11月13日（金）\
> ・回答方法：（URL）
>
> お忙しいところ恐れ入りますが、ご協力をよろしくお願いいたします。

**うまくいかないときは**

- 「名前は出さない」などの約束は、**本当にそうなっているときだけ**書きましょう。
- お客さま向けなら → あて先を「お客さま」に変え、「ていねいに」と追加すれば使えます。

## テンプレ39　急ぎのお願い

**場面**：急に対応してもらう必要が出てきたとき。急いでいることを伝えつつ、失礼にならないようにしたい。

**頼み方（コピペ用）**

```
急ぎのお願いをするメールを書いてください。
・相手：［名前・関係］
・お願いしたいこと：［何を］
・期限：［例：今日の17時まで］
・急ぎになった理由：［短く］
件名に【至急】などを入れて、用件を最初の2行で書いてください。全体で150字程度。
```

**試してみた**

入れた内容：社外の工藤様／明日の納品書の宛名をA社からB社に変えてほしい／今日の16時まで／先方から請求先の変更の連絡が今朝あった

出力例：

> 件名：【至急】明日の納品書の宛名変更のお願い
>
> 工藤様
>
> お世話になっております。急なお願いで恐縮ですが、明日の納品書の宛名を「A社」から「B社」へ変更していただけますでしょうか。本日16時までにご対応いただけますと助かります。\
> 今朝、先方から請求先変更の連絡があったためです。お手数をおかけし申し訳ございません。

**うまくいかないときは**

- 本当に急ぐときは、メールのあとに電話もしましょう。AIに「電話でもご連絡します、と入れて」と頼めます。
- 【至急】が強すぎる相手なら → 「【お急ぎのお願い】にして」と変えられます。

## テンプレ40　お願いの内容を変える・追加する

**場面**：一度お願いしたことの内容を変えたり、あとから追加したりするとき。

**頼み方（コピペ用）**

```
前にお願いした内容を変更（または追加）するメールを書いてください。
・相手：［名前・関係］
・前にお願いした内容：［何を、いつ頼んだか］
・変える・追加する内容：［変更前→変更後］
・期限への影響：［例：期限はそのまま／〇日に延ばしてよい］
変更点がひと目でわかるように書いて、お詫びも入れて、200字程度で。
```

**試してみた**

入れた内容：社外の野口様／10月28日にお願いした挿絵4点／4点→5点に追加（表紙用に1点）／期限は12月11日から12月18日に延ばしてよい

出力例：

> 野口様
>
> お世話になっております。10月28日にご依頼した挿絵について、内容の追加をお願いしたくご連絡いたしました。
>
> ・点数：4点 → 5点（表紙用に1点追加）\
> ・期限：12月11日 → 12月18日
>
> 後からのご相談となり、申し訳ございません。追加分のお見積もりについても、あわせてご相談させてください。\
> どうぞよろしくお願いいたします。

**うまくいかないときは**

- 「追加分のお見積もり」はAIが気をきかせた一文です。費用の話をどうするかは自分で決めてから送りましょう。
- 変更が多いときは、変更前と変更後を全部書き出してから渡すと、まちがいが減ります。

## テンプレ41　お願いを受けてもらったあとのお礼と確認

**場面**：お願いを引き受けてもらえたので、お礼を言いつつ、内容を確認したいとき。

**頼み方（コピペ用）**

```
お願いを引き受けてもらったことへのお礼と、内容の確認のメールを書いてください。
・相手：［名前・関係］
・引き受けてもらったこと：［何を］
・確認したい内容：［期限・量・やり方など］
・こちらが次にすること：［例：資料を〇日までに送る］
お礼を最初に、確認は箇条書きで、200字程度。
```

**試してみた**

入れた内容：社内勉強会の講師を引き受けてくれた社外の太田様／12月4日の社内勉強会で、新人向けに「伝わるメモの取り方」を40分話してもらう／参加者は20名、会場は本社5階／参加者名簿と会場の地図を11月27日までに送る

出力例：

> 太田様
>
> このたびは、社内勉強会の講師をお引き受けいただき、誠にありがとうございます。新人一同、とても楽しみにしております。\
> 念のため、内容を確認させてください。
>
> ・日時：12月4日\
> ・テーマ：「伝わるメモの取り方」（40分）\
> ・対象：新人 約20名\
> ・会場：本社5階
>
> 参加者名簿と会場の地図は、11月27日までにお送りいたします。\
> 何かございましたら、お気軽にお知らせください。

**うまくいかないときは**

- 「新人一同、とても楽しみに」は、実際にそう言える場合だけ残しましょう。AIは場をあたためる言葉をよく足します。
- 時間（何時から）を入れていないと、AIも書きません。日時は時刻まで入れて渡すのがおすすめです。

> **ぷるののひとこと**\
> お願いのメールは、AIに「箇条書きで」と言うと、一気に読みやすくなります。相手が返事を書くときも、箇条書きの順に答えればいいので楽そうです。

# 第8章　社内の報告・連絡・相談

社内のメールやチャットは、ていねいさよりも**わかりやすさと速さ**が大事です。AIには「結論を先に」と頼むのがコツです。

## テンプレ42　上司への進み具合の報告

**場面**：担当している仕事の進み具合を、上司に報告するとき。

**頼み方（コピペ用）**

```
上司への進み具合の報告を書いてください。
・相手：［名前］
・仕事の名前：［何の仕事か］
・終わったこと：［箇条書き］
・まだのこと：［箇条書き］
・困っていること・相談したいこと：［あれば］
・今後の予定：［いつ何をするか］
結論（予定どおりか、遅れているか）を最初の1文に。箇条書きで、全体で250字程度。
```

**試してみた**

入れた内容：課長の吉田さん／新しい店舗の開店準備／終わった：棚の発注、アルバイトの面接5人／まだ：チラシの印刷／チラシの文案を見てほしい／チラシは11月10日に印刷へ出す

出力例：

> 吉田課長
>
> お疲れさまです。新店舗の開店準備は、ほぼ予定どおり進んでいます。
>
> 【終わったこと】\
> ・棚の発注\
> ・アルバイトの面接（5名）
>
> 【まだのこと】\
> ・チラシの印刷（11月10日に印刷へ出す予定）
>
> 【ご相談】\
> チラシの文案を一度見ていただけないでしょうか。今週中にお送りします。
>
> 引き続きよろしくお願いします。

**うまくいかないときは**

- 「ほぼ予定どおり」かどうかは、AIではなく自分が決めることです。遅れているなら、その旨をはっきり書いて渡しましょう。
- 「今週中にお送りします」は、AIが足した約束です。自分で決めた日に書きかえてください。

## テンプレ43　トラブルの第一報

**場面**：何かトラブルが起きたことを、まず上司やチームに知らせるとき。くわしいことはまだわからない。

**頼み方（コピペ用）**

```
社内へのトラブルの第一報を書いてください。
・あて先：［例：上司とチーム］
・起きたこと：［何が・いつ・どこで］
・わかっていること：［箇条書き］
・まだわかっていないこと：［箇条書き］
・今やっていること：［対応］
・次の報告の予定：［例：〇時ごろ］
推測は書かず、わかっていることだけを短く。件名に【第一報】と入れてください。
```

**試してみた**

入れた内容：課長とチーム／今日の9時ごろから、会社のお問い合わせフォームから送信できない／お客さまから電話で2件連絡あり／原因と、いつから止まっていたか正確にはまだわからない／システム担当の竹内さんに調べてもらっている／11時ごろに次の報告

出力例：

> 件名：【第一報】お問い合わせフォームの送信不具合について
>
> 課長、チームのみなさん
>
> お疲れさまです。本日9時ごろから、会社のお問い合わせフォームから送信ができない状態になっています。
>
> 【わかっていること】\
> ・お客さまから電話で2件、送信できないと連絡がありました
>
> 【まだわかっていないこと】\
> ・原因\
> ・正確にいつから止まっていたか
>
> 【対応】\
> ・システム担当の竹内さんに調べてもらっています
>
> 次の報告は11時ごろにいたします。

**うまくいかないときは**

- 「推測は書かないで」は大事な一言です。これがないと、AIが「サーバーの不具合と思われます」などと、もっともらしい原因を書くことがあります。
- お客さま向けのお知らせは、社内で中身を決めてから、テンプレ14などを使って別に作りましょう。

## テンプレ44　休みの連絡・不在の連絡

**場面**：休みをとるときや、出張などで不在になるときに、社内に知らせる。

**頼み方（コピペ用）**

```
社内向けの［休み／不在］の連絡を書いてください。
・あて先：［例：チームのみなさん］
・期間：［いつからいつまで］
・その間の連絡先・代わりの担当：［名前］
・お願いしたいこと：［例：急ぎの件は〇〇さんへ］
・休み前に終わらせておくこと：［あれば］
社内向けで、短く。
```

**試してみた**

入れた内容：チームのみなさん／11月9日（月）〜11月11日（水）の3日間／代わりは菊地さん／急ぎの件は菊地さんへ／お客さまA社の見積もりは休み前に送っておく

出力例：

> チームのみなさん
>
> お疲れさまです。11月9日（月）から11日（水）までの3日間、お休みをいただきます。\
> その間、急ぎの件は菊地さんにお願いしています。\
> A社のお見積もりは、お休みに入る前に送っておきます。\
> ご迷惑をおかけしますが、よろしくお願いします。

**うまくいかないときは**

- 休みの理由は、書かなくてもいいことが多いです。AIが理由を聞いてきても、「理由は書かない」と答えてOKです。
- 社外の人に送る不在のお知らせなら → 「社外の取引先向けに、不在の間の連絡先を伝える文にして」と頼みます。

## テンプレ45　引き継ぎのメール

**場面**：異動や休みの前に、担当している仕事をほかの人に引き継ぐとき。

**頼み方（コピペ用）**

```
仕事の引き継ぎメールを書いてください。
・相手：［引き継ぐ人の名前］
・引き継ぐ仕事：［仕事の名前］
・今の状態：［どこまで終わっているか］
・これからやること：［いつまでに何を］
・注意すること：［例：先方は朝のうちに連絡するとつかまりやすい］
・資料の場所：［例：共有フォルダの〇〇］
見出しをつけて、読み返しやすい形にしてください。
```

**試してみた**

入れた内容：後任の桜井さん／B社の年賀状の印刷の手配／デザインは決定済み、部数の確認待ち／11月20日までに部数を確認して印刷会社に発注する／B社の担当の方は午前中のほうがつかまりやすい／共有フォルダ「B社」の中の「年賀状」

出力例：

> 桜井さん
>
> お疲れさまです。B社の年賀状の印刷手配について、引き継ぎをお願いします。
>
> ■ 今の状態\
> ・デザイン：決定済み\
> ・部数：B社さんに確認中（返事待ち）
>
> ■ これからやること\
> ・11月20日までに部数を確認し、印刷会社に発注する
>
> ■ 注意すること\
> ・B社のご担当の方は、午前中のほうがつかまりやすいです
>
> ■ 資料の場所\
> ・共有フォルダ「B社」＞「年賀状」
>
> わからないことがあれば、いつでも聞いてください。

**うまくいかないときは**

- 引き継ぎは「書いていないことは伝わらない」と考えましょう。AIに渡す前に、思いつくことを全部箇条書きにしておくのがコツです。
- 長くなる場合は → 「引き継ぎの一覧表の形にして」と頼むこともできます。

## テンプレ46　上司に相談する

**場面**：自分だけでは決められないことを、上司に相談したいとき。

**頼み方（コピペ用）**

```
上司に相談するメッセージを書いてください。
・相手：［名前］
・相談したいこと：［何を決めたいか］
・考えている案：［案A・案B など］
・自分のおすすめと理由：［あれば］
・いつまでに決めたいか：［期限］
最初の1文で「何の相談か」がわかるように、200字程度で。
```

**試してみた**

入れた内容：課長の坂本さん／来月の展示会に、何人で行くか／案A：2人で2日間、案B：3人で1日目だけ／案Aがおすすめ、2日目に来るお客さまとも話せるから／11月6日まで

出力例：

> 坂本課長
>
> お疲れさまです。来月の展示会に何人で参加するかについて、ご相談させてください。
>
> ・案A：2人で2日間とも参加\
> ・案B：3人で1日目だけ参加
>
> 私は、2日目に来場されるお客さまともお話しできるので、案Aがよいと考えています。\
> 申し込みの都合で、11月6日までに決めたいと思っています。ご意見をいただけますでしょうか。

**うまくいかないときは**

- 案が1つしかないときも、「案はこれしか思いつかないが、ほかにあれば聞きたい」と書いて渡すと、相談らしい文になります。
- AIに「どちらがいいと思う？」と聞くこともできますが、決めるのは上司と自分です。

## テンプレ47　会議のあとの共有メール

**場面**：社内の会議が終わったあと、決まったことを参加者に共有するとき。

**頼み方（コピペ用）**

```
会議のあとに、決まったことを共有するメールを書いてください。
・あて先：［参加者］
・会議：［日時・名前］
・決まったこと：［箇条書き］
・だれが何をいつまでに：［担当・内容・期限］
・次の会議：［あれば］
メモを整理して、見出しつきで短くまとめてください。私のメモにないことは足さないでください。
```

**試してみた**

入れた内容：定例会の参加者／11月4日の営業定例会／決まったこと：年末のキャンペーンは12月1日から、チラシは2種類作る／担当：チラシの文案＝原さん（11月12日まで）、配る店舗のリスト＝小島さん（11月10日まで）／次回は11月18日

出力例：

> 定例会参加者のみなさん
>
> お疲れさまです。11月4日の営業定例会で決まったことを共有します。
>
> ■ 決まったこと\
> ・年末キャンペーンは12月1日から開始\
> ・チラシは2種類作成する
>
> ■ 担当と期限\
> ・チラシの文案：原さん（11月12日まで）\
> ・配布店舗のリスト：小島さん（11月10日まで）
>
> ■ 次回\
> ・11月18日
>
> 抜けやまちがいがあれば、返信で教えてください。

**うまくいかないときは**

- 「私のメモにないことは足さないで」は、共有メールではとても大事です。
- 会議の議事録をまるごと作りたいときは、シリーズの第2巻「議事録・要約編」が役に立つかもしれません。

> **ぷるののひとこと**\
> 社内の報告は、ぼくも「結論を先に」と言われることが多いです。AIにも「結論を最初の1文に」と頼むと、ちゃんとそうしてくれます。

# 第9章　社外へのあいさつ・定番のメール

ここでは、初めての連絡や、異動・年末などのあいさつのメールを集めました。決まった形があるメールほど、AIは得意です。

## テンプレ48　初めての相手に連絡する

**場面**：会ったことのない会社や人に、初めてメールを送るとき。

**頼み方（コピペ用）**

```
初めての相手に送るメールを書いてください。
・相手：［会社名・部署・名前（わかれば）］
・自分：［会社名・部署・名前］
・どこで知ったか：［例：ウェブサイト、〇〇さんの紹介、展示会］
・連絡した目的：［何をお願い・相談したいか］
・次の一歩：［例：15分ほどオンラインで話したい］
自己紹介、目的、お願いの順で、300字程度。売り込みっぽくならないように。
```

**試してみた**

入れた内容：株式会社こもれび製作所 広報部 ご担当者様／株式会社ぷるぷる商会 企画部の鈴木／会社のウェブサイトで、木のおもちゃのワークショップの取り組みを見た／自社のお客さま向けイベントで、ワークショップをお願いできないか相談したい／一度オンラインで30分ほど話を聞きたい

出力例：

> 件名：ワークショップのご相談（株式会社ぷるぷる商会）
>
> 株式会社こもれび製作所　広報部　ご担当者様
>
> 突然のご連絡失礼いたします。株式会社ぷるぷる商会 企画部の鈴木と申します。\
> 御社のウェブサイトで、木のおもちゃのワークショップの取り組みを拝見し、ご連絡いたしました。
>
> 弊社では、お客さま向けのイベントを企画しており、その中で御社にワークショップをお願いできないかと考えております。\
> もしよろしければ、一度オンラインで30分ほど、お話をうかがう機会をいただけないでしょうか。
>
> ご多忙のところ恐れ入りますが、ご検討いただけますと幸いです。

**うまくいかないときは**

- 相手の取り組みをほめる部分は、**自分が実際に見たことだけ**にしましょう。AIに相手の会社のことを想像で書かせるのは危険です。
- 署名（電話番号・住所など）は、いつも使っている署名を自分ではりつけてください。

## テンプレ49　異動・着任のあいさつ

**場面**：自分が異動して新しく担当になったとき、または前の担当先にお別れのあいさつをするとき。

**頼み方（コピペ用）**

```
［着任／異動］のあいさつメールを書いてください。
・相手：［取引先の名前］
・自分の変化：［例：〇月〇日から〇〇部へ異動／新しく担当になった］
・後任または前任：［名前］
・これまでのお礼・これからの抱負：［ひとこと］
件名つき、250字程度で。
```

**試してみた**

入れた内容：異動／取引先の今井様／11月1日付で営業部から商品開発部へ異動／後任は営業部の河野／3年間のお礼、今後は商品づくりの立場で関われたらうれしい

出力例：

> 件名：異動のごあいさつ
>
> 今井様
>
> いつも大変お世話になっております。\
> 私事で恐縮ですが、11月1日付で営業部から商品開発部へ異動することになりました。\
> 3年間、多くのことを教えていただき、本当にありがとうございました。
>
> 今後の担当は、営業部の河野が引き継ぎます。改めて河野からもご連絡いたします。\
> これからは商品づくりの立場から、また御社とご一緒できればうれしく思います。
>
> 今後とも変わらぬお引き立てのほど、よろしくお願いいたします。

**うまくいかないときは**

- 「改めて河野からもご連絡いたします」は、後任と話し合ってから残しましょう。
- 着任のあいさつにしたい場合 → ［着任］を選び、「前任の〇〇から引き継ぎました」と書けば作れます。

## テンプレ50　年末のあいさつ

**場面**：年末に、取引先へ一年のお礼と、年末年始の休みを伝えるとき。

**頼み方（コピペ用）**

```
取引先への年末のあいさつメールを書いてください。
・相手：［名前］
・今年のお礼：［例：〇〇の案件でお世話になった］
・年末年始の休み：［いつからいつまで］
・来年について：［ひとこと］
件名つき、200字程度で、季節感のある結びにしてください。
```

**試してみた**

入れた内容：取引先の小松様／春から新しい商品の売り場づくりでお世話になった／12月29日〜1月4日休み／来年もいっしょに売り場を盛り上げたい

出力例：

> 件名：年末のごあいさつ
>
> 小松様
>
> 本年も大変お世話になりました。春からの新商品の売り場づくりでは、多くのお力添えをいただき、心より感謝申し上げます。
>
> 弊社の年末年始の休業期間は、12月29日から1月4日までとなっております。\
> 来年も、ともに売り場を盛り上げていければ幸いです。
>
> 寒さが厳しくなってまいりましたので、どうぞ暖かくしてよいお年をお迎えください。

**うまくいかないときは**

- 休業期間は会社で決まった日付を、**自分で確認して**入れましょう。
- 年明けのあいさつにしたいときは、「新年のあいさつに書きかえて」と頼めます。

## テンプレ51　問い合わせに答える（社外・一般）

**場面**：取引先や外部の人から質問があり、答えを返すとき。

**頼み方（コピペ用）**

```
社外からの質問への返信を書いてください。
・相手：［名前］
・質問の内容：［要点］
・答え：［答え（箇条書きでも可）］
・補足や注意：［あれば］
・答えられないこと：［あれば。例：〇〇は確認中］
答えを先に、わかりやすく、200字程度で。私の答えにないことは書かないでください。
```

**試してみた**

入れた内容：社外の中川様／会社見学は何人まで、どの曜日ならできるか／10人まで、火曜と木曜の午後／駐車場は3台分／見学の中で写真を撮ってよいかは確認中

出力例：

> 中川様
>
> お問い合わせいただき、ありがとうございます。会社見学について、以下のとおりご案内いたします。
>
> ・人数：10名さままで\
> ・曜日：火曜日・木曜日の午後\
> ・駐車場：3台分ございます
>
> なお、見学中の写真撮影が可能かどうかは、現在確認しております。わかり次第ご連絡いたします。\
> ほかにご不明な点がございましたら、お気軽にお知らせください。

**うまくいかないときは**

- 「確認中」のことを書かないと、AIが「撮影はご遠慮ください」などと決めてしまうことがあります。わからないことは「わからない」と渡しましょう。
- 社内で決まった定型文があるなら、それをはりつけて「この形に合わせて」と頼むのもおすすめです。

## テンプレ52　見積もりや資料を送るときの添え状メール

**頼み方（コピペ用）**

```
資料を添付して送るときのメール本文を書いてください。
・相手：［名前］
・添付するもの：［ファイルの名前・数］
・ひとこと説明：［例：先日の打ち合わせの内容を反映した］
・見てほしいところ・お願い：［例：〇日までにご意見を］
4〜5行で、短くお願いします。
```

**試してみた**

入れた内容：社外の山田様／お見積書1つ、商品の説明資料1つ／10月20日の打ち合わせの内容を反映した／ご意見があれば10月30日までに

出力例：

> 山田様
>
> お世話になっております。10月20日のお打ち合わせの内容を反映したお見積書と、商品の説明資料を添付にてお送りいたします。

> ・お見積書（1点）\
> ・商品説明資料（1点）
>

> どうぞよろしくお願いいたします。

**うまくいかないときは**

- **添付のつけ忘れ**は、AIでは防げません。送る前に添付を確認しましょう。
- パスワードつきファイルの送り方などは、会社のルールに合わせて自分で書き足してください。

## テンプレ53　お世話になった人へのお別れのあいさつ（退職）

**場面**：自分が退職するときに、取引先や社内の人へあいさつを送るとき。

**頼み方（コピペ用）**

```
退職のあいさつメールを書いてください。
・あて先：［社内／社外］
・最終出社日：［日付］
・後任：［社外向けなら名前］
・お礼の気持ち：［思い出やエピソードを1つ］
・これから：［書ける範囲で。書かなくてもよい］
暗くならないように、感謝が伝わる文で、250字程度。
```

**試してみた**

入れた内容：社内／最終出社日は11月30日／（社内向けなので後任なし）／入社したとき、仕事の進め方をみんなが一から教えてくれた／これからのことは書かない

出力例：

> 件名：退職のごあいさつ
>
> みなさま
>
> お疲れさまです。私事で恐縮ですが、11月30日をもちまして退職することになりました。\
> 入社したばかりのころ、右も左もわからない私に、みなさんが仕事の進め方を一から教えてくださったことを、今もよく覚えています。本当にありがとうございました。\
> ここで学んだことを大切に、これからもがんばっていきます。\
> みなさまのますますのご活躍を、心からお祈りしております。

**うまくいかないときは**

- 「今もよく覚えています」のような気持ちの言葉は、AIが足したものです。自分の気持ちに合っているか読んで、合わなければ自分の言葉に変えましょう。
- 社外向けにするときは、後任の名前と「後任から改めてご連絡いたします」を入れてもらいます。

> **ぷるののひとこと**\
> あいさつのメールは、AIがいちばんさらっと書いてくれる種類でした。そのぶん、どれも似た文になりがちなので、ひとことだけ自分の思い出を入れるのがおすすめです。

# 第10章　自分の下書きをAIに直してもらう

最後は、ゼロから書いてもらうのではなく、**自分で書いた下書きを直してもらう**頼み方です。慣れてくると、こちらのほうが早いかもしれません。

## テンプレ54　下書きをていねいな文に直す

**場面**：自分で書いたメールが、くだけすぎていないか心配なとき。

**頼み方（コピペ用）**

```
次のメールの下書きを、［社外の取引先／社内の上司］に送れる、ていねいな文に直してください。
内容や事実は変えず、言葉づかいだけを直してください。
直したあとに、どこを変えたかを3つまで箇条書きで教えてください。

［下書きをここにはりつける］
```

**試してみた**

入れた下書き：

> 佐藤さん、見積もり見ました。ちょっと高いかなと思ったので、もうちょい安くできたりしますか？無理なら全然大丈夫です。来週中にお返事もらえるとうれしいです。

（あて先：社外の取引先）

出力例：

> 佐藤様
>
> お世話になっております。お見積もりを拝見いたしました。\
> 恐れ入りますが、予算と比べるとやや高めに感じており、もう少しご調整いただくことは可能でしょうか。\
> 難しい場合は、どうぞご遠慮なくお知らせください。\
> 来週中にお返事をいただけますと幸いです。
>
> 【変えたところ】\
> ・「見ました」→「拝見いたしました」など、敬語に直しました\
> ・「ちょっと高いかな」を「予算と比べるとやや高めに感じており」と、理由が伝わる形にしました\
> ・「無理なら全然大丈夫です」を「難しい場合は、どうぞご遠慮なくお知らせください」にしました

**うまくいかないときは**

- 「予算と比べると」のように、**下書きになかった理由**が足されることがあります。上の例でもそうなりました。事実とちがえば「予算の話は入れないで」と直してもらいましょう。
- 「変えたところを教えて」と頼むと、AIが何を足したか・変えたかがわかりやすくなります。

## テンプレ55　長いメールを短くする

**場面**：書いているうちに長くなってしまったメールを、短くまとめたいとき。

**頼み方（コピペ用）**

```
次のメールを、要点を残して［〇行／〇字］くらいに短くしてください。
・必ず残してほしいこと：［例：日付、お願いの内容］
・消してよいもの：［例：前置き、言い訳］

［メールをここにはりつける］
```

**試してみた**

入れたメール（社内向け、約200字）：

> 中村さん、お疲れさまです。先日はいろいろとありがとうございました。さて、例の件なのですが、あれからいろいろ考えてみたのですが、やはり来週の会議の前に一度相談させていただきたいと思っておりまして、もしお時間があれば、今週の木曜か金曜あたりで30分くらいお時間をいただけないでしょうか。お忙しいところ本当に申し訳ないのですが、ご都合のよい時間を教えていただけるとありがたいです。よろしくお願いいたします。

必ず残す：今週木曜か金曜、30分、来週の会議の前の相談／消してよい：前置き／3行くらいに

出力例：

> 中村さん
>
> お疲れさまです。来週の会議の前に一度ご相談したく、今週の木曜か金曜に30分ほどお時間をいただけないでしょうか。\
> ご都合のよい時間を教えていただけると助かります。よろしくお願いいたします。

**うまくいかないときは**

- 「例の件」のように、短くするとかえって何の話かわからなくなることがあります。上の例では、AIが「例の件」ごと消しました。必要なら「何の相談か（〇〇について）を入れて」と頼みましょう。
- 短くしすぎて冷たく感じる → 「お礼のひとことだけ戻して」と頼みます。

## テンプレ56　送る前の最終チェックをしてもらう

**場面**：書き終えたメールを送る前に、まちがいや失礼がないか、AIに見てもらいたいとき。

**頼み方（コピペ用）**

```
次のメールを送る前にチェックしてください。直した文は書かずに、気になる点だけを箇条書きで教えてください。
見てほしい点：
・敬語のまちがい
・誤字脱字
・相手が読んで、わかりにくいところ
・日付と曜日が合っているか（今年は［西暦］年です）

［メールをここにはりつける］
```

**試してみた**

入れたメール：

> 木下様\
> いつもお世話になっております。来週のお打ち合わせですが、11月12日（水）の14時からでよろしいでしょうか。資料は前日までにお送りさせていただきます。ご確認のほど、よろしくお願い致します。

（今年は2026年）

出力例：

> ・日付と曜日：2026年11月12日は木曜日です。「（水）」になっているので、日付か曜日のどちらかを確認してください。\
> ・「お送りさせていただきます」は、「お送りいたします」のほうがすっきりします（まちがいではありません）。\
> ・「お願い致します」の「致します」は、ひらがなの「いたします」と書く会社も多いです。社内のルールがあれば合わせてください。\
> ・全体として、わかりにくいところは特にありません。

**うまくいかないときは**

- 「直した文は書かずに」と言わないと、AIが全文を書き直してしまい、どこが変わったかわかりにくくなります。
- 曜日のチェックは、AIもまちがえることがあります。AIに「合っている」と言われても、**最後はカレンダーで確かめましょう**。

> **ぷるののひとこと**\
> ぼくはこの「最終チェック」をいちばんよく使います。自分で書いて、AIに見てもらって、最後にもう一度自分で読む。三回読むと、だいぶ安心です。

# おわりに

ここまで読んでくださって、ありがとうございました。ぷるのです。

56個のテンプレを並べてみて、ぼくが気づいたことは3つあります。

1. **AIは、渡された情報でできている。** だれに、何があって、何を入れるか。そこを書くほど、そのまま使えるメールになりました。
2. **AIは、気をきかせて事実を足すことがある。** 「お花を飾りました」「改めてご連絡します」など、言っていないことが入ることがありました。送る前に読むのは、やっぱり人間の仕事です。
3. **1回で決めなくていい。** 「もう少し短く」「ここを消して」と続けて頼めば、少しずつ自分のメールに近づいていきます。

テンプレは、そのまま使っても、少し改造しても大丈夫です。よく使う場面のテンプレは、メモ帳などに自分用にコピーしておくと、次からもっと速くなります。巻末の付録には、テンプレの一覧と、どの場面にも使える「万能の型」、困ったときの「追加の注文」集をまとめました。

メールが少しでも楽になって、空いた時間でお茶でも飲んでもらえたら、ぷるぷるうれしいです。

**スライムと覚える AIへの頼み方テンプレ集**シリーズでは、このあと「議事録・要約編」「PTA・町内会・サークルのお知らせ編」も予定しています。

**依頼（35〜41）**：仕事の依頼／資料の送付／チェック／アンケート／急ぎ／内容の変更／引き受けてもらったあと

## どの場面にも使える「万能の型」

ぴったりのテンプレがないときは、第1章の基本1〜4をまとめた、この型を使ってください。

```
［相手］に送る［メールの種類］を書いてください。
・相手：［名前・関係・社内か社外か］
・用件・起きたこと：［事実を箇条書きで］
・入れてほしいこと：［日付・お願い・次の約束など］
・入れてほしくないこと：［例：言い訳、私が書いていない約束や条件］
件名をつけて、［長さ。例：200字程度］で、［かたさ。例：ていねいだけどかたすぎない］文にしてください。
```

## 困ったときの「追加の注文」集

出てきた文章が少しちがうときは、同じ会話の続きで、次のように頼んでみてください。

- 長い → 「もう少し短くして」「3行に減らして」
- かたい／やわらかすぎる → 「もう少しやわらかく」「もう一段ていねいに」
- お礼やお詫びがくどい → 「お礼の言葉は1回だけにして」「お詫びは最初と最後の2回だけ」
- 言っていないことが入った → 「私が書いていないことは消して」
- 約束が増えた → 「最後の一文はなしで」「『改めてご連絡』は消して」
- 理由をぼかしたい → 「理由は『私用のため』として」
- 件名に迷う → 「件名を3つ考えて」
- 自分の名前がない → 「最後に署名として［会社名・名前］を入れて」
- 送る前に確かめたい → テンプレ56の「最終チェック」へ

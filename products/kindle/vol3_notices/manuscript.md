# この本について

- この本は、AI（人工知能）が企画・執筆し、表紙もAI（プログラム）で作りました。
- のっている「出力例」は、テンプレの［　］を**架空の内容**で埋めた頼み方を、AI（Anthropic社のClaude）に**1つずつ別々に送って、返ってきた答え**です。言い回しは直さず、そのまま載せています（見出しや太字の記号〔#や**〕だけは、読みやすさのために取りのぞいています）。答えが文の形で返ってこなかったテンプレ2つ（41・49）だけは、頼みなおした答えを載せ、そのことを各テンプレに書いています。
- 試したのは2026年10月です。この本を書いたAIと同じ系統のAIで試しているので、ほかのAIのサービスでは、答えの雰囲気が変わることがあります。
- 出てくる団体・お店・人の名前、日付、金額は、**すべて架空**です。実在のものとは関係ありません。
- AIの答えは、**同じ頼み方でも毎回少しずつ変わります**。「必ずこうなる」ものではなく、「こんな感じで返ってくることが多い」という目安として読んでください。
- 特定のAIサービスの機能・料金・設定については、この本では扱いません。お使いのサービスの公式の案内を確認してください。

# はじめに

> **ぷるの**：こんにちは。スライム国の案内係、スライムの「ぷるの」です。ぷるぷる。

PTAの係になった。町内会の班長が回ってきた。サークルの幹事をたのまれた。
そうなると、やってくるのが「お知らせ文」の仕事です。

「来週の清掃、どう書けば人が来てくれるんだろう」
「会費を払っていない人に、どう伝えたら角が立たないかな」
「回覧板は、ご年配の方も読むから、読みやすくしたい」

お知らせ文は、短いのに気をつかいます。書く人も、ほとんどがボランティアです。
仕事や家のことの合間に、夜おそくまで文面に悩んでいる人も多いのではないでしょうか。

> **ぷるの**：そういう「ちょっと気をつかう文」の下書きは、AIにまかせると、ずいぶん楽になるよ。

ただし、AIに「いい感じのお知らせを書いて」とだけ頼むと、

- 日時や持ち物が抜けている
- 「ぜひ」「必ず」が多くて、ちょっと圧が強い
- たのんでいない話（講師の経歴や、来場者の人数など）が、勝手に足されている

…といった答えが返ってくることがあります。

この本では、PTA・町内会・サークルで出番の多い場面ごとに、**そのままコピペして使える頼み方**を、59個のテンプレにまとめました。

## この本の使い方

各テンプレは、次の4つでできています。

1. **場面**：どんなときに使うか
2. **コピペ用の頼み方**：そのままAIに貼れる文章です。**［　］の中**を、自分の内容に書きかえてください。
3. **試した出力例**：架空の内容を入れて、実際にAIに頼んだときの答えです。
4. **うまくいかないときの直し方**：よくあるズレと、その直し方です。

使うときの流れは、かんたんです。

1. 場面に合うテンプレを探す
2. 「コピペ用の頼み方」をコピーして、AIのチャット欄に貼る
3. ［　］の部分を書きかえる
4. 送る。返ってきた答えを**自分の目で確認**してから配る

> **ぷるの**：4番目がいちばん大事！ AIの文は「下書き」。日付・曜日・金額・名前は、最後に人がチェックして完成だよ。

# 第1章　AIへの頼み方の基本

テンプレを使う前に、5つのコツと、お知らせ文ならではの注意を知っておくと、自分でテンプレを直すときに迷いにくくなります。

## コツ1　「だれが・だれに・何を書くか」を最初に言う

「あなたは〇〇小学校PTAのお知らせ係です。保護者向けのお知らせ文を書いてください。」
このように、**書く人の立場と、読む人**を最初に伝えると、言葉づかいや長さが合いやすくなります。

## コツ2　事実は箇条書きで渡す

日時、場所、持ち物、締め切り、連絡先。お知らせ文の「中身」は、**箇条書きで1つずつ渡します**。
文章でまとめて渡すより、抜けやまちがいが起きにくくなります。

```
・日時：11月14日（土）午前10時〜11時30分
・場所：さくら小学校 図工室
・持ち物：牛乳パック1本、はさみ、タオル
```

## コツ3　「足さないで」をはっきり言う

AIは、気をきかせて、**頼んでいないことを書き足す**ことがあります。
講師の経歴、来場者の人数、「毎年大好評」などの言葉は、事実でなければ困ります。

「私が書いた内容だけを使い、付け足さないでください」
「数字は私が書いたものだけを使ってください」

と一言入れておくと、足されにくくなります（ゼロにはなりません。最後は自分で確認します）。

## コツ4　長さと形を指定する

「A4 1枚」「LINE用に3行」「1文40字くらいまで」「箇条書きで」など、**長さと形**を伝えます。
同じ内容でも、紙で配るのか、LINEで送るのか、掲示板にはるのかで、ちょうどよい長さはちがいます。

## コツ5　一回で決めなくていい

最初の答えがしっくりこなければ、続けて一言送るだけで直せます。

- 「もう少し短くしてください」
- 「『ぜひ』を使わずに書き直してください」
- 「2行目をもっとやわらかく」

> **ぷるの**：AIとの会話はキャッチボール。ちょっとずつ近づけていけばいいんだ。

## 曜日と数字は、かならず自分で確かめる

お知らせ文で一番多い事故は、**日付と曜日のずれ**、そして**金額のまちがい**です。
AIは、曜日をまちがえることがあります。合計金額の計算も、まちがえることがあります。

- 曜日は、カレンダーで自分で確かめてから、頼み方に書く
- 合計や繰越金は、電卓で自分で出してから渡す
- AIの答えの日付・金額を、最後にもう一度、元のメモと見比べる

この本の出力例でも、日付と曜日は、こちらでカレンダーを見てから頼み方に書いています。

## 答えの「前後のひとこと」は消してから配る

AIは、お知らせ文のあとに「A4 1枚に収まる長さにしました」「必要なら調整します」のような**ひとこと**をつけることがあります。この本の出力例にも、そのまま残しています。
配るときは、この部分を消してから使ってください。

## 角が立たない言い方のコツ

PTAや町内会は、仕事とちがって「上司と部下」がありません。みんな対等で、しかもご近所です。
だからこそ、**ちょっとした言い方のちがい**で、受け取る気持ちが大きく変わります。
AIに頼むときに、次のような条件を足してみてください。

| こうなりがち | こう頼むと、やわらかくなる |
|---|---|
| 「〜してください」が続く | 「『〜していただけると助かります』など、お願いの言い方を混ぜてください」 |
| 「必ず」「絶対に」「厳守」 | 「強い言葉（必ず・厳守など）は使わないでください」 |
| 注意の理由がない | 「なぜお願いするのか、理由を1文入れてください」 |
| いきなり本題 | 「最初に『いつもありがとうございます』の一言を入れてください」 |
| 特定の人を責めているように読める | 「だれのことかわからない書き方にしてください」「だれでもうっかりしてしまうこと、という書き方で」 |
| 参加しないと悪いように読める | 「参加は自由で、来られなくても気にしなくてよいことが伝わるように」 |
| 謝りすぎて、かえって重い | 「お詫びは1回だけにしてください」 |

> **ぷるの**：「お礼から始めて、理由を添えて、お願いで終わる」。この順番だけでも、ずいぶん感じがよくなるよ。

ただし、やわらかくしすぎると、**何をしてほしいのかが伝わらなく**なります。
そのときは「お願いの中身ははっきり残してください」と頼みましょう。

## ご高齢の方にも読みやすい書き方のコツ

回覧板や掲示板のお知らせは、ご高齢の方も読みます。次のような点を、頼み方の条件に入れておくと、だれにとっても読みやすい文になります。

- **1文を短く**：「1文30〜40字くらいまで」と数字で伝える
- **カタカナ語を減らす**：「カタカナ語は、やさしい言葉に言いかえてください」（例：「エントリー」→「申し込み」）
- **むずかしい熟語を減らす**：「標記の件」「万障お繰り合わせ」などのかたい言い回しは使わない
- **日時は省略しない**：「11/8 9:00」ではなく「11月8日（日曜日）午前9時」のように、曜日と午前・午後まで書く
- **大事なことは箇条書き**：日時・場所・持ち物は、文の中にうめずに、1行ずつ
- **問い合わせ先は電話も**：スマホやLINEを使わない方もいるので、連絡の方法を2つ用意できるとていねい
- **紙にするときは文字を大きく**：行数を少なくして、印刷するときの文字を大きめにする（これはAIではなく、印刷のときの工夫です）

この本では、元の文を読みやすく直してもらう頼み方を、第8章のテンプレに入れています。

## 個人情報の取り扱い

お知らせ文の材料には、名前、住所、電話番号、子どもの学年やクラスなど、**個人の情報**が入りがちです。

- 団体に「外部のサービスに個人情報を入れない」などのルールがあるなら、そちらを優先してください。
- 入力した内容がどう扱われるか（保存されるか、学習に使われるか、設定で変えられるか）は、**サービスや契約によって違います**。この本では、特定のサービスについて「安全」「危険」とは言い切りません。使う前に、利用規約やプライバシーの説明を確かめてください。
- 個人の名前は「担当者」「Aさん」などに置きかえて頼み、**できあがった文に自分で名前を入れる**のが手軽で安全です。
- 電話番号、住所、口座番号、子どもの名前などは、**AIに入れない**のが基本です。
- 未払いの人の名前、役員を断った人の事情、ご近所の苦情の相手など、**人間関係にかかわる情報**も、入れずに頼みましょう。

> **ぷるの**：この本の例に出てくる名前は、ぜんぶ架空だよ。実際に使うときは、名前を「〇〇さん」にして頼んで、最後に自分で書き入れてね。

> **ぷるの**：お知らせの「5点セット」は、日時・場所・持ち物・締め切り・問い合わせ先。これがそろえば、もう半分できあがり！

## テンプレ02　町内の一斉清掃の案内

**① 場面**
町内会の清掃活動や草取りの案内です。「なるべく参加してほしいけれど、強制には聞こえたくない」ときに。

**② コピペ用の頼み方**

```
［町内会名］の［行事名］のお知らせを、回覧板用に書いてください。

・日時：［月日（曜日）と時間］（［雨天の場合］）
・集合場所：［場所］
・持ち物：［持ち物］
・町内会で用意するもの：［用意するもの］

条件：
・参加をお願いしたいが、無理強いには聞こえないようにする
・ご高齢の方や体調のすぐれない方は、無理をしなくてよいと一言添える
・文は短く、1文40字くらいまで
```

**③ 試した出力例**

実際に送った頼み方（［　］を架空の内容で埋めたもの）：

```
ひまわり町内会の秋の一斉清掃のお知らせを、回覧板用に書いてください。

・日時：11月8日（日）午前8時〜9時（雨天の場合は11月15日（日）に延期）
・集合場所：ひまわり公園
・持ち物：軍手、ほうき（お持ちの方）
・町内会で用意するもの：ごみ袋、飲み物

条件：
・参加をお願いしたいが、無理強いには聞こえないようにする
・ご高齢の方や体調のすぐれない方は、無理をしなくてよいと一言添える
・文は短く、1文40字くらいまで
```

AIの答え：

```

**④ うまくいかないときの直し方**

## テンプレ03　夏祭り・盆踊りの案内

**① 場面**
町内会や子ども会のお祭りの案内です。楽しさが伝わる文と、注意事項の両方を入れたいときに。

**② コピペ用の頼み方**

```
［団体名］の［お祭りの名前］の案内文を書いてください。

・日時：［月日（曜日）と時間］
・場所：［場所］
・内容：［出し物・屋台など］
・お願い：［ごみの持ち帰り・駐車場がないなど］

条件：
・最初の2〜3行は、楽しい雰囲気が伝わるように
・お願いごとは最後にまとめて、責める言い方にしない
・子どもから大人まで読める言葉で
```

**③ 試した出力例**

実際に送った頼み方（［　］を架空の内容で埋めたもの）：

```
ひまわり町内会の「ひまわり夏まつり」の案内文を書いてください。

・日時：7月25日（日）午後4時〜8時
・場所：ひまわり公園
・内容：盆踊り、ヨーヨーつり、焼きそば、かき氷（子どもは無料券あり）
・お願い：ごみはお持ち帰りください／駐車場はありません／花火は禁止です

条件：
・最初の2〜3行は、楽しい雰囲気が伝わるように
・お願いごとは最後にまとめて、責める言い方にしない
・子どもから大人まで読める言葉で
```

AIの答え：

```
ひまわり夏まつり

お金の話は、いちばん気をつかう場面です。金額や合計は、AIに計算させずに自分で確かめてから渡します。

> **ぷるの**：お金の文は「使い道」と「お礼」をセットにすると、ぐっと受け取ってもらいやすくなるよ。

---

## テンプレ09　会費の集金のお知らせ

**① 場面**
年会費や行事の参加費を集めるときの基本形です。

**② コピペ用の頼み方**

```
［団体名］の［会費の名前］の集金のお知らせを書いてください。

・金額：［金額］
・集金日：［月日（曜日）］
・集め方：［誰が・どうやって集めるか］
・使い道：［主な使い道］

条件：
・おつりのいらないように用意してほしいことを、やわらかく
・使い道を1〜2行で書いて、納得してもらえるように
```

**③ 試した出力例**

実際に送った頼み方（［　］を架空の内容で埋めたもの）：

```
ひまわり町内会の令和8年度後期の町内会費の集金のお知らせを書いてください。

・金額：1世帯 1,800円（半年分）
・集金日：11月15日（日）〜11月22日（日）のあいだ
・集め方：各班の班長が、ご自宅にうかがいます
・使い道：街灯の電気代、ごみ集積所の管理、防災用品の購入など

条件：
・おつりのいらないように用意してほしいことを、やわらかく
・使い道を1〜2行で書いて、納得してもらえるように
```

AIの答え：

```
令和8年度後期 町内会費集金のお知らせ

ひまわり町内会 会員の皆さまへ

秋も深まってまいりました。日ごろより町内会の活動にご理解とご協力をいただき、ありがとうございます。
さて、令和8年度後期の町内会費の集金を、下記のとおり行います。お忙しいところ恐れ入りますが、ご準備をお願いいたします。

記

1. 会費　1世帯 1,800円（半年分）

2. 集金期間　11月15日（日）〜11月22日（日）

3. 集め方　各班の班長が、ご自宅にうかがいます。

4. 会費の使い道
街灯の電気代、ごみ集積所の管理、防災用品の購入など、地域の安全で快適な暮らしを支えるために使わせていただきます。

5. お願い
集金がスムーズに進みますよう、できましたら1,800円ちょうどをご用意いただけると助かります。ご協力のほど、よろしくお願いいたします。
不在の場合は、班長とご相談のうえ、ご都合のよい日をお知らせください。

ひまわり町内会

---

補足です。
- 「不在の場合」の一文は、集金が週をまたぐ点を考えて私が足しました。不要でしたら削除してください。
- 会長名や連絡先を入れる場合は、末尾の「ひまわり町内会」の下に追記してください。
```

**④ うまくいかないときの直し方**

- **この例では**：「不在の場合は〜」の一文を、AIが自分の判断で足していました（補足に書いてあります）。団体のやり方と合うか確かめます。
- 留守のときどうするかが抜けている → 「留守の場合の対応（封筒をポストへ、など）も入れてください。対応は［　］です」
- 領収書の有無を書きたい → 「領収書をお渡しすることも書いてください」

# 第4章　役員・係の募集

役員や係の募集は、正直さが大切です。仕事の量をぼかすと、あとで「聞いていた話とちがう」となりがちです。

> **ぷるの**：「大変です」より「月1回・1時間です」。具体的なほうが、手をあげやすいんだって。

# 第6章　中止・延期・変更の連絡

中止や延期の連絡は、早く・短く・まちがいなく。とくに、新しい日時の書きまちがいには気をつけます。

> **ぷるの**：1行目で「中止」「延期」がわかるように。忙しい人は1行目しか読まないこともあるからね。

---

## テンプレ27　雨で中止のお知らせ

**① 場面**

**② コピペ用の頼み方**

```
［行事名］が雨のため中止になりました。お知らせ文を書いてください。

・LINEにも貼れる短さで
```

・この後どうなるか：今年は行いません。春にあらためて計画します
・お願い：会費をお預かりした方には、班長からお返しします

・1行目で「中止」がわかるように

# 第9章　アンケート

アンケートは、答えてもらうまでと、結果をまとめるところの両方で、AIが手伝えます。集計した数字は自分で数えたものを使います。

> **ぷるの**：アンケートは「何に使うか」を書くと、答えてもらいやすくなるよ。

## テンプレ53　できあがった文の見直し（抜け・まちがい探し）

**① 場面**
自分で書いた文や、AIが書いた文を、配る前にチェックしてもらいます。

**② コピペ用の頼み方**

```
次のお知らせを、配る前にチェックしてください。

チェックしてほしいこと：
・日時・場所・持ち物・締め切り・問い合わせ先のうち、抜けているもの
・誤字や、意味が二通りに読める文
・曜日が合っているか（［年］年のカレンダーで）

直した文ではなく、気になる点を箇条書きで教えてください。

【お知らせ】
［文を貼る］
```

**③ 試した出力例**

実際に送った頼み方（［　］を架空の内容で埋めたもの）：

```
次のお知らせを、配る前にチェックしてください。

チェックしてほしいこと：
・日時・場所・持ち物・締め切り・問い合わせ先のうち、抜けているもの
・誤字や、意味が二通りに読める文
・曜日が合っているか（2026年のカレンダーで）

直した文ではなく、気になる点を箇条書きで教えてください。

【お知らせ】
子ども会 クリスマス会のお知らせ
日時：12月12日（日）午後1時から
場所：ひまわり町内会館
参加費：500円
ゲームやプレゼント交換をします。プレゼントは300円くらいのものを用意して下さい。
参加する人は、12月4日までに班長さんに申し込んで下さい。
```

AIの答え：

```
チェック結果

曜日の誤り
- 2026年12月12日は土曜日です。「(日)」は誤りです。日曜は12月13日です。日付と曜日のどちらが正しいかを確認してください。
- 締め切りの12月4日は金曜日です。曜日が書かれていないので、書き添えると親切です。

抜けている項目
- 問い合わせ先: 連絡先(名前・電話番号など)がありません。
- 持ち物: プレゼント以外が書かれていません。飲み物、上履き、名札などが必要なら追記が要ります。不要なら「特になし」とあると安心です。
- 終了時刻: 「午後1時から」だけで、終わる時間がありません。迎えの時間の目安になります。
- 場所の補足: 会館名のみで、住所や目印がありません。町内の方以外には分かりにくいかもしれません。
- 参加費の払い方: 申し込み時に払うのか、当日持参なのかが書かれていません。
- 申し込み方法: 「班長さんに申し込む」とありますが、口頭か用紙かが不明です。班長さんが誰か分からない人もいるかもしれません。

二通りに読める、または分かりにくい点
- 「参加する人は」: 子どもだけなのか、保護者の参加もよいのかが不明です。対象学年も書かれていません。
- 「500円」と「300円くらいのプレゼント」: 合計800円かかるのか、参加費にプレゼント代が含まれるのかが分かりにくいです。
- 「300円くらいのもの」: 上限なのか目安なのかが曖昧です。
- 「12月4日までに」: 4日を含むのかが曖昧です。「12月4日(金)まで」と書けば解消します。

表記
- 誤字は見当たりません。
- 「下さい」は、補助的な用法なので「ください」とひらがなにするのが一般的です。ただし趣旨が伝わらなくなるわけではないので、任意です。
```

**④ うまくいかないときの直し方**

- **この例では**：じつは、この例の「12月12日（日）」は、こちらが書きまちがえたものです（2026年の12月12日は土曜日）。AIはそれを見つけてくれました。ただし、AIが曜日をまちがえることもあるので、最後はカレンダーで確かめます。
- AIのチェックも完ぺきではない。曜日は最後に必ず自分でカレンダーを見る
- 直した文がほしいときは → 「気になる点を直した文も、最後に出してください」

## テンプレ54　もっとやわらかい言い方に直す

**① 場面**
書いた文がきつく感じるとき、角が立たない言い方に直してもらいます。

**② コピペ用の頼み方**

```
次の文が、少しきつく感じます。
内容は変えずに、角が立たないやわらかい言い方に直してください。
直したところを、あとで箇条書きで教えてください。

【文】
［文を貼る］
```

**③ 試した出力例**

実際に送った頼み方（［　］を架空の内容で埋めたもの）：

```
次の文が、少しきつく感じます。
内容は変えずに、角が立たないやわらかい言い方に直してください。
直したところを、あとで箇条書きで教えてください。

【文】
集会所の使用後は、必ず掃除をしてから帰ってください。前回、ごみが放置されていました。鍵は使用後すぐに返却すること。守れない場合は今後の使用をお断りします。
```

AIの答え：

```
【直した文】

集会所をご利用になったあとは、お手数ですが、掃除をしてからお帰りいただけると助かります。前回、ごみが残っていたことがありましたので、あらためてお願いいたします。鍵は、ご利用後すぐにご返却ください。みなさまに気持ちよくご利用いただくため、ご協力をお願いいたします。なお、難しい場合は、今後のご利用についてご相談させていただくことがあります。

【直したところ】

- 「必ず掃除をしてから帰ってください」→「お手数ですが、掃除をしてからお帰りいただけると助かります」:命令調をやめ、依頼の形にしました。
- 「ごみが放置されていました」→「ごみが残っていたことがありました」:「放置」という責める印象の言葉を避け、事実だけを伝える表現にしました。
- 「あらためてお願いいたします」を追加:前回の件を注意ではなく、お願いとして受け取ってもらえるようにしました。
- 「返却すること」→「ご返却ください」:体言止めの指示を、丁寧な依頼にしました。
- 「みなさまに気持ちよくご利用いただくため、ご協力をお願いいたします」を追加:ルールの理由を示して、押しつけに聞こえないようにしました。
- 「守れない場合は今後の使用をお断りします」→「難しい場合は、今後のご利用についてご相談させていただくことがあります」:断定的な警告を、話し合いの余地を残す言い方にしました。内容(守られなければ利用に影響がある)は保っています。
```

**④ うまくいかないときの直し方**

- **この例では**：「守れない場合は使用をお断りします」が「ご相談させていただくことがあります」になり、意味が少し弱くなりました。強さを残したいときは、そう伝えて直してもらいます。
- やわらかくしすぎて、ルールが伝わらなくなった → 「お願いの中身ははっきり残してください」
- まだきつい → 「もう一段階やわらかく」と一言送るだけでもよい

## テンプレ55　敬語のチェック

**① 場面**
目上の方や地域の方に出す文の、敬語が合っているか見てもらいます。

**② コピペ用の頼み方**

```
次の文の敬語が正しいか、チェックしてください。
まちがいや、ていねいすぎて不自然なところがあれば、理由と直し方を教えてください。

【文】
［文を貼る］
```

**③ 試した出力例**

実際に送った頼み方（［　］を架空の内容で埋めたもの）：

```
次の文の敬語が正しいか、チェックしてください。
まちがいや、ていねいすぎて不自然なところがあれば、理由と直し方を教えてください。

【文】
先日は夏まつりにご協賛いただきまして、誠にありがとうございました。おかげさまで、たくさんの方が参加させていただきました。景品をいただかれた子どもたちも、大変喜んでおられました。今後ともよろしくお願い申し上げます。
```

AIの答え：

```
結論から言うと、いくつか直したほうがよい箇所があります。

修正が必要な箇所

1. 「たくさんの方が参加させていただきました」→ 誤り
- 理由:「参加させていただく」は、自分(こちら側)が参加する場合の表現です。ここでは参加したのは「方」(相手や来場者)なので、主語と敬語が合っていません。
- 直し方:「たくさんの方に参加していただきました」「たくさんの方がご参加くださいました」

2. 「景品をいただかれた子どもたち」→ 誤り
- 理由:「いただく」は謙譲語なので、子どもたち(相手側)の動作には使えません。さらに「れる」を付けても敬語としては成り立ちません。また、景品を「あげた」のは協賛先なので、受け取る側の子どもたちに敬語を重ねる必要もあまりありません。
- 直し方:「景品を受け取った子どもたち」「景品を手にした子どもたち」

3. 「大変喜んでおられました」→ 少していねいすぎ(不自然)
- 理由:「おられる」は文法的には誤りではありませんが、相手(協賛者)に対して、子どもたち(こちら側の身内に近い存在)の動作を高めてしまうため、不自然です。
- 直し方:「大変喜んでおりました」(謙譲・丁重)、または「大変喜んでいました」

問題のない箇所

- 「ご協賛いただきまして、誠にありがとうございました」:正しい表現です。「ご協賛くださいまして」でも可。
- 「おかげさまで」:適切です。
- 「今後ともよろしくお願い申し上げます」:正しい結びです。

修正例

> 先日は夏まつりにご協賛いただきまして、誠にありがとうございました。おかげさまで、たくさんの方にご参加いただきました。景品を受け取った子どもたちも、大変喜んでおりました。今後ともよろしくお願い申し上げます。

補足

- 「景品を差し上げた」など、協賛者が景品を提供した点に触れるなら、「ご提供いただいた景品を受け取った子どもたちも」とすると、感謝がより伝わります。
```

**④ うまくいかないときの直し方**

- AIの説明にも迷うところがあるときは、国語辞典や敬語の本でも確かめる
- 直しすぎて固くなったら → 「町内のお店あてなので、ていねいすぎない程度に」

> **ぷるの**：ここまで読んでくれて、ありがとう！ ぷるぷる。

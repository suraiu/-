# 02 リサーチAI提案：「1回出品すれば売れ続けるデジタル商品」は成り立つか

> 立場：市場の需要を調べる専門家（リサーチAI）
> 作成：2026-10-20（火）／ステータス：**提案（未承認）**。出品・価格・アカウント作成は人の承認後に実行。
> 調べ方：WebSearch（検索の抜粋のみ）。WebFetchは今回すべて接続できなかった（booth.pm、kdp.amazon.co.jp、creator.line.me、brain-market.com はいずれも名前解決エラー）。**公式ページで確認できなかった点は「要確認」と書いている。** 二次情報（ブログ等）だけで確認したものは「二次情報」と付けた。

## 0. 結論を先に

1. **「1回出品すれば勝手に売れ続ける」は、実績ゼロ・40日では、ほぼ成り立たない。** どのプラットフォームも、売れるかどうかは「見に来る人がいるか」で決まる。フォロワー100〜300人でも有料記事が売れなかったという体験談が複数あり、「売れなかった原因は中身ではなく、そもそも見てもらえていなかった」とまとめられている（二次情報）。
2. もう一つの大きな制約：**どのプラットフォームにも、出品用の公式APIが見つからない。** noteは「公式APIはない」と解説されている（二次情報）。つまり出品・記事更新・値下げ・クーポンは、すべてオーナーの手作業になる。「最初に1回まとめて出品する」形にしか設計できない。
3. それでも条件の中で一番マシなのは、**需要の裏付けがあるジャンル（AI活用）の商品を、手数料が安く自動で納品されるnoteとBOOTHに1回だけ置き、集客はAIがAPIで投稿するX・Threadsに任せる**プラン。
4. **達成確率は約7%（幅3〜12%）と見ている。** 根拠は6章。正直に言うと、5万円を確実に狙うなら「オーナーが毎日30分営業する」B2B案（`sales/plan_november.md`）のほうが確率は高い。ただし、その案は今回の前提1（オーナーはほぼ動かない）に合わない。

### 表から読み取れること
- **手数料**で見ると、BOOTH（5.6%＋45円・要確認）＞ note（実質約14.5%）≒ Tips（14%）＞ Brain（12%＋出金料）の順に手元に残る。Kindleの35%や、LINEの35%は大きく不利。
- **11月に「確定」させやすい**のは note（毎月2日に前月分が確定と明記）。Brain は「販売から30日」の縛りがあるが、確定ではなく出金の話なので、11月の売上として数えることはできる。
- **AI規約が一番はっきり厳しい**のは Kindle（申告必須・2026年4月から強化）と BOOTH（粗製乱造品は強制非公開）。どちらも「少数の、ちゃんとした商品」なら問題になりにくい。量で勝負するやり方は全部ダメ。
- **見に来てもらう力**を自前で持っているのは Kindle（Amazon検索）くらい。note・BOOTH・Brain・Tips は外（SNS）から連れてくる前提。

## 4. オーナーに最初に1回だけ頼むこと（10/24〜10/26のどこかで、約90分）

AIが「コピペするだけ」の状態に全部そろえてから渡す。手順書は `output/2026-10-24/owner_setup.md` に作る。

1. **noteで売る準備**：アカウント（あれば今のもの）、銀行口座の登録、**自動振込申請をオン**（12/6までにオンにすれば12/7申請・12月末振込）。
2. **BOOTHのショップ開設**：pixiv ID、ショップ作成、口座登録。
3. **出品（全部で4つ）**：noteに有料記事2本（A・B）と無料の見本記事2本を貼り付けて公開。BOOTHに商品A（ZIP）と商品B（PDF）をアップロード。値段は上の表のとおりで、**あとから変えない**（変えるにはオーナーの手作業が必要になるため）。
4. **特定商取引法の表記をどうするか決める**（個人の住所・名前を出すかどうか。各サービスの表記の扱いは要確認）。
5. **X・ThreadsのAPIトークンを設定し、`data/config.md` の `AUTO_POST` を `true` にしてよいか判断する。**
6. **12/1に1回だけ**：note・BOOTHの11月の売上画面のスクリーンショットを送ってもらう（AIは売上画面にログインできないので、結果の確認だけはお願いする）。

※ 2本の記事の中身は、出品後に直す前提にしない。誤りが見つかったときだけ、修正版の貼り替えをお願いする（品質管理AIで事前に潰しておく）。

## 7. リスクと対策

| **そもそも見に来る人がいない**（フォロワー0から40日） | **非常に高い** | 「AIだけで会社を回している」という話題そのものを投稿にする。ただしこれでも伸びる保証はない。いちばん大きなリスクで、確率が低い主な理由 |
| 商品Aが「稼げる情報商材」に見える | 中 | 収入の約束を一切しない。売上0円も含めて公開する。品質管理AIが誇大表現をチェック |
| 商品Bの事実誤り（議員が議会で使う＝影響が大きい） | 中 | 出典2つ以上・確認日を書く。「確認できなかった数字」は「未確認」と書く。最後に「使う前に一次資料をご確認ください」と入れる |
| BOOTHの「AI粗製乱造」扱い | 低〜中 | 出品は2点だけ。中身を作り込む。類似品の大量出品をしない |
| X APIの料金・投稿数の上限 | 中（**要確認**） | 無料の範囲で投稿する。足りなければThreadsを中心にする。有料プランを使うと経費で赤字になるので使わない |
| 出品後に直せない（AIはログインできない） | 中 | 出品前に品質管理を2回通す。どうしても必要な修正だけオーナーに頼む |
| 手数料が想定とちがう（BOOTHの改定は二次情報） | 低 | 計算は手取りが低いnoteの数字で行っている。BOOTHの公式料金はオーナーのセットアップ時に画面で確認 |
| 特商法の表記で個人情報が出る | 中 | 4章の4でオーナーに先に決めてもらう。決まらなければnoteのみで出す（BOOTHの扱いは要確認） |
| 入金は12月以降になる | 確実 | ブリーフの前提4では「11月中に確定した売上」で数えるのでOK。noteは12/2確定・12月末振込 |

## 8. 達成確率と根拠（正直に）

**達成確率：約7%（幅3〜12%）**

- **18人に買ってもらう必要がある一方、見込み客との接点は今ゼロ。** フォロワー100〜300人でも有料記事が売れなかったという体験談が複数ある（二次情報）。40日で数百人のフォロワーを作れたとしても、そこから18件はかなり上振れが必要。
- 確率を上げる材料：①AI活用ジャンルは需要が伸びている（note社の分析）②「AIだけで会社を回す」は話題性がある ③商品Bは11月下旬という時期の追い風がある ④手数料が低く、納品が自動なので、1件あたりの手取りが大きい（2,500〜4,600円）。
- 確率を下げる材料：①集客はX・Threadsの自動投稿だけ ②出品後に値段・中身を直せない ③1%という購入率は根拠のない仮置き。
- **比べると**：オーナーが毎日30分、営業メールを確認・送信できるなら、`sales/plan_november.md` のB2B案のほうが確率は高いと見ている（直接連絡できるため）。前提1を少しゆるめられるかどうかを、会議で決めてほしい。
- 11月に5万円に届かなくても、商品A・Bは12月以降も置いたままにできる。そこがこのプランの「1回出品」の価値で、40日勝負よりも長い期間で効いてくる。

## 1. プラン名と一言の説明

**「12月議会パック」**
地方議員・自治体職員・コンサルが**12月議会の一般質問を準備する時期（11月）**に合わせて、「日本ではまだ知られていない海外の仕組み」を出典付きでまとめた**note有料記事**を売る。集客はAIがX・Threads・InstagramのAPIで毎日行う。売るのも届けるのもnoteが自動でやるので、オーナーの仕事は最初の1回だけで済む。

なぜこれにしたか（3行で）：
1. 前提2（AIはログインできない）があるので、**決済と納品をプラットフォームが自動でやってくれる売り方**しか、オーナーなしでは回らない。受注・メッセージ・納品が毎回いるココナラやB2B受託は回らない。
2. 12月議会の一般質問の通告締切は、多くの議会で**11月下旬**にある（新潟県議会：質問要旨の通告期限11/30〈2021年〉、柏市議会：通告締切11/21〈2023年〉など。過去の例で、2026年の日程は議会ごとに要確認）。**「11月に海外事例を探す人がいちばん多い」という時期と、今回の期間がぴったり重なる。**
3. ブランドのB2Bの見込み客（`brand/guidelines.md`）とネタ帳（`data/ideas.md`）、サンプルレポート（`sales/sample_report.md`）をそのまま使える。

## 4. オーナーに最初に1回だけ頼むこと（10/26（日）までに、1回・約90分）

まとめて1回で終わるように、AIが手順書・貼るだけの本文・画像を全部先に用意しておく。

1. **noteのアカウント作成と、売上の振込先口座の登録**（本人確認がいるなら一緒に）。
2. **有料記事2本（AとB）を貼り付けて公開する。** 本文・見出し画像・価格・無料部分の区切り位置は、AIがファイルで用意する。このとき「価格の上限」「領収書が出せるか」「特定商取引法の表記が必要か」を画面で見て、メモを1行残してもらう（**要確認**の3点）。
3. **X・Threads・InstagramのAPIトークンを設定し、`data/config.md` の `AUTO_POST` を `true` にする許可。** Instagramはビジネス／クリエイターアカウントへの切り替えとFacebookページの連携がいる（要確認）。
4. **X APIの利用料として$10ほどをクレジットで入れる**（従量課金の前払い。要確認）。

→ これより後、オーナーにお願いするのは「記事に誤りが見つかって直す必要が出たとき」だけにする（7章）。

## 5. AIが自動でやること／自動化できない作業とその解決策

### AIが自動でやること
| 担当 | 作業 |
|---|---|
| ②リサーチ＋④ライター | 30事例の調査と執筆（ネタ帳の10件＋新しく20件）。一次資料（政府・議会・統計）を優先する |
| ⑥品質管理 | 全事例の出典・数字・禁止表現・「日本を下げていないか」・政治的にかたよっていないかの検査。合格したものだけを載せる |
| ③戦略（私） | 毎日の投稿テーマ選び。投稿時刻は初期値（X 7:30/12:15/21:00、Threads 8:00/20:30、Instagram 19:00）から始めて、週ごとに直す |
| ⑦投稿・分析 | X 1日2本・Threads 1日2本・リール週3本をAPIで投稿。表示・クリック・フォロワーを `data/metrics.md` に記録する |
| ⑤デザイン＋⑧動画 | 1事例を1枚の画像・15〜30秒のリールにする（`scripts/` を使う。AIで描いた実写風の画像は使わない） |
| ⑩コミュニティ | **自分の投稿に付いたコメントへの返信**（APIで）。知らない人への一方的なリプライやDMはしない（スパム扱いになるため） |
| ⑨収益化 | 売上を `data/revenue.md` に記録（noteの数字は自動で取れない。下の表を参照） |

**集客の作り方（私の専門部分）**
- **「無料で1事例まるごと」→「残り27事例はnoteで」の流れ。** 投稿の8割は見返りを求めない純粋な「へぇ」の投稿にし、2割に「議会・企画書で使うなら」という一言とプロフィールのリンクを付ける。
- **Xの投稿にはURLを入れない**（1件$0.20と高いうえ、一般にリンク付きは伸びにくいとされる）。リンクはプロフィールと、週2本の案内投稿だけに入れる。Threadsは無料なので、案内投稿にリンクを入れる。
- **Instagramリールを新しい人に届く入口にする。** フォロワーがゼロでも、おすすめに出て見てもらえる可能性がいちばん高い形式なので、週3本は必ず出す。
- **時期に合わせたメッセージ**：11月前半は「通告締切の前に」、11月後半は「3月議会と来年度予算の準備に」に切り替える。
- **キーワード**：#一般質問 #地方議員 #自治体 #政策 #海外事例 などを付ける。noteの無料部分のタイトルと見出しには「海外 事例 ○○（分野）」を入れ、検索から来てもらう。

### 自動化できない作業と解決策
| 自動化できない作業 | 解決策 |
|---|---|
| noteへのログイン・記事の公開・修正 | 公開は4章の1回だけにする。**記事は公開前に⑥品質管理を2回通し、あとから直さなくて済む状態にする。** 万一の誤りはSNSの固定投稿に「正誤表」を出して知らせ、記事の修正だけを例外としてオーナーに頼む |
| noteの売上数の取得（APIがない） | X・Threadsのリンククリック数と、noteの「スキ」の数（公開ページで見られる範囲）で推定する。正確な数は11/9と11/23の2回だけ、オーナーにスクリーンショット1枚をお願いする（任意。なくても計画は止めない） |
| 購入者からの質問 | 記事の最後に「よくある質問」を厚く書いて先に答えておく。質問はXのリプライで受け、AIが返す（APIで返せる範囲） |
| ページの本文が開けず、出典を全文で確認できない（前提5） | 一次資料のURLを付けたうえで、抜粋で確かめられた数字だけを載せる。確かめられなかった数字は「未確認」と書くか、載せない。**有料商品なので、出典が弱い事例は30件に入れない**（予備を40件作ってから30件に絞る） |
| 本人確認・口座・特定商取引法の表記 | 4章の1回でまとめて済ませる |

## 7. リスクと対策

| リスク | 起こりやすさ | 対策 |
|---|---|---|
| **フォロワーゼロからでは、40日で人が集まらない**（いちばん大きい） | 高 | Instagramリールを入口にする。noteの無料部分を検索に載せる。11/9と11/23で判断し、早めに作戦を変える |
| 有料記事の中に誤りがあり、AIでは直せない | 中 | 公開前に品質管理を2回通す。出典が弱い事例は入れない。正誤表を出す。修正だけは例外としてオーナーに頼む |
| 議員は政治的に見られやすい | 中 | 特定の政党・政策の良し悪しを言わない。良い面と批判の両方を載せる。選挙運動に関わる使い方はお断りと明記する |
| SNSの規約（自動投稿・スパム） | 低〜中 | 同じ文面は使わない、知らない人へのリプライ・DMはしない、API上限よりずっと少なく投稿する。宣伝の投稿は自分の商品だとわかる書き方にする |
| X APIの料金が上がる・使えなくなる | 低〜中 | リンク付きの投稿を減らす。ThreadsとInstagramに比重を移す |
| noteの価格上限・規約・特定商取引法の表記で、想定どおりに出せない | 低〜中 | 4章の作業の中で画面を見て確認する。9,800円が出せなければ、分冊（4,980円×2本）に変える |
| 「売れたか」がAIにはリアルタイムでわからない | 高（確実） | クリック数とスキで推定する。正確な数はスクショ2回（任意） |
| オーナーが第0週の1回の作業をできない | 中 | 一式を10/24に渡し、所要時間を90分以内に抑える。遅れるほど売れる期間が短くなるので、このお願いの優先度を一番上にする |

## 8. 達成確率（正直に）と、その根拠

| 結果 | 見込み |
|---|---|
| 何か1件でも売れる | 約50% |
| 利益2万円以上 | 約20〜25% |
| **利益5万円以上（目標）** | **約10〜15%** |

**根拠**
- 必要なのは「Aが6件前後」。3章の流れだと、買い手候補が約300人来て、そのうち2%が買う必要がある。フォロワー・実績・レビューがゼロのアカウントでは、**来る人の数（約1,500人）がいちばん不確か**で、半分の750人程度で終わることも十分にありうる。その場合、Aは3件ほど、利益は2万円台になる。
- 上がる要因：時期がぴったり合っていて、買い手の予算感からすると9,800円は小さい。Aが1件売れるだけで目標の約17%になる。noteの無料部分が検索に載れば、SNSのフォロワーと関係なく人が来る。
- 下がる要因：議員がnoteで資料を買う習慣があるかは確かめられていない。政務活動費の扱いも要確認。出典の確認が抜粋頼みなので、出せる事例数や品質に限界がある。
- 参考：`sales/plan_november.md` のB2B営業案は「利益5万円以上で約35%」と見ている。ただしそれは**人が約30〜35時間、営業・返信・納品をする前提**の数字。今回の前提（オーナーはほぼ動かない）では、その案はそもそも動かせない。
- **12月以降の価値**：12月で終わりではなく、3月議会（通告は2月ごろが多いとされる。要確認）向けにも同じ記事が売れる。11月で目標に届かなくても、資産は残る。

## 9. ほかの案を退けた理由

- **ココナラ・ランサーズへの出品**：購入者とのメッセージや納品ボタンなど、注文ごとに人がログインしてやる作業がいる。APIもないので、前提1・2に反する。
- **B2Bリサーチの受託（メール営業＋個別納品）**：営業の送信・見積もり・契約・納品の確認に、人が毎日必要になる。自治体は支払いや手続きが遅く、11月に間に合わないことが多い。
- **Stripeの決済リンク＋自前のサイト**：APIで全部自動にできるのは良い点。ただ、オーナーの初期作業（本人確認・審査・特定商取引法の表記で住所や電話番号を出す・サイトの公開）が重い。それに、知らないサイトの決済ページは買われにくい。12月に、売れ行きの実績を見てから検討する。
- （補足）**Xの収益配分・アフィリエイト**：Xの収益配分は、フォロワー数などの条件を40日で満たすのが現実的でない（細かい条件は要確認）。アフィリエイトは、1件あたりの額が小さすぎて5万円に届かない。

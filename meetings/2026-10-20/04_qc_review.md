# 品質管理AIのレビュー：3案への批判

> 作成：⑥ 品質管理AI ／ 2026-10-20
> 立場：**疑う人。** 3案の数字・前提・規約を検算し、通してよいかを判定する。
> 調べ方：3案の本文、社内ファイル（`CLAUDE.md`、`.claude/agents/`、`data/`、`sales/`、`scripts/`）、WebSearch（抜粋のみ）。ページ本文は読めていない。確認できなかった点は「要確認」と書いた。

## 0. 先に結論

- **3案とも、このままでは通さない。** いちばん大きい理由は3案に共通している。**「AIがAPIで毎日自動投稿する」仕組みが、社内にまだ存在しない**（2章）。集客はすべてこの仕組みに頼っているのに、どの案もこの穴に触れていない。
- 3案の中では **①戦略AIの「12月議会パック」がいちばん筋が良い**。ただし集客の見込み（1,500人）は10倍近く楽観しすぎで、達成確率10〜15%は高すぎる。私の見立ては **3〜5%**。
- ②リサーチAIの「AI会社の中身キット」は、**今の社内ファイルでは売り物にならない**（5章）。11月には出さない。
- ③収益化AIの「知り合い限定」案は、5万円にいちばん近い唯一の道だが、**前提1（営業は頼めない）に正面から反する**。社長だけでは決められず、オーナーに聞くべき論点。
- 社長への推薦：**①を土台に、②の直し（事例数を絞る・11/20締め）を入れ、③は「オーナーの了承が取れたときだけ足す」選択肢にする組み合わせ案**（6章）。

## 2. 3案に共通する致命的な問題（どの案を選んでも直す）

### 2-1. 自動投稿の仕組みが、まだ無い【致命的・直せる】
- `scripts/` にあるのは `make_reel.sh`（動画化）と `render.sh`（画像化）だけ。**X・Threads・Instagramに投稿するスクリプトは存在しない。** `publisher-analyst.md` は「`scripts/` の投稿スクリプトで投稿する」と書いているが、その実物が無い。
- `data/config.md` は `AUTO_POST: false`、`data/posted.md`・`data/metrics.md` は空。**この会社はまだ1本も投稿していない。**
- `CLAUDE.md` の日次フローは「『日次運営を実行』と言われたら」動く。**毎日だれかが話しかけないと動かない。** オーナーが毎日指示するなら前提1違反。定期実行（スケジュール）を最初に組む必要がある。
- **Instagramは、APIで投稿する画像・動画を「公開されたURL」に置く必要がある**（Meta公式ドキュメントの抜粋：メディアは公開サーバー上にあること）。いまの環境には画像・動画を置く公開の場所が無い。①が「新しい人に届く入口」とするリールは、このままでは投稿できない。リールをAPIで出せるかも、Metaの新旧ドキュメントで記述が食い違っている（要確認）。
- **直し方**：第0週（10/26まで）に「投稿スクリプト3本＋定期実行＋画像の公開置き場」を作り、テスト投稿まで終える。置き場が用意できなければ、11月はXとThreadsだけで計画する（リールは12月）。この作業はAIでほぼできるが、トークン・置き場のアカウントはオーナーの初回作業に入れる。

### 2-2. 集客の数字に根拠が無い【致命的に近い・一部直せる】
- フォロワー0のアカウントの1投稿の表示は、多くて数十〜数百回と見るのが普通。①の想定を自分で積み直すと：
  - X：1日2本×約35日＝70本×1本50表示＝約3,500表示。リンクはプロフィールだけなので、noteへのクリックは**数十回**。
  - リール：週3本×5週＝15本×1本300再生＝約4,500再生。プロフィールのリンクを押す人を0.5%とすると**約20人**。
  - noteの中・Google検索：新しい有料記事が11月中に検索で上位に出る根拠は無い。多めに見て**100人**。
  - → 合計 **150〜300人**。①の1,500人の **1/5〜1/10**。
- その上で「来た人の20%が議員・職員・コンサル」も楽観すぎる。「へぇ」系の雑学投稿に集まるのは主に一般の20〜40代（`brand/guidelines.md` のメインターゲット）。議員の比率は数%と見るべき。
- 再計算：250人×5%（買い手候補）×2%＝**0.25件**。①の6件とは桁が違う。
- **直し方**：SNSだけで売る前提をやめ、「買い手が自分で探しに来る場所」（note・Google検索のタイトル設計）と、③のような「すでに信用がある経路」を足す。判断日（11/9）の基準を「クリック300回」ではなく「クリック50回・購入1件」に下げ、早めに見切る。

### 2-3. 有料の事実資料を「抜粋だけ」で作る【直せる・必須】
- 前提5でページ本文が読めない。①は「抜粋で確かめた数字だけ載せる」としているが、**抜粋は文脈が切れていて、年・単位・対象の取り違えが起きやすい**（`data/ideas.md` 自身が「報道によって年齢や速度に食い違いあり」「利用者数は資料によって幅」と書いている）。議員が議会で使う資料に誤りがあれば、買った人が恥をかき、返金・炎上につながる。
- `sales/sample_report.md` の冒頭は「AIを活用して公開情報を調査し、**人が確認したもの**です」と書いている。**オーナーが確認しない計画なら、この文言は事実と違う（誤認表示）。** どの案でも、この一文は「AIが出典と照らし合わせたもの。人による最終確認はしていません」に直す。
- **直し方**：①の「40作って30に絞る」を「本文（公的機関のページかPDF）まで確認できたものだけ、**20事例**」に減らす（②の数に合わせる）。各事例に「確認日」と「確認の深さ（本文／抜粋のみ）」を書く。抜粋だけのものは有料部分に入れない。

### 2-4. 経費の数え方がバラバラ【直せる】
- ①：AIツール5,000円＋X API約1,000円＋振込270円＝約6,300円
- ②：**経費0円**（AIツール代を入れていない。X APIも「無料枠」前提）
- ③：AIツール5,000円（X APIは入れていない）
- X APIは現在、新規は従量課金が基本で、前払いのクレジットが必要とされる（第三者記事の抜粋。要確認）。投稿だけでなく、**自分の投稿へのコメントを読む・実績を取る（読み取り）にも料金がかかる**（1件あたり約$0.001〜0.005とされる）。①はコメント返信と実績の自動取得を予定しているので、読み取り分も見ておく。金額は小さい（月数百円）が、②の「経費0円」は成り立たない。
- **直し方**：3案共通で「AIツール5,000円＋X API 1,500円（前払い$10）＋振込手数料」で計算し直す。

## 4. 法律・規約のチェック（3案まとめ）

| 項目 | 判定 | 内容と直し方 |
|---|---|---|
| **特定商取引法** | **要対応（全案）** | note・BOOTH・自前の決済で、不特定の人に繰り返し売るなら「販売業者」にあたり、氏名・住所・電話番号などの表示が必要になる可能性が高い（法11条、施行規則。個人でも対象）。noteのヘルプに「特商法表示で自分の住所や電話番号を掲載しなければならないか」という項目がある（中身は抜粋で確認できず、要確認）。**オーナーの個人情報を出すかどうかの判断なので、初回作業の前に必ず決める。**「請求があれば遅滞なく開示する」形で省略できる場合があるとされるが、条件は消費者庁の資料で確認が必要（要確認） |
| **ステマ規制（景品表示法）** | OK（条件つき） | 自社アカウントで自社商品を案内するのは、事業者の表示だと明らかなので、ステマには当たりにくい。条件：①案内投稿に「自社の有料記事です」と書く ②アフィリエイトを入れるなら「PR」を必ず付ける ③「購入者の声」は本人の許可があり、実在するものだけ（①の案どおり。つくらない） |
| **景品表示法（有利誤認・優良誤認）** | **要対応（②・全案のサンプル）** | 「人が確認した」（sample_report.md）、「SNS会社を回す」（②）は実態と違う。直す |

| **AI生成物の扱い** | 注意 | AIが作った文章は著作権で守られない可能性がある。買った人が中身をそのまま公開しても止めにくい。特に②のキットは丸ごとコピーされやすい。note・BOOTHではAI使用を冒頭に明記する（全案とも予定どおり） |
| **X の自動化ルール** | 注意 | 自動投稿は許されているが、同じ文面の繰り返し・一方的なリプライやメンションは禁止。プロフィールに「自動化されたアカウント」のラベルを付けておくと安全（要確認） |
| **X API の費用** | 要対応 | 従量課金・前払い。通常投稿約$0.015、URL付き約$0.20、読み取りも課金（第三者記事の抜粋、要確認）。①の「URLはXに入れない」は正しい。②の「無料枠」は前提として成り立たない |
| **Instagram API** | **要対応（①）** | ビジネス／クリエイターアカウント、Facebookページ連携、メディアの公開URLが必要。リールのAPI投稿可否は要確認 |
| **BOOTHのAI規約** | 注意（②） | 「AIを使った粗製乱造品」は強制非公開の対象（②の調査どおり）。2点だけなら低リスクだが、中身が薄いキットはこれに近い |
| **公職選挙法・政治** | OK（条件つき） | 議員に有料で資料を売ること自体は問題ない。選挙運動用の利用お断り、特定政党・政策の評価をしない（①の対策どおり）。議員に**無料で配る**のは寄附の議論を呼びうるので、見本は誰でも読める無料部分に限る |
| **ブランド名「スライム国」** | 注意 | 「スライム」は一般名詞で名前自体は問題ないが、画像に有名ゲームのスライムに似たキャラクターを描くと、著作権・商標の問題になる。オリジナルの形にする |

| `brand/guidelines.md` | 自社ブランド専用 | 中身は良いが、スライム国の色・名前がそのまま。テンプレートにするには作り直しが必要 |
| `sales/`・`meetings/` | 社内の営業方針・会議資料 | 混ぜると社内情報の流出。抜く作業がいる |

**名前の問題**
- 「AI社員10人でSNS会社を回す」：まだ回っていないので**実態と違う**。「社員」も誤解を招く（エージェントは雇用ではない）。
- 「AI会社の中身キット」「設定キット」：中身は「設定ファイルの見本」なので、名前としては「〜の設定ファイル見本（未完成の記録つき）」のように、できていない部分が分かる名前にすべき。
- 製品名・商標（Claude、Claude Codeなど）を商品名に入れるのは避け、説明文で「〜で使える」と書く程度にする（各社の商標ガイドラインは要確認）。

**売るなら（12月以降）の条件**
1. 30日以上実際に動かし、投稿数・表示・失敗・費用の**実際の記録**をつける（「売上0円でした」も含めて）。
2. 投稿スクリプトと定期実行の設定を入れ、別の環境で動くか試す。環境固有のパスを消す。
3. 社内の営業資料・会議資料・個人に関わる情報を抜く（品質管理AIが全ファイルを検査）。
4. 価格は980〜1,980円程度から。中身の多くは無料記事で見せ、「まとめて取れる便利さ」に値段を付ける。

## 6. 私が社長なら：組み合わせ案「議会パック・確実版」

**土台は①。②から「品質の設計」を、③から「信用のある経路」を、オーナーが了承したときだけ借りる。キットは12月へ。**

| 項目 | 内容 |
|---|---|
| 商品 | note有料記事1本『12月議会・企画書で使える 海外の仕組み20（出典・確認日つき）』**9,800円**。無料部分に3事例を丸ごと。980円のBはやめる |
| 中身の基準 | 本文（公的機関のページ・PDF）まで確認できた事例だけ。各事例に確認日・確認の深さ。「人が確認した」とは書かない。法的助言ではない旨と、選挙運動での利用お断りを明記 |
| 公開日 | **10/31（金）**。第0週は「20事例＋自動投稿の基盤づくり」に充てる |
| 売り場 | noteだけ（BOOTH・Stripeは使わない） |
| 集客 | X・ThreadsのAPI投稿（基盤ができた場合）。リールは画像の公開置き場ができたときだけ。noteの記事タイトルを「海外事例 一般質問 ○○」のように検索される言葉にする |
| 追加（オーナーが了承した場合のみ） | ③を縮めた形：オーナーが**1回だけ**、該当しそうな知り合いに「こういう資料をnoteで出しました。個別の調査も11月は2枠だけ受けます」と個別に送る。個別調査は銀行振込・前払い・標準3万円。確認は週1回20分 |
| 判断日 | **11/9**：noteへのクリック50回未満なら、SNSの比重を下げ、記事タイトル・無料部分を直す（オーナーに1回だけ修正を頼む）。**11/20**：訴求を「3月議会・来年度予算」に切り替え、12月以降も売れる形にする |
| キット | 11月は出さない。11月の運用記録を貯め、12月に5章の条件で再検討 |

**この案の収支（経費約6,700円＝AIツール5,000円＋X API約1,500円＋振込270円）**
- note A（手取り8,379円）だけなら **7件**で利益約51,900円（58,653−6,770）。SNSだけでは届かない見込み。
- 追加ありなら：個別調査1件（3万円、振込）＋note A 3件（25,137円）＝55,137円−6,770円＝**利益約48,400円**。あと1件（noteでも個別でも）で届く。

**達成確率の見立て**：追加なし **約3〜5%**、追加あり **約10〜15%**（知り合いの中身しだいで大きく上下）。正直に言えば、どの形でも「5万円が届かない」可能性のほうがずっと高い。その場合でも、20事例の記事と投稿の基盤は12月以降の資産として残る。

## 7. 社長が決める前に、必ず解決すべき論点（3つ）

1. **前提1の線引きをオーナー本人に確かめる。** 「知り合いへの1回だけの個別メッセージ」と「週20分の受信確認」を受けてくれるか。受けてくれないなら、5万円の確率は数%しかないことを先に伝え、11月の目標を「利益5万円」から「商品公開＋売上1件以上＋投稿基盤の完成」に変えるかを決めてもらう。
2. **自動投稿の基盤が10/26までに本当に動くか。** 投稿スクリプト（いま存在しない）、毎日の定期実行、X APIの前払い、Instagramの画像の公開置き場、各トークン。どれか一つでも欠けると、全案の集客が止まる。10/26時点で「テスト投稿が成功したSNSだけで計画する」と決めておく。
3. **販売者の表示（特商法）を誰の名前・住所で出すか。** オーナーの個人情報に関わり、AIでは決められない。noteでの表示方法と「請求時に開示」で省略できる条件を、初回作業の前に確認する。決まらなければ有料販売は始められない。

# 第2回経営会議 決定事項（2026-10-21）　決定者：統括AI（社長）

品質管理AIの差し戻し（13/25点）を受け、修正後のプランで決定する。

## 決定
### 商品：Kindle本「スライムと覚える AIへの頼み方テンプレ集」シリーズ 3冊
| 巻 | 場面 | 中身 |
|---|---|---|
| 1 | 仕事のメール | テンプレ50個以上＋使用例 |
| 2 | 議事録・要約 | テンプレ50個以上＋使用例 |
| 3 | PTA・町内会・サークルのお知らせ | テンプレ50個以上＋使用例 |
- 価格300円、KDPセレクト登録（日本で70%印税を取るための前提）。
- 中身はすべて**自分たちで実際にAIで試した結果**だけ。外部の数字や事実に頼らない → ネットワーク制限の影響を受けない。
- AI生成であることはAmazonに正しく申告する。表紙もAI（スクリプト）で作るので同様に申告。
- noteは1か月目の計算に入れない（2か月目から）。

### SNS：1か月目は Threads と Bluesky だけ（経費0円で確定）
- テーマ：**「スライムと試す、AIのかんたん使い方」**。海外の仕組みは週1回の特集に格下げ。
- Threads 1日3本、Bluesky に転記。プロフィールに「AIが運営しています」と明記。
- X（有料API）と Instagram（画像の置き場が未解決）は2か月目以降に再検討。

## 論点への回答
1. **3,000円は「目指す目標」。** 1か月目＝11/1〜11/30の売上（手数料差引）で数える。届かなければ2か月目と合算で判定する。
   見込み：1か月目20〜30%、2か月目までの合計で50〜60%（品質管理AIの推測）。
2. **ブランドのテーマ変更を承認。** `brand/guidelines.md` を更新する。
3. **KDPセレクトを承認。** オーナー作業は1か月目に note を外して約2時間に圧縮する。

## 社長が進めること
- Kindle 3冊の原稿・表紙・登録情報（タイトル、説明文、キーワード、AI申告）を作る
- Threads・Bluesky の投稿スクリプトと30日分の投稿ストックを作る
- 毎朝の自動運営の準備

1. Amazon KDP のアカウント作成・税務情報・振込口座（約40分）
2. Kindle 3冊のアップロード（AIが用意したファイルを選んで、文面を貼るだけ。約45分）
3. Threads のアカウント作成と API トークンの登録（約20分）
4. Bluesky のアカウント作成とアプリパスワードの登録（約10分）

## 0. 先に結論

1. **推奨プラン：「Kindle本（ストア内検索）× note有料記事（検索・SNS）」の二本立て。** 経費0円。
2. 理由：フォロワー0でも **お客さんの側から探しに来る場所（Amazonのストア内検索・Kindle Unlimited の読み放題）** があるのは、比べた中ではKindleが一番強い。noteは振込が早く（11月分は12月末に入金）、少額から引き出せる。片方がこけても、もう片方で3,000円に届くように組む。
3. **1か月目の内訳（標準ケース）**：Kindle本3冊（各400円）で **購入6冊＋読み放題の既読6,000ページ**、note有料記事（300円）を **8件**、チップ1件 → 利益 **約5,930円**（3,000円に対して約2,900円の余裕）。くわしくは4章。
4. 正直な見通し：**11月に利益3,000円に届く確率は 35〜45%**（私の見立て。フォロワー0から1か月の実績データは見つからなかった）。「確実」と言える方法は見つからなかった。最も外れにくいのは、ストア内検索がある売り場に、商品を**最初から複数並べる**こと。
5. 注意：**「3,000円が確定した」と言えるのは12月2日（noteの売上確定日）**。Kindle分は11月の販売がレポートに出るが、入金は**1月末ごろ**になる見込み（約60日後）。

### 1-2. 比べてわかったこと

- **フォロワー0で効くのは「売り場に検索がある」こと。** SNSの投げ銭・サブスクは、そもそもフォロワー条件を満たせない。

- **noteは「入金が一番早い」。** 11月の売上が12月中に現金になるのはnoteだけ（比べた中で確認できたもの）。

## 3. 経費を0円にする方法

| 費用になりそうなもの | 0円にする方法 |
|---|---|
| X APIの前払い（前回会議で約$10） | **11月はXのAPIを使わない**。Threads・InstagramはAPIが無料（Meta側の利用条件は要確認）。Xを使うなら、AIが作った投稿キューをオーナーが手で貼る…は作業が増えるので、**11月はXをやめる**のが筋。$10（約1,500円）を払うと、利益3,000円には売上を約1,500円多く積む必要がある |
| 表紙・図解の画像 | 既存の自動生成スクリプト（`scripts/render.sh` など）とブランドカラーで作る。有料素材は使わない。実在の人物や実写風のAI画像は使わない |
| 電子書籍の作成ツール | KDPはWord（.docx）やEPUBで入稿できる。AIが原稿ファイルを作る（無料） |
| ISBN | Kindle電子書籍は不要（ASINが付く）。要確認 |
| 有料APIの調査ツール | 使わない（WebSearchの範囲で作る） |
| 振込手数料 | 経費ではなく手数料として計算に入れる（noteは1回270円。**振込は月1回にまとめる**） |

→ **経費0円。** 利益＝売上−手数料（振込手数料を含む）だけで計算する。

## 7. リスクと対策

| リスク | 対策 |
|---|---|
| 事実の誤り（本文を開けない） | 検索抜粋で確認できた事実だけ。1テーマ1出典以上。断定を避ける。品質管理AIが照合 |
| KDPの品質審査・AI本への厳しい扱い | AI生成を正直に申告。薄い本・似た本を量産しない（1冊ごとにテーマを分ける） |
| KDPセレクトの独占とnoteの重複 | ネタを分ける（Kindle＝まとめ型、note＝深掘り型） |
| 手数料・規約が変わっている | 「要確認」の項目は、オーナーが登録するときの画面表示で確かめてもらい、ずれていたら計算を直す |
| 自分で買う・知り合いに頼んでレビューを書いてもらう | **しない**（規約違反・誤解を招く。Amazonは家族・友人のレビューを禁止しているとされる） |
